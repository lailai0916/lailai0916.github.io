## 题意简述

给定六位整数 $Y$ 和整数 $Z$，求所有后六位为 $Y$ 的十二位整数 $X$ 中，$|X-Z|$ 的最小值。

## 解题思路

令 $M=10^6$。由于 $X$ 的后六位固定为 $Y$，可写成 $X=kM+Y$。要使 $X$ 恰有十二位，前六位 $k$ 必须满足 $100000\le k\le999999$。因此，问题转化为在这组等差数列中，选出与 $Z$ 距离最近的数。

不限制 $k$ 时，最优系数是最接近 $(Z-Y)/M$ 的整数；再将它限制在 $[100000,999999]$ 内，就得到最优合法系数。代码用 `(z-y+M/2)/M` 对系数四舍五入，再用 `clamp` 限制范围。当 $Z$ 位于合法数列范围内时，$z-y$ 非负，该整数式会将系数舍入到最近整数；若 $Z$ 在范围外，`clamp` 会将系数截到相应端点。若 $Z$ 恰处于两个相邻合法系数的中点，向上或向下取整都得到相同距离。

据此构造 $X$ 并计算 $|X-Z|$，时间复杂度为 $O(1)$。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

using ll=long long;
const ll M=1000000;
int main()
{
	ios::sync_with_stdio(false);
	cin.tie(nullptr);
	ll y,z;
	cin>>y>>z;
	cout<<abs(clamp((z-y+M/2)/M,100000ll,999999ll)*M+y-z)<<'\n';
	return 0;
}
```
