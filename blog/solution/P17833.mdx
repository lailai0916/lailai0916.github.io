## 解题思路

记 $l_i,r_i$ 为从 $i$ 一步可达的最左、最右岛屿，包含自身。

最短路严格递增，起点右侧的图距各层按坐标分离。逐层取两条路的最大、最小点仍为最短路；若至少两层不同，由大路转入小路可得第三条。若唯一分叉层的两点不相邻，夹点也产生第三条。因此，恰好两路必为单个相邻菱形：

$$
p\to\set{a,a+1}\to q,p<a<a+1<q,r_p=a+1,l_q=a
$$

记 $f_i$ 为到 $i$ 的最短路唯一且每步均跳至最右可达点的起点数，包含 $i$。直接起点满足 $j<i,r_j=i$；继续向左延伸须有 $j=l_i$。令 $l_{n+1}=n+1$，以 $[P]$ 表示指示函数，则：

$$
f_i=1+\min(i,l_{i+1})-l_i+[l_i<i\land r_{l_i}=i](f_{l_i}-1)
$$

从右向左对称求出 $g_i$。菱形向左、右延伸分别要求 $l_a=p,r_{a+1}=q$，使前驱、后继均唯一。因此，两端选择数为：

$$
\begin{aligned}
  L_p & =1+[l_a=p](f_p-1) \\
  R_q & =1+[r_{a+1}=q](g_q-1)
\end{aligned}
$$

每对端点对应唯一菱形，左右选择独立。汇总左侧后得到答案：

$$
\begin{aligned}
  s_a & =\sum_{\substack{p<a\\r_p=a+1}}L_p \\
  A & =\sum_{\substack{1\le q\le n\\l_q+1<q}}s_{l_q}R_q
\end{aligned}
$$

时间、空间复杂度均为 $O(n)$。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

using ll=long long;
const int N=2000005;
ll x[N];
int l[N],r[N],f[N],s[N];
int main()
{
	ios::sync_with_stdio(false);
	cin.tie(nullptr);
	int c,T;
	cin>>c>>T;
	while(T--)
	{
		int n;
		ll d;
		cin>>n>>d;
		for(int i=1;i<=n;i++)cin>>x[i];
		int j=0;
		for(int i=1;i<=n;i++)
		{
			while(j<n&&x[j+1]-x[i]<=d)
			{
				j++;
				l[j]=i;
			}
			r[i]=j;
			s[i]=0;
		}
		l[n+1]=n+1;
		for(int i=1;i<=n;i++)
		{
			f[i]=1+min(i,l[i+1])-l[i];
			if(l[i]<i&&r[l[i]]==i)f[i]+=f[l[i]]-1;
			if(r[i]>i+1)s[r[i]-1]+=l[r[i]-1]==i?f[i]:1;
		}
		r[0]=0;
		ll ans=0;
		for(int i=n;i>=1;i--)
		{
			f[i]=1+r[i]-max(i,r[i-1]);
			if(r[i]>i&&l[r[i]]==i)f[i]+=f[r[i]]-1;
			if(l[i]<i-1)ans+=1ll*s[l[i]]*(r[l[i]+1]==i?f[i]:1);
		}
		cout<<ans<<'\n';
	}
	return 0;
}
```
