## 解题思路

将 $a$ 升序排序。固定数量和最大值，选取不超过该最大值的最大若干项最优。因此仅需考虑连续区间 $[l,r]$，代价为：

$$
\sum_{i=l}^r(a_r-a_i)=(r-l+1)a_r-\sum_{i=l}^r a_i
$$

代价随 $r$ 不减、随 $l$ 不增。用双指针求代价不超过 $m$ 的最长区间，时间复杂度 $O(n\log n)$。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

using ll=long long;
const int N=500005;
ll a[N];
int main()
{
	ios::sync_with_stdio(false);
	cin.tie(nullptr);
	int n;
	ll m;
	cin>>n>>m;
	for(int i=1;i<=n;i++)cin>>a[i];
	sort(a+1,a+n+1);
	int l=1,ans=0;
	ll sum=0;
	for(int i=1;i<=n;i++)
	{
		sum+=a[i];
		while(a[i]*(i-l+1)-sum>m)
		{
			sum-=a[l];
			l++;
		}
		ans=max(ans,i-l+1);
	}
	cout<<ans<<'\n';
	return 0;
}
```
