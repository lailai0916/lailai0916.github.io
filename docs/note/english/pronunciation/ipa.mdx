## 简介

**国际音标**（International Phonetic Alphabet，IPA）用符号记录语音。使用英语词典时，区分 3 个层次：

1. **字母**：单词的拼写，如 sheep 中的 ee；
2. **音位标记**：用斜线括起，如 /ʃiːp/，表示所选口音下的宽式读音；
3. **具体音值**：用方括号括起，如美式闪音 [ɾ]，记录更细的发音特征。

以下清单采用传统英式词典中的 12 个单元音、8 个双元音和 24 个辅音分类。它是英语学习模型；其他口音的音位数量与音值可能不同。

## 元音

### 单元音

**长元音**：

- /iː/：see。
- /ɑː/：father。
- /ɔː/：saw。
- /uː/：too。
- /ɜː/：bird。

**短元音**：

- /ɪ/：sit。
- /e/：bed。
- /æ/：cat。
- /ɒ/：hot。
- /ʊ/：put。
- /ʌ/：cup。

**中央元音 /ə/**：见 about 的首音节，常见于非重读音节。

- 长短分类同时涉及音质，不能仅靠延长 /ɪ/ 得到 /iː/。
- 实际时长还受重音、语速和相邻辅音影响。
- 弱读不仅涉及 /ə/；/ɪ/ 等也可出现在非重读音节中。

### 双元音

- /eɪ/：face。
- /aɪ/：price。
- /ɔɪ/：choice。
- /əʊ/：goat。
- /aʊ/：mouth。
- /ɪə/：near。
- /eə/：square。
- /ʊə/：cure。

这是传统分类。部分当代英式口音会把有关双元音读成单元音，例如 cure 也可读 /kjɔː/；查词时以所选口音的词典标音为准。

## 辅音

### 爆破音

每对前者为清辅音，后者为浊辅音：

- /p/ 与 /b/：pen、bad。
- /t/ 与 /d/：ten、day。
- /k/ 与 /g/：cat、get。

### 摩擦音

每对前者为清辅音，后者为浊辅音，另列 /h/：

- /f/ 与 /v/：fine、voice。
- /θ/ 与 /ð/：think、this。
- /s/ 与 /z/：see、zoo。
- /ʃ/ 与 /ʒ/：she、vision。
- /h/：he，清辅音。

### 破擦音

- /tʃ/：chair，清辅音。
- /dʒ/：job，浊辅音。

### 鼻音、边音和近音

- **鼻音**：/m/（man）、/n/（no）、/ŋ/（sing）。
- **边音**：/l/（look）。
- **近音**：/r/（red）、/j/（yes）、/w/（we）。

词典用 /r/ 记英语的有关近音；精细标音中也可见 [ɹ]。字母名称、词典符号和实际音值分别判断。

## 重音

- **主重音 /ˈ/**：标在主重读音节前，如 table /ˈteɪbl/。
- **次重音 /ˌ/**：标在次重读音节前，如 international /ˌɪntəˈnæʃnəl/。

查词时同时记录各音段和重音位置。重音标记位于音节前，不一定紧贴该音节的元音。

## 英式与美式差异

先确定口音，再比较具体词项。英式、美式各自都包含不同地区的读法。

- **r 的发音**：
  - 英格兰南部等非卷舌口音中，字母 r 在词尾或辅音前不读 /r/，如 car /kɑː/、hard /hɑːd/；这与该音节是否重读无关。
  - 后接元音时可出现连接 r，如 car engine。
  - 通用美式等卷舌口音保留上述位置的 r，如 car /kɑːr/。
- **元音**：
  - goat 的英式标音常写 /əʊ/，美式常写 /oʊ/。
  - hot、bath、dance 等词也有口音差异，分别查词，不能对所有拼写作统一替换。
- **闪音**：
  - 通用美式中，重读元音与非重读元音之间的 /t/ 或 /d/ 可读成 [ɾ]，如 better、ladder。
  - water 也是常见例子；[ɾ] 是实际音值，不是把拼写 t 改成 d。
