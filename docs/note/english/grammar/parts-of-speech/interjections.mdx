## 简介

**叹词**（Interjection）通常独立于周围的句法结构，表达即时情感、反应或交际态度，例如 oh、wow、ouch、alas。

- **Oh**, I forgot to tell you.（哦，我忘了告诉你。）
- **Ouch!** That hurts.（哎哟！好疼。）

Oh 不是主句的主语、宾语或表语；删去它，I forgot to tell you 仍完整。但它传达了突然想起、察觉等话语信息，不能因为「不作主句成分」就认为它没有意义。

叹词既可以是单词，也可以是固定表达，如 oh dear。不同词典对边缘情况的分类可能不同，应区分 **词类** 与「用于应答、招呼、表达情感」等 **话语功能**。

## 常见情感与语域

**语域**（Register）指表达与交际场景之间的适配关系，如日常口语、正式书面语、文学语言。

|     表达     |         常见反应         |                   语域与示例                   |
| :----------: | :----------------------: | :--------------------------------------------: |
|      oh      | 察觉、惊讶、理解、失望等 |            常见口语：**Oh, I see.**            |
|      ah      |       领悟、满意等       |      常见口语：**Ah, now I understand.**       |
|     wow      |        惊叹、惊讶        |         较随意：**Wow, what a view!**          |
|     ouch     |   疼痛，也可比喻受打击   |        常见口语：**Ouch! That hurts.**         |
|  ugh / yuck  |        厌恶、不适        |     随意口语：**Yuck! This tastes awful.**     |
|     phew     |  松一口气、感到热或疲惫  |      常见口语：**Phew, that was close!**       |
| hooray / yay |        欢呼、喜悦        |      欢庆或随意语境：**Hooray! We won!**       |
|     alas     |        惋惜、悲伤        | 偏文学或刻意戏剧化：**Alas, it was too late.** |
|     oops     |     察觉小失误、意外     |   常见口语：**Oops! I sent the wrong file.**   |
|    bravo     |        赞赏、喝彩        |    演出或取得成绩后：**Bravo! Well done!**     |
|     psst     |       低声引起注意       |         随意口语：**Psst! Over here.**         |
|   shh / sh   |         请求安静         |     常见口语：**Shh! The baby is asleep.**     |

一个词不只对应一种情感。Oh, really? 可以表示好奇、怀疑或讽刺，取决于语调和上下文。学习叹词不能只背一对一的中文翻译。

犹豫声常写成 um、uh、er 或 erm，拼写和使用倾向存在地区差异。叹词的使用频率还可能因年龄和交际群体不同而变化；词典中列出的近义表达，不保证在同一场合具有相同语气。

alas 不适合机械替代日常口语里的「唉」；它可能显得文学化或带戏剧效果。yuck、yay 等也不适合无条件放进正式论述。

## 相近的话语表达

### 应答与招呼

|       表达       |         功能         |                        分类边界                        |
| :--------------: | :------------------: | :----------------------------------------------------: |
| yes / yeah / no  |    肯定或否定应答    |        常称应答词；不同词典可能采用不同词类标签        |
|    OK / sure     |      接受、同意      |       词类须看具体结构，不能仅凭「表示同意」判断       |
|  hmm / um / er   | 思考、犹豫或填补停顿 |                 常按叹词或话语标记处理                 |
| hi / hello / hey | 问候、招呼、引起注意 |               hello、hey 等常有叹词用法                |
|      maybe       |       表示可能       | 通常是副词；Maybe later 是省略表达，不因此自动变成叹词 |
|  look / listen   |       引起注意       |     通常仍与动词祈使结构有关，也可发挥话语标记作用     |

对比 **Listen!** 和 **Listen to the recording.**：后者清楚地是省略主语 you 的祈使句。look、listen 的招呼功能与 hey 相似，不代表句法结构相同。

hey 可以是友好招呼，也可能显得生硬。对陌生人或正式场合，Excuse me 往往更合适。yeah 比 yes 随意，但不能把「随意」直接等同于「错误」。

词组也可以表达即时反应：Come on! 可表示鼓励，也可表示催促或不耐烦；Oh dear! 可表达担忧或失望。判断时应看整段对话，不能因两个表达出现在同一情感类别里就任意替换。

英语 yes / no 通常按回答的事实是否为肯定判断。

- Haven't you finished? — **Yes, I have.**（已经完成了。）
- Haven't you finished? — **No, I haven't.**（还没有完成。）

否定问句的回答宜补出短答，避免仅靠中文「是的」「不是」来对应。

### 拟声表达

**拟声词**（Onomatopoeia）模仿声音。拟声与叹词有交集，但不是同一分类依据。

|    表达     |  模仿对象  |                  示例                   |
| :---------: | :--------: | :-------------------------------------: |
| bang / boom | 撞击或爆炸 |    **Bang!** The door slammed shut.     |
|   splash    | 落水、水花 |   **Splash!** He fell into the pool.    |
|  tick-tock  |   时钟声   | The clock went **tick-tock** all night. |
| meow / woof | 猫叫或狗叫 |        We heard a loud **meow**.        |

独立的 Bang! 可以起类似叹词的作用；a loud bang 中的 bang 是名词；The door banged 中的 banged 是动词。相同声音形式在不同句法位置可以属于不同词类，不能把所有拟声表达一律列为叹词。

## 标点与句式

### 标点选择

标点反映语气和与后文的联系，不存在「叹词独立出现就必须用感叹号」的规则。

|         情况         |            示例             |      作用      |
| :------------------: | :-------------------------: | :------------: |
| 与后句连成较轻的反应 |       **Oh,** I see.        |   用逗号隔开   |
|  反应较强，独立成句  |    **Ouch!** That hurts.    |    用感叹号    |
|    语气平缓或低落    | **Oh.** I thought you knew. |     用句号     |
|  表示疑问或要求确认  |          **Hmm?**           | 用问号表现语气 |

小说或聊天可能用重复字母、重复标点表现声音，但正式考试写作应保持规范标点。叹词在句首时遵循句首大写；位于句中时不必机械大写。

### 叹词与感叹句

**叹词** 是词类，**感叹句**（Exclamative Clause）是句式。一个表达具有感叹语气，也不意味着其中一定有叹词。

|    类型     |              示例               |             结构              |
| :---------: | :-----------------------------: | :---------------------------: |
|  叹词表达   |            **Wow!**             |        不要求主谓结构         |
| what 感叹句 | **What a beautiful day it is!** | what + 名词短语 + 主语 + 谓语 |
| what 感叹句 |   **What beautiful weather!**   |    weather 不可数，不加 a     |
| how 感叹句  |  **How beautiful the day is!**  |  how + 形容词 + 主语 + 谓语   |
| how 感叹句  |  **How carefully she works!**   |   how + 副词 + 主语 + 谓语    |

what 修饰名词短语；how 可修饰形容词或副词。感叹句通常保持陈述语序：How beautiful **the day is**，不是 How beautiful **is the day**。

What a beautiful day! 等表达可省略后面的主谓部分。Wow, what a beautiful day! 中同时有叹词和感叹句，两者并不排斥。Fire! 等呼喊也能表达感叹或警报功能，但不能仅凭感叹号就判定为 what / how 感叹句。

## 考试与交际

- **高考记叙文、日记、对话或续写**：可按人物情感使用少量叹词；是否合适取决于题目语境。
- **托福、雅思口语**：自然出现的 Oh、well、hmm 等反应或话语标记可以成立，不必刻意插入或反复填充。
- **学术论述、正式说明和议论文**：通常直接写判断与理由，不用 Wow!、Yay! 等表达个人惊叹；引用人物原话时可保留其语言。

well 常作为组织话语或缓和回答的标记，不必把口语中每次 well 都解释成情感叹词。考试的目标是语境恰当、表达清楚，而不是叹词越多越自然。
