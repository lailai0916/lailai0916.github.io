## 简介

**代词**（Pronoun）用来指称人、物或语境中的内容，常替代整个名词短语。

- **依赖说话角色**：I、you 可直接指说话人和听者，不必先出现一个名词。
- **依赖现场或话语**：this 可由手势、现场或前后文确定。
- **不指具体对象**：「It is raining.」中 it 是语法主语，没有对应的某件事物。
- **同形但功能不同**：this 可独立作代词，也可在名词前作限定词。

<EnglishExamples
  title="同形形式的不同功能"
  items={[
    {
      label: '独立指代',
      sentence: 'This is useful.',
      translation: '这很有用。',
    },
    {
      label: '限定名词',
      sentence: 'This book is useful.',
      translation: '这本书很有用。',
    },
  ]}
/>

选择形式时，依次检查 **所指 → 句法功能 → 格与数 → 谓语及回指的一致关系**。

- 传统的形容词性物主代词对应 **物主限定词** my、your 等。
- 传统的名词性物主代词对应 **独立物主形式** mine、yours 等。

### 人称代词

**人称代词**（Personal Pronoun）依照说话角色或语境指称人和事物；按当前句法功能选格。

#### 格与句法位置

- **普通限定分句的主语用主格**：疑问或倒装会改变表面顺序，不能按是否位于动词前判断。非限定分句另按结构选格，如 for **him** to leave。
- **动词或介词的宾语用宾格**。
- **并列结构逐项检查功能**。
- **并列次序与格分开判断**：you and I、Anna and me 将自己放在后面是礼貌习惯；2-3-1 或担责时 I 放首位不是语法规则。
- **表语区分语体**：me、her 等宾格形式用于自然的标准口语；I 等主格形式也见于很正式的传统用法。

#### 单数 they

**单数 they**（Singular They）指性别未知、无需说明性别的人，或使用 they 作为代词的特定个体。

- **人称与物主形式**：主格 they，宾格 them，物主限定词 their，独立物主形式 theirs。
- **反身形式**：themselves；也见 themself，具体采用哪种形式按所用词典或体例。

<EnglishExamples
  title="单数 they 的一致关系"
  items={[
    {
      sentence: 'Someone has left their umbrella.',
      label: '主语单数与回指',
      translation: '有人落下了伞。',
      analysis: ['someone 作主语仍接单数谓语。'],
    },
    {
      sentence: 'Every student has a password. They are expected to keep it private.',
      label: '跨句回指',
      translation: '每名学生都有密码，应妥善保管。',
      analysis: ['回指的 they 保留 are、have 等形式，不用 they is。'],
    },
  ]}
/>

- 语义上只有一个人，不会使 they 采用 he/she 的动词形式；everyone 接 has 与回指用 their 可以同时成立。
- he or she、his or her 是另一套表达，现代标准英语也广泛接受单数 they；考试给定人称或选项时，按所指定结构判断。

### 物主代词

物主形式表达所属或关联，分为依存形式与独立形式：

- **后接名词短语**：物主限定词限定后面的名词。
- **独立使用**：独立物主形式的所指名词可从语境恢复。
- **双重所有格**：a friend of **mine**，不用 a friend of my。
- **限定位置**：my、this、the 不叠占同一中心限定位置，用 my book，不用 the my book，详见 [冠词](/docs/note/english/grammar/parts-of-speech/articles)。

<EnglishExamples
  title="物主限定与独立物主形式"
  items={[
    {
      label: '限定名词',
      sentence: 'My book is on the desk.',
      translation: '我的书在桌上。',
      analysis: ['my 限定 book。'],
    },
    {
      label: '独立物主形式',
      sentence: 'This book is mine.',
      translation: '这本书是我的。',
      analysis: ['mine 独立作表语，所指名词由语境恢复。'],
    },
    {
      label: '独立物主形式作主语',
      sentence: 'Yours is on the shelf.',
      translation: '你的在架子上。',
      analysis: ['yours 的所指名词可从语境恢复。'],
    },
  ]}
/>

按是否含动词区分同音形式：

- **its / it's**：its 表所属；it's 缩写 it is 或 it has。

<EnglishExamples
  title="its 与 it's"
  items={[
    {
      label: 'its 表所属',
      sentence: 'The dog wagged its tail.',
      translation: '狗摇了摇尾巴。',
    },
    {
      label: 'it is 的缩写',
      sentence: "It's raining.",
      translation: '正在下雨。',
      analysis: ["it's 在这里展开为 it is。"],
    },
    {
      label: 'it has 的缩写',
      sentence: "It's been a long day.",
      translation: '真是漫长的一天。',
      analysis: ["it's 在这里展开为 it has；has 后接过去分词 been。"],
    },
  ]}
/>

- **their / they're**：their 表所属，they're 缩写 they are。
- **your / you're**：your 表所属，you're 缩写 you are。
- **whose / who's**：whose 表所属，who's 缩写 who is 或 who has，不能把所有 's 都展开为 is。

### 反身代词

**反身代词**（Reflexive Pronoun）在局部结构中指回相应的主语；用于强调时，也可突出某人亲自做某事。

- **可理解宾语的省略**：wash、dress 可不明说反身宾语，如「She washed and dressed.」。

<EnglishExamples
  title="反身、强调与普通宾格"
  items={[
    {
      sentence: 'He hurt himself.',
      label: '反身宾语',
      translation: '他伤到了自己。',
    },
    {
      sentence: 'She taught herself English.',
      label: '反身宾语',
      translation: '她自学英语。',
    },
    {
      sentence: 'He hurt him.',
      label: '与他人对比',
      analysis: ['him 按这一局部结构的普通解读指另一个男性，与 himself 不同。'],
    },
    {
      sentence: 'The president himself answered.',
      label: '亲自强调',
      analysis: ['去掉强调成分后，句子骨架仍成立。'],
    },
    {
      sentence: 'I did the work myself.',
      translation: '这活儿是我自己做的。',
      label: '亲自强调',
      analysis: ['去掉强调成分后，句子骨架仍成立。'],
    },
    {
      sentence: 'I took my bag with me.',
      label: '非反身的同指结构',
      analysis: ['with me 自然，不因 me 与主语同指就一律改成 myself。'],
    },
    {
      sentence: 'Please contact Anna or me.',
      label: '宾格与礼貌',
      analysis: ['本句按普通宾语表达用 me，不能将 myself 当作更礼貌的宾格通用替代。'],
    },
  ]}
/>

常见搭配按意义归组：

- **独自或独立完成**：by oneself，如 by myself；I did it myself 强调亲自做，不必表示无人陪同或帮助。
- **自我活动**：enjoy oneself（玩得开心）、teach oneself（自学）。
- **自取或放松**：help oneself to（自取食物等）、make oneself at home（不拘束）。
- **投入活动**：lose oneself in（沉浸于）。

## 相互代词

**相互代词**（Reciprocal Pronoun）each other、one another 表示成员之间的关系；现代英语中两者都可用于两者或多者。

相互形式的所有格用 each other's、one another's，不用 each others'。

## 指示与疑问

### 指示与替代

- **近指**：this 用于单数，these 用于复数。
- **远指或回指**：that 用于单数，those 用于复数。
- **事件或话语**：this、that 也可指整件事，远近不必是物理距离。
- **电话惯用表达**：用 this/that 识别通话双方，不按中文我、你的词形直接替换。

<EnglishExamples
  title="指示指称与电话表达"
  items={[
    {
      label: 'this 单数',
      sentence: 'This is my book.',
      translation: '这是我的书。',
    },
    {
      label: 'these 复数',
      sentence: 'These are my friends.',
      translation: '这些是我的朋友。',
    },
    {
      label: 'that 远指或回指',
      sentence: 'That is what I mean.',
      translation: '那就是我的意思。',
    },
    {
      label: 'those 复数',
      sentence: 'Those are yours.',
      translation: '那些是你的。',
    },
    {
      label: '电话中自报身份',
      sentence: 'This is Anna speaking.',
      translation: '我是 Anna。',
    },
    {
      label: '电话中询问身份',
      sentence: 'Is that Lisa?',
      translation: '你是 Lisa 吗？',
    },
  ]}
/>

one/ones 替代可数名词，one 用于单数，ones 用于复数；限定方式影响所指。

### 疑问形式

- **who**：询问人的身份，作主语或宾语。
- **whom**：人的宾格形式，偏正式。
- **whose**：询问所属，可独立使用或限定名词。
- **what**：不先建立一组备选项。
- **which**：从语境建立的备选范围选择，也能选人。

what/which 的区别是提问时怎样设定范围，不是客观世界中的选项是否有限。

介词的位置决定正式宾格形式的用法：

- **介词前置的正式结构**：前置介词后用宾格 whom。
- **介词留在句末的自然口语**：可用 who。

<EnglishExamples
  title="疑问句中的介词位置"
  items={[
    {
      label: '前置介词',
      sentence: 'To whom did you speak?',
      translation: '你和谁说了话？',
    },
    {
      label: '句末介词',
      sentence: 'Who did you speak to?',
      translation: '你和谁说了话？',
    },
  ]}
/>

因此，正式结构中前置介词后用 whom，不等于句末有介词时也不能用 who。

### 两者与整体

明确涉及两者时，区分以下 3 个量词：

- **both**：两者都，如 both answers、both of them；作主语用复数。
- **either**：两者中任一，如 either answer、either of them；正式写作按单数。
- **neither**：两者都不，如 neither answer、neither of them；正式写作按单数。

    {
      label: 'either 单数',
      sentence: 'Either is fine.',
      translation: '两个中任一个都可以。',
    },
    {
      label: 'neither 单数',
      sentence: 'Neither is correct.',
      translation: '两个都不正确。',
    },
  ]}
/>

指整个集合或总量时，另看所指的数：

- **all + 可数复数**：全部成员，如 all the books。
- **all + 不可数**：整个量或情状，如 all the water。
- **none + 不可数所指**：没有任何量，用单数谓语。
- **none of + 可数复数**：没有一个，单复数谓语均有标准用例；单数可突出没有任何一个，复数可按多个成员组织一致关系。

<EnglishExamples
  title="整体数量与 none 的一致关系"
  items={[
    {
      label: '多个成员',
      sentence: 'All are ready.',
      translation: '所有人都准备好了。',
    },
    {
      label: '整个情状',
      sentence: 'All is well.',
      translation: '一切都好。',
    },
    {
      label: '不可数总量',
      sentence: 'None of the water was wasted.',
      translation: '这些水一点也没浪费。',
    },
    {
      label: '可数复数所指',
      sentence: 'None of the answers is/are correct.',
      translation: '这些答案都不正确。',
      analysis: ['单复数谓语均有标准用例；单数可突出没有任何一个，复数可按多个成员组织一致关系。'],
    },
  ]}
/>

范围与语体另行检查：

- **否定对象范围**：明确否定两者时，用 neither 更直接；none 也能否定不可数的量，不限于 3 个及以上对象。
- **一致关系的语体**：either/neither of + 复数名词在非正式英语中可见复数谓语；正式写作和多数学校语法题取单数。

### 逐个分配

<EnglishExamples
  title="each 的位置与一致关系"
  items={[
    {
      sentence: 'Each of the students has a book.',
      translation: '每个学生都有一本书。',
      label: 'each 作主语中心',
      analysis: ['单数谓语与 each 一致。'],
    },
    {
      sentence: 'The students each have a book.',
      translation: '学生们每人都有一本书。',
      label: 'each 为附加分配成分',
      analysis: ['主语中心是复数 students。'],
    },
  ]}
/>

- **each 可独立使用**：「Each is different.」；each of us、each student 均成立。
- **every 不直接独立使用**：every student、every one of us，不用 every of us。
- **数量范围**：each 可用于 2 个及以上成员；every 的常见分配用法面向 3 个及以上成员，明确仅两者时用 both 或 each 更自然。
- **every + 数量间隔**：every two days 表每两天一次，即隔一天；它按每个两天的间隔组织，不是 every + 单数名词规则的反例。

否定的位置决定范围：

- **not both**：两个不全成立，至少一个不成立；不保证恰好有一个成立。
- **neither**：两个都不成立。
- **not all**：并非全部成立；**none**：没有一个成立。部分否定不能直接改写为全部否定。
- **on either side of the road**：道路两侧各一边，不能只因 either 表任一就译为仅道路一边。

### 不定数量

|     对象     | 少，近乎没有 | 少，但有一些  |      多      |
| :----------: | :----------: | :-----------: | :----------: |
| 复数可数名词 | few friends  | a few friends | many friends |
|  不可数名词  | little time  | a little time |  much time   |

- few/little 强调数量少或不足，a few/a little 肯定仍有一些；这是语义与语用倾向，不等于说话人的情绪必然消极或积极。
- quite a few 表相当多，不能逐字解释为很少。
- a lot of/lots of 可接复数可数或不可数名词，如 a lot of books、a lot of time。
- 普通肯定句中单独的 much 较正式；日常常用 a lot of。否定、疑问及 so、too 等修饰结构中用 much 自然。

<EnglishExamples
  title="much 与 a lot of 的语境"
  items={[
    {
      label: '日常肯定句',
      sentence: 'We have a lot of time.',
      translation: '我们有很多时间。',
    },
    {
      label: '否定句',
      sentence: "We don't have much time.",
      translation: '我们没有多少时间。',
    },
    {
      label: 'too 修饰 much',
      sentence: 'There is too much noise.',
      translation: '噪声太大了。',
    },
  ]}
/>

some/any 按数量意义及语境判断：

- **some 表一定数量**：肯定有一些。
- **some 用于提供或期待肯定回应**：不是所有问句都用 any。
- **any 用于疑问、否定或条件**：询问不预设一定存在，条件则把存在作为条件。
- **any 表自由选择**：不限于否定或疑问。

<EnglishExamples
  title="some 与 any 的数量语境"
  items={[
    {
      label: '肯定存在',
      sentence: 'I have some questions.',
      translation: '我有一些问题。',
    },
    {
      label: '提供物品',
      sentence: 'Would you like some tea?',
      translation: '你想喝点茶吗？',
    },
    {
      label: '不预设存在的询问',
      sentence: 'Do you have any questions?',
      translation: '你有什么问题吗？',
    },
    {
      label: '否定存在',
      sentence: "I don't have any questions.",
      translation: '我没有任何问题。',
    },
    {
      label: '存在作为条件',
      sentence: 'If you have any questions, ask me.',
      translation: '如果你有什么问题，就问我。',
    },
    {
      label: '自由选择',
      sentence: 'Any student can apply.',
      translation: '任何学生都可以申请。',
    },
  ]}
/>

### 其他与剩余

- **another**：再一个或另一个，如 another book；后接数量短语时还可说 another two days（再两天）。
- **other + 名词**：other books、other information；前有适当限定词时也可接单数，如 my other hand、one other question。
- **others 独立使用**：后面不再直接接名词。
- **the other**：已确定的另一个，如 one hand ... the other；也可限定复数，如 the other students。
- **the others**：某组其余全部，独立使用。

  title="others 与 the others"

### 复合不定代词

|      结尾      |   some-   |   any-   |   every-   |   no-   |
| :------------: | :-------: | :------: | :--------: | :-----: |
|   -one（人）   |  someone  |  anyone  |  everyone  | no one  |
|  -body（人）   | somebody  | anybody  | everybody  | nobody  |
| -thing（事物） | something | anything | everything | nothing |

- **作主语**：接单数谓语；回指人时可用单数 they。

<EnglishExamples
  title="复合不定代词与回指"
  items={[
    {
      label: '单数一致',

- **后接修饰语**：something **important**、nothing **to say**，不用把形容词机械前置。
- **拼写**：no one 分写，英式英语也见 no-one。
- **-one/-body**：多数场景可互换，不按书面或口语一刀切。

## 从句中的代词

### 结构与功能

同一个 who、what、which 或 that，先按所在结构分类，再判断从句内部功能。

- 传统的 **连接代词** 引导名词性从句，并在从句内部作成分。
- 传统的 **关系代词** 引导关系从句，关联先行内容并在内部作成分；现代语法对部分形式另有分析。

<EnglishExamples
  title="同形词在不同从句中的功能"
  items={[
    {
      sentence: 'What do you need?',
      label: '直接疑问',
      analysis: ['直接提出问题，what 作 need 的宾语。'],
    },
    {
      sentence: 'I wonder which book she chose.',
      label: '间接疑问',
      analysis: ['从句作 wonder 的宾语，which 在从句内限定 book。'],
    },
    {
      sentence: 'the book which she chose',
      label: '普通关系从句',
      analysis: ['从句修饰名词 book，which 作 chose 的宾语。'],
    },
    {
      sentence: 'What she chose surprised me.',
      label: '融合关系结构',
      analysis: ['整体接近 the thing that she chose，并作主语。'],
    },
    {
      sentence: 'I know that she left.',
      label: '内容从句',
      analysis: ['that 标记从属，不代替名词，也不在 she left 内作主语或宾语。'],
    },
  ]}
/>

what 的 2 种位置不能混用：

- 有显式名词先行词时，用 the book **that/which** I need，不用 the book what I need 引导普通关系从句。
- 「**What I need** is a book.」没有另一个名词先行词，what 将所指与关系功能融合；传统学校语法常将整体归为名词性从句。

### 关系形式

- **who**：关联人，作主语，也常作宾语。
- **whom**：关联人，作较正式的宾语形式。
- **whose**：关联人或物的所属，如 a house **whose roof** is red。
- **which**：关联物或整个前句，作主语或宾语。
- **that**：关联人或物，用于限制性关系从句；传统分析将其列为关系代词，与内容从句中的连词 that 区分。
- **as**：可关联整个事实，如「**As we expected**, the train was late.」，不必代替前面一个名词。

关系词的可省略性取决于功能与结构：

- **从句主语**：普通关系从句的主语关系词不能直接删除。
- **限制性关系从句的宾语**：在许可省略的结构中可以省去关系词。

<EnglishExamples
  title="关系词的主语与宾语功能"
  items={[
    {
      label: '关系词作从句主语',
      sentence: 'The man who called is my uncle.',
      translation: '打电话的那个人是我叔叔。',
      analysis: ['who 作 called 的主语，不能直接删除。'],
    },
    {
      label: '关系词作从句宾语',
      sentence: 'The book which I bought is useful.',
      translation: '我买的那本书很有用。',
      analysis: ['which 作 bought 的宾语，在这个限制性结构中可以省略。'],
    },
  ]}
/>

### wh-ever 形式

- **泛指所指**：whoever、whatever、whichever 可引导相应结构。
- **内部格决定形式**：whomever 是较正式的宾格形式，需看它在从句内的功能。
- **外层介词不直接决定格**：内部作主语时，不因外层介词而改成宾格。

<EnglishExamples
  title="wh-ever 的内部功能"
  items={[
    {
      label: '整个分句作主语',
      sentence: 'Whoever arrives first may choose a seat.',
      translation: '谁先到，谁就可选座。',
      analysis: ['whoever 在从句内作 arrives 的主语。'],
    },
    {
      label: '外层介词后的分句',
      sentence: 'Give it to whoever needs it.',
      translation: '把它给需要它的人。',
      analysis: ['whoever 作 needs 的主语，不因外层有 to 就改成 whomever。'],
    },
  ]}
/>
