## 句法层级

分析句子时，先分清单位大小，再判断结构形式与句法功能。

- **词**（Word）：词汇与语法的基本单位，如 student、reads。
- **短语**（Phrase）：以中心词组织的单位，也可以只有一个词，如 the young student、very carefully。
- **分句**（Clause）：以谓词为核心的结构，典型形式包含主语与谓语，如 the student reads a book。
- **句子**（Sentence）：能完成一次独立表达的句法单位，可包含 1 个或多个分句，如 The student reads a book, and I take notes.

这些单位可以嵌套：the student **who won the prize** 整体是名词短语，内部又包含关系从句。

### 形式与功能

- **结构形式** 回答「它是什么结构」，如名词短语、关系从句。
- **句法功能** 回答「它在上层结构中做什么」，如主语、宾语、定语。
- 同一功能可由不同形式承担，例如名词短语或从句都能作主语。
- 名词是词类，主语是句法功能，不能把两者当作同一维度的类别。

### 限定与非限定

按动词形式区分：

- **限定分句**（Finite Clause）：包含限定动词，体现时态或情态等语法信息。
- **非限定分句**（Non-finite Clause）：使用不定式、分词等形式，常省略可由上下文确定的主语。

<EnglishExamples
  title="限定形式与非限定结构"
  items={[
    {
      label: '限定谓语',
      sentence: 'She has finished the work.',
      analysis: ['has 是限定形式，finished 是过去分词；has finished 构成谓语动词短语。'],
    },
    {
      label: '不定式',
      sentence: 'She wants to finish the work.',
      analysis: ['to finish the work 是非限定结构。'],
    },
    {
      label: '分词状语',
      sentence: 'Walking along the river, I saw a bird.',
      analysis: ['Walking 的逻辑主语是 I。'],
    },
  ]}
/>

分类时须先确定分析口径：

- **现代语法**：把这些非限定结构也分析为分句。
- **中学语法**：通常称为非谓语动词结构，主要按限定分句划分简单句与复合句。
- 按后者判断时，「Walking along the river, I saw a bird.」仍归为简单句，不能按动词单词数机械计数。

## 分句骨架

先确定主要动词及其补足要求，再识别各成分。

- **S**：主语（Subject）。
- **V**：动词（Verb）。
- **O**：宾语（Object）；IO 和 DO 分别是间接宾语和直接宾语。
- **C**：补语（Complement）；说明主语的补语是表语，说明宾语的补语是宾语补足语。
- **A**：状语（Adverbial），可进一步区分必需成分与可选修饰语。

记号与框架见 [语法总纲](/docs/note/english/grammar)。

### 五种基本句型

- **主谓：S + V**。动词不要求宾语或表语。
- **主系表：S + V + C**。系动词后的表语说明主语。
- **主谓宾：S + V + O**。动词接 1 个宾语，不要求描述该宾语的补语。
- **主谓双宾：S + V + IO + DO**。分别是间接宾语和直接宾语；给予句中常为接收者与给予的事物。
- **主谓宾补：S + V + O + C**。补语说明宾语的身份、性质、状态或动作。

### 必需成分与修饰语

五种句型是入门模型，不能穷尽动词的补足要求。

<EnglishExamples
  title="可选修饰语与必需成分"
  items={[
    {
      label: '可选修饰语',
      sentence: 'I read a book yesterday.',
      analysis: ['yesterday 可省。'],
    },
    {
      label: '必需地点成分',

    },

有些体系因此另列 **S + V + A** 和 **S + V + O + A**。不能把所有介词短语都当作可随意删除的附加信息。

## 结构分类

以下按限定分句之间的关系分类，非限定结构按前述学校语法口径处理。

- **独立分句**（Independent Clause）：具备独立成句的语法条件。
- **从属分句**（Subordinate Clause）：嵌入另一结构，或通过从属关系依附其他分句。

### 判断步骤

1. 找出限定动词，把助动词与主要动词看作一个谓语系统；
2. 标出各分句的主语，区分共享主语的并列谓语与分句并列；
3. 确定从句边界及嵌套层级，统计外层独立分句，并检查有无从属分句；
4. 按下表确定句子结构，再分别分析每个分句的内部成分。

| 独立分句  |         无从属分句          |               有从属分句                |
| :-------: | :-------------------------: | :-------------------------------------: |
|   1 个    |  简单句（Simple Sentence）  |     主从复合句（Complex Sentence）      |
| 至少 2 个 | 并列句（Compound Sentence） | 并列复合句（Compound-complex Sentence） |

<EnglishExamples
  title="4 类句子结构"
  items={[
    {
      label: '简单句',
      sentence: 'I called him.',
    },
    {
      label: '并列句',
      sentence: 'I called him, but he did not answer.',
    },
    {
      label: '主从复合句',
      sentence: 'I called him because I needed help.',
    },
    {
      label: '并列复合句',
      sentence: 'I called him, but he did not answer because he was asleep.',
    },
  ]}
/>

不同教材对 compound、complex 的中文译名不完全一致。课程的简单句、复合句、复杂句三分法与这里的 4 类结构可按英文名称对应；同时含并列与从属的情形归入 Compound-complex。

### 并列成分与并列分句

- **并列主语和谓语** 不自动增加独立分句。
- **2 个独立分句并列** 才构成这里所说的并列句。
- **非限定结构** 不按上述教学口径另计限定分句。

<EnglishExamples
  title="并列成分与独立分句"
  items={[
    {
      label: '并列主语和谓语',
      sentence: 'My brother and I read and write every day.',
      analysis: ['仅有 1 套共享主语的结构，仍是简单句。'],
    },
    {
      label: '共享主语的并列谓语',
      sentence: 'Tom reads and takes notes.',
      analysis: ['2 个谓语共享 Tom。'],
    },
    {
      label: '2 个独立分句',
      sentence: 'Tom reads, and Mary takes notes.',
      analysis: ['2 部分各有自己的主语与谓语。'],
    },
    {
      label: '非限定结构',
      sentence: 'Tom wants to study abroad.',
      analysis: ['非限定结构不按上述教学口径另计限定分句，仍归为简单句。'],
    },
  ]}
/>

and 的数量、动词数量、句子长度都不能单独决定类别。

### 并列分句的连接

先确认连接的是独立分句，再选择连接方式。

- **并列连词**：for、and、nor、but、or、yet、so，可用 FANBOYS 记忆。连词前通常用逗号；极短且联系紧密的分句有时可省。
- **关联结构**：either...or、not only...but also 等。not only 前置并修饰分句谓语时，常触发部分倒装，见 [倒装](/docs/note/english/grammar/sentences/inversion)。
- **分号**：连接 2 个关系紧密的独立分句。
- **连接副词**：however、therefore、moreover 等说明逻辑关系，本身不代替并列连词或边界标点。

<EnglishExamples
  title="独立分句的连接方式"
  items={[
    {
      label: '并列连词 so',
      sentence: 'It rained, so we stayed inside.',
      translation: '下雨了，所以我们待在室内。',
    },
    {
      label: '并列连词 but',
      sentence: 'She is young, but she is wise.',
      translation: '她很年轻，但很有智慧。',
    },
    {
      label: '关联结构 either...or',
      sentence: 'Either you apologize, or I leave.',
      translation: '要么你道歉，要么我离开。',
    },
    {
      label: '关联结构 not only...but also',
      sentence: 'Not only did he come, but he also brought a gift.',
      translation: '他不仅来了，还带了一份礼物。',
      analysis: ['not only 前置并修饰分句谓语时，常触发部分倒装。'],
    },
    {
      label: '分号',
      sentence: 'He did not come; he was ill.',
      translation: '他没来；他病了。',
    },
    {
      label: '连接副词',
      sentence: 'It was raining; however, we went out.',
      translation: '当时在下雨；不过，我们还是出门了。',
    },
    {
      label: '断为两句',
      sentence: 'It rained. Therefore, we stayed inside.',
      analysis: ['也可断为两句，Therefore 不充当并列连词。'],
    },
  ]}
/>

正式写作不能仅用逗号拼接为「It rained, we stayed inside.」。
连词和关联结构也能连接词或短语，仍须逐句检查它们连接的层级。

### 主从关系与嵌套

先确定上层成分，再向内分析：

<EnglishExamples
  title="从句的外层关系"
  items={[
    {
      label: '宾语从句',
      sentence: 'I know that he is right.',
      analysis: ['that he is right 是 know 的宾语。'],
    },
    {
      label: '关系从句',
      sentence: 'The book which I bought yesterday is on the desk.',
      analysis: ['which I bought yesterday 修饰 book。'],
    },
    {
      label: '状语从句',
      sentence: 'He came because he needed help.',
      analysis: ['because 从句说明原因。'],
    },
  ]}
/>

外层主句包含它的从句。I know that he is right 中，I know 只是删去宾语后的骨架，不能一概当作完整主句。

I know **that she believes [that he is honest]**.（我知道她相信他很诚实。）包含以下层级：

- 外层分句：「I know that she believes that he is honest.」。
  - know 的宾语：that she believes that he is honest。
    - believes 的宾语：that he is honest。

最内层从句嵌在 know 的宾语从句内部，不能把 2 个从句都直接平铺到最外层。详细分类见 [从句](/docs/note/english/grammar/sentences/clauses)。

## 句式与用途

句式是另一条分类轴，与简单句、并列句等结构分类相互独立。

- **陈述句**（Declarative）：典型形式为主语在谓语前。
- **疑问句**（Interrogative）：典型形式采用疑问语序，一般疑问句常有主语与助动词倒装。
- **祈使句**（Imperative）：常用动词原形，主语 you 通常不出现。
- **感叹句**（Exclamative）：常由 what 或 how 引导。

句式与交际功能也不完全对应。

  title="句式形式与交际功能"
  items={[

疑问表达还可从答案范围与表达结构两方面描述。

- **按所询问的答案范围**：
  - **一般疑问句**（Yes–No Question）：询问命题是否成立。
  - **特殊疑问句**（Wh-question）：用 wh- 成分询问具体信息。
  - **选择疑问句**（Alternative Question）：要求在给定选项中选择。
- **按是否采用附加结构**：
  - 前 3 个例子都是独立提出的问句。
  - **附加疑问句**（Tag Question）在前面的分句后附加简短问句，须先判断该分句的类型。
