## 简介

**倒装**（Inversion）改变主语和谓语的通常顺序。教学中常分为 **完全倒装**（Full Inversion）与 **部分倒装**（Partial Inversion）。

- **完全倒装**：实义动词或系动词位于后置主语前。
  - The bus comes here. → **Here comes the bus**.
- **部分倒装**：仅第一个助动词、情态动词或作谓语的 be 放到主语前。
  - She has never seen it. → **Never has she seen it**.

谓语仅有系动词 be 时，2 类的表面语序可能重合，不同教材的归类也会有差别。判断具体句子时，应辨认主语、前置成分与动词位置，不能仅按「搬动了几个单词」分类。

不是所有句首成分前置都要倒装。Yesterday I met Tom.（昨天我遇见了 Tom。）的时间状语在句首，主语仍在谓语前。

## 部分倒装的构造

部分倒装也称 **主语与助动词倒装**（Subject–Auxiliary Inversion）。先确认后文列出的触发构式成立，再按已有动词选择操作；不是任意前置成分都启动这一步。

1. **已有助动词或情态动词**：仅提前第一个，其余动词保持原位；
2. **没有上述助动词，但谓语是 be**：提前 be；
3. **一般现在或一般过去的实义动词**：按时态和主语补 do、does 或 did，再把实义动词恢复原形。

助动词链中的后续部分保持原位。不能把 have been 全部搬到主语前，也不能在 did 后继续用过去式。

## 部分倒装的条件

### 疑问句

疑问结构先区分嵌入与独立问句；独立问句再按疑问成分的作用判断。

1. **嵌入疑问**：嵌入部分用陈述语序，不照搬直接问句的倒装；
2. **独立的一般疑问句**：询问整个命题是否成立，使用主语与助动词倒装；
3. **独立的非主语特殊疑问句**：采用疑问词前置时，先前置疑问成分，再构造相应的一般疑问语序；
4. **独立的主语疑问句**：疑问成分直接占据主语位置，不作这种倒装。

### 否定成分前置

否定前置倒装多用于正式表达。采用该构式时，依次检查：

1. **成分有没有否定或近否定意义**：如 never、little、at no time；
2. **它在句中是什么作用**：前置状语或否定宾语可触发，否定主语不触发；
3. **它是否前置并作用于该分句**：留在句中的 never 不触发；作用于外层主句的 not until，从句内部不倒装。

常见前置成分如下。

- **否定或近否定频率**：never、rarely、seldom。
- **表示「几乎不知道」的 little**。
- **否定时间或方式状语**：at no time、in no way。
- **否定条件或理由状语**：on no account、under no circumstances。
- **not only 前置并作用于谓语内容**：前一分句倒装，but 后的分句保持原顺序。

  items={[
    {

      sentence: 'Never have I seen such a sight.',
      translation: '我从未见过这样的景象。',
    },
    {
      label: 'little',
      sentence: 'Little did he know what would happen.',
      translation: '他几乎不知道将要发生什么。',
    },
    {
      label: '否定时间',
      sentence: 'At no time did we agree to this.',
      translation: '我们从未同意过此事。',
    },
    {
      label: '否定条件',
      sentence: 'Under no circumstances should you open this door.',
      translation: '任何情况下你都不应打开这扇门。',
    },
    {
      label: 'not only',
      sentence: 'Not only did she apologise, but she also offered to help.',
      translation: '她不仅道歉，还提出帮忙。',
      analysis: ['前一分句倒装，but 后的分句保持原顺序。'],
    },
  ]}
/>

否定宾语前置也可触发部分倒装：I did not say **a single word**. → **Not a single word did I say**.（我一句话也没说。）这里 a single word 是 say 的宾语，不是状语。

规则针对 **否定成分的句法作用、位置与范围**，不是看到否定词就倒装。

  title="否定词不触发倒装的边界"

    },

    },
  ]}
/>

### not until 与先后结构

**Not until + 时间短语或从句** 前置时，倒装发生在 **主句**，until 从句内部保持陈述语序。

<EnglishExamples
  title="not until 前置的作用范围"
  items={[
    {
      label: '原句',
      sentence: 'We did not begin until he arrived.',
    },
    {
      label: '主句倒装',
      sentence: 'Not until he arrived did we begin.',
      translation: '直到他到场，我们才开始。',
    },
  ]}
/>

不能写成 Not until did he arrive we began.

表示「刚……就……」时，常见以下搭配：

- **hardly/scarcely...when...**。
- **no sooner...than...**。

<EnglishExamples
  title="先后结构的固定搭配"
  items={[
    {
      label: 'hardly/scarcely...when',
      sentence: 'Hardly had I sat down when the phone rang.',
      translation: '我刚坐下，电话就响了。',
    },
    {
      label: 'no sooner...than',
      sentence: 'No sooner had I arrived than it began to rain.',
      translation: '我一到就下起了雨。',
    },
  ]}
/>

过去叙事中，先发生的事件常用过去完成时，后发生的事件常用一般过去时。不要把 when 与 than 对换，也不要连后一个分句一起倒装。

### only 加状语前置

在 **only + 状语前置** 构式中，先识别 only 限定的对象。若它限定时间、方式或条件状语，把整个状语前置后，对主句作部分倒装；若它限定主语，则不适用。

<EnglishExamples
  title="only 前置的状语类型"
  items={[
    {
      label: '时间',
      sentence: 'Only then did I realise my mistake.',
      translation: '直到那时，我才意识到自己的错误。',
    },
    {
      label: '方式',
      sentence: 'Only by checking the data can we find the cause.',
      translation: '只有检查数据，我们才能找到原因。',
    },
    {
      label: '时间从句',
      sentence: 'Only when he arrived did the meeting begin.',
      translation: '直到他到场，会议才开始。',
    },
  ]}
/>

only when 后的从句仍用 he arrived，倒装的是主句 did the meeting begin。

<EnglishExamples
  title="only 的位置与作用范围"
  items={[
    {

    },
    {

### so、neither 与 nor

承接前句表示另一个人或事物「也一样」时，用 **so + 助动词 + 主语**；否定承接用 neither 或 nor。

- **肯定承接** 用 so，**否定承接** 用 neither 或 nor。
- **完成形式** 保留相应助动词。
- **句末 too/either** 也可表示相应承接，不要求倒装。
- **so + 主语 + 助动词** 不倒装，表示认同原判断，常译为「的确如此」。

助动词需匹配前句的时态、情态与新主语，不能把所有情况都写成 so do I。不能把表示否定承接的 neither 句式改成 Neither I can。

<EnglishExamples
  title="肯定、否定承接与认同"
  items={[
    {
      label: '一般现在时承接',
      sentence: 'Lily likes music. So do I.',
      translation: 'Lily 喜欢音乐，我也喜欢。',
    },
    {
      label: 'be 承接',
      sentence: 'He is tired. So am I.',
      translation: '他累了，我也累了。',
    },
    {
      label: 'neither 否定承接',
      sentence: 'He cannot swim. Neither can I.',
      translation: '他不会游泳，我也不会。',
    },
    {
      label: 'nor 否定承接',
      sentence: 'He cannot swim. Nor can I.',
      analysis: ['nor 可替换这种否定承接中的 neither。'],
    },
    {
      label: '完成形式承接',
      sentence: 'She has finished. So have I.',
      translation: '她完成了，我也完成了。',
      analysis: ['保留相应助动词。'],
    },
    {
      label: '句末 too',
      sentence: 'I like music too.',
      translation: '我也喜欢音乐。',
      analysis: ['也可不倒装而用句末 too。'],
    },
    {
      label: '句末 either',
      sentence: 'I cannot swim either.',
      translation: '我也不会游泳。',
      analysis: ['也可不倒装而用句末 either。'],
    },
    {
      label: '认同原判断',
      sentence: '"He is tired." "So he is."',
      translation: '「他累了。」「确实如此。」',
      analysis: ['so + 主语 + 助动词不倒装，表示认同原判断。'],
    },
  ]}
/>

### 省略 if 的条件句

省 if 的条件倒装用于下列正式条件结构。先确认已有 **were、完成助动词 had 或 should**，再省 if 并提前相应动词；不是先删除 if，再任意补一个助动词。详见 [动词语气](/docs/note/english/grammar/verbs/verb-moods)。

- **were 条件结构**：删除 if，把 were 放到主语前，其余内容保持顺序。
- **had + 过去分词条件结构**：删除 if，把完成助动词 had 放到主语前。
- **should + 原形条件结构**：删除 if，把 should 放到主语前。

<EnglishExamples
  title="省略 if 的条件结构"
  items={[
    {
      label: 'were 条件',
      sentence: 'Were I you, I would wait.',
      analysis: [
        '对应原句：If I were you, I would wait.',
        '删除 if，把 were 放到主语前，其余内容保持顺序。',
      ],
    },
    {
      label: 'were to 条件',
      sentence: 'Were she to return, we would welcome her.',
      analysis: [
        '对应原句：If she were to return, we would welcome her.',
        '只提前 were，to return 保持原位。',
      ],
    },
    {
      label: 'had 条件',
      sentence: 'Had I known, I would have helped.',
      analysis: ['对应原句：If I had known, I would have helped.', '提前完成助动词 had。'],
    },
    {
      label: 'should 条件',
      sentence: 'Should you need help, please call me.',
      analysis: ['对应原句：If you should need help, please call me.', '提前 should。'],
    },
  ]}
/>

这不是「任意条件句都能删 if 再倒装」。通常不能把 If he comes, ... 改成 Comes he, ... 或 Does he
come, ...

否定词通常放在主语后：**Had I not checked**, I would have missed the error.（若没有检查，我就会漏掉这个错误。）

### 程度前置与祝愿

正式表达中，**so + 形容词或副词** 提到句首，可伴随倒装。

  title="程度成分前置"
  items={[
    {

      sentence: 'So difficult was the task that nobody finished it.',
      translation: '任务太难，没有人完成。',
    },

**May + 主语 + 动词原形** 可表达祝愿：**May you succeed!**（愿你成功！）这不是一般疑问句。

## 完全倒装

### 地点与方向前置

地点、方向成分前置时，部分不及物谓语可放在名词主语前。常见动词包括 be、come、go、stand、sit、lie 等。这种结构常先交代场景，再引出人物或事物。

<EnglishExamples
  title="地点、方向与阶段引入"
  items={[
    {
      label: 'here',
      sentence: 'Here comes the bus.',
      translation: '公交车来了。',
    },
    {
      label: '地点',
      sentence: 'On the hill stood an old castle.',
      translation: '山丘上矗立着一座古堡。',
    },
    {
      label: '方向',
      sentence: 'Out rushed the children.',
      translation: '孩子们冲了出去。',
    },
    {
      label: 'now',
      sentence: 'Now comes your turn.',
      translation: '现在轮到你了。',
    },
    {
      label: 'then',
      sentence: 'Then came the difficult part.',
      translation: '然后到了困难的部分。',
    },
  ]}
/>

now、then 等时间副词在引出新阶段或新事件时，也可出现类似语序。这不等于所有时间状语前置都要倒装。
选用这类完全倒装，需同时满足场景引入、适合后置主语的谓语结构及名词主语等条件。**地点前置本身不决定倒装**：On the hill, we had a picnic.（我们在山丘上野餐。）仍用正常语序。

此类地点或方向倒装通常要求主语为名词短语；主语为人称代词时一般保持正常语序。

- **主语是名词短语，且采用场景引入结构**：可把主语放在谓语后。
- **主语是普通人称代词**：这类 here/away 结构保留主语在动词前。

<EnglishExamples
  title="地点或方向结构的主语限制"
  items={[
    {
      label: '名词主语',
      sentence: 'Here comes Tom.',
      analysis: ['名词短语主语在场景引入结构中可后置。'],
    },
    {
      label: '名词主语',
      sentence: 'Away went the children.',
      analysis: ['名词短语主语在场景引入结构中可后置。'],
    },
    {
      label: '人称代词主语',
      sentence: 'Here he comes.',
      analysis: ['普通人称代词在这类 here 结构中保持在动词前。'],
    },
    {
      label: '人称代词主语',
      sentence: 'Away they went.',
      analysis: ['普通人称代词在这类 away 结构中保持在动词前。'],
    },
  ]}
/>

代词限制针对这类完全倒装，不适用于 Never have **I** seen it. 等部分倒装。

### 表语前置

表语前置有时伴随系动词与主语位置变化，常见于书面表达。

<EnglishExamples
  title="表语前置与后置主语"
  items={[
    {
      label: '过去分词表语',
      sentence: 'Gone are the days when we had no clean water.',
      translation: '没有洁净用水的日子已经过去了。',
    },
    {
      label: '复数主语',
      sentence: 'Present at the meeting were three teachers.',
      translation: '出席会议的有 3 位老师。',
    },
    {
      label: 'such 表语',
      sentence: 'Such were his tricks.',
      translation: '这就是他的把戏。',
    },
    {
      label: 'such 与结果',
      sentence: 'Such was his excitement that he could not speak.',
      translation: '他激动得说不出话。',
    },
    {
      label: '单数主语',
      sentence: 'Present at the meeting was one teacher.',
      analysis: ['谓语的数取决于后面的主语，而不是前置表语，因此用 was。'],
    },
  ]}
/>

such 作前置表语也有类似结构，还可接结果从句。不必把所有 such 加名词结构都机械搬到句首。谓语的数取决于后面的主语，而不是前置表语。

### 引述语倒装

直接引语在前时，后面的引述语有时把名词主语放在 say、ask 等动词后。

<EnglishExamples
  title="引述语倒装的名词主语"
  items={[
    {
      label: 'say',
      sentence: '"I am ready," said Lily.',
      translation: '「我准备好了。」Lily 说。',
    },
    {
      label: 'ask',
      sentence: '"Are you sure?" asked the teacher.',
      translation: '「你确定吗？」老师问道。',
    },
  ]}
/>

这是引述结构的倒装，不要求谓语像地点倒装那样是不及物动词。主语为人称代词时，普通叙述通常用 **she said**，said she 带有文学或旧式色彩。标点见 [标点](/docs/note/english/grammar/sentences/punctuation)。

### there 存在句

There is a book on the desk. 表示「桌上有一本书」，不等于 The book is there. 的简单语序交换。

现代语法常把存在句中的 there 分析为 **形式主语**。它与表示「那里」的地点副词 there 不同，因此不宜把所有 there be 句都仅解释为普通完全倒装。

## 前置与倒装的边界

### as 与 though 让步

学校语法常把下列结构归入让步倒装，但它实际是 **表语、状语或动词前置**，不等同于把助动词移到主语前。

<EnglishExamples
  title="让步前置的成分类型"
  items={[
    {
      label: '形容词前置',
      sentence: 'Tired as he was, he kept working.',

构造时保留主语与剩余谓语的顺序：Tired as **he was**，不能写 Tired as was he。

- **单数可数名词作前置表语**：采用 Child as he is 这类构式时，不保留原来的不定冠词 a。
- **形容词、副词或动词前置**：分别按 Tired、Hard、Try 的例子保留其余结构，不从一个词类机械类推另一个。
- **连接词**：as 和部分 though 让步构式允许这种前置，although 不作为这套前置句型的替换词。

### 感叹与关联结构

有些教材还把下列结构称为形式倒装。它们的共同点是某些成分前置，**从句内部通常仍保持主语在助动词或谓语前**。

as 让步还常用 **Much as I admire her, I disagree with her**.（尽管我很钦佩她，我仍与她意见不同。）这些形式不能与 Never have I... 的助动词前置机械归为同一条规则。

### 其他前置

often、well、many a time 等前置后，文学或修辞语境中偶有倒装。但它们不构成普通写作必须套用的规则：**Often he visits us** 与 **He often visits us** 都不因 often 而必须倒装。

例如 **Many a time has he helped me**.（他多次帮助过我。）保留 has he helped 的助动词倒装；它是带修辞色彩的选择，不意味着所有句首频率状语都要求倒装。

威廉·莎士比亚（William Shakespeare，1564 – 1616）的《十四行诗第 18 首》中，**And often is his gold complexion dimmed**. 也采用文学性的 is 前置。普通散文可写 And his gold complexion is often dimmed. 诗歌语序受节奏与修辞影响，不应据此推出新的强制倒装规则。

**It was Tom that called me** 是 [强调句](/docs/note/english/grammar/sentences/emphasis)，不是倒装。判断倒装应检查主语与动词的位置，而不能仅凭语气强烈。
