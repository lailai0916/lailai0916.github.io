## 简介

**强调**（Emphasis）突出一句话中的特定信息，可以通过重音、语序、词语或专门句型实现。

语法结构本身不能完全决定焦点，语境与口语重音也参与解释。

<EnglishExamples
  title="重音与焦点"
  items={[
    {
      label: '重读主语',
      sentence: 'TOM borrowed my bike.',
      translation: '借我自行车的是 Tom。',
    },
    {
      label: '重读限定词',
      sentence: 'Tom borrowed MY bike.',
      translation: 'Tom 借的是我的自行车。',
    },
    {
      label: '重读助动词',
      sentence: 'Tom DID borrow my bike.',
      translation: 'Tom 确实借了我的自行车。',
    },
  ]}
/>

大写在这里仅标示重读，普通写作不必把强调词全部大写。

口语还可借助语调与 Wow!、Oh! 等叹词表达态度；书面格式可用加粗、斜体或适当标点突出信息。它们与下面的语法句型属于不同层面，不能把所有强调都等同于 It is...that...

- **突出某个句子成分**：用 it 分裂句，如 It was **Tom** that called.
- **突出所需事物或所做动作**：用 wh 分裂句，如 **What I need is a break**.
- **证实或反驳整个判断**：重读助动词，如 I **do** understand.
- **限定或扩展焦点范围**：用 only、even 等，如 **Only Tom** knew.
- **利用语序或重复加强表达**：按倒装构式的条件选择，或用 again and again 等重复形式。

## it 分裂句

### 结构与焦点

**分裂句**（Cleft Sentence）把一个命题拆为 2 个部分。最常见的 **it 分裂句**（It-Cleft Sentence）采用 **It + be + 焦点 + that/who + 其余部分**。

构造 it 分裂句时，按以下顺序判断：

1. **选出要对比的成分**，并确认它在原句中的位置；
2. **把该成分移到 It + be 后**，保留它内部的介词等结构；
3. **原位置留空**，用 that 或相应的人称连接形式接回其余部分；
4. **按辨认或叙述的时间视角选择 be**，再检查后面从句的主谓一致。

<EnglishExamples
  title="it 分裂句的焦点位置"

    {

      translation: 'Tom 昨天在公园遇见了 Lily。',
    },
    {
      label: '焦点是主语',
      sentence: 'It was Tom who met Lily in the park yesterday.',
      translation: '昨天在公园遇见 Lily 的是 Tom。',
    },
    {
      label: '焦点是宾语',
      sentence: 'It was Lily that Tom met in the park yesterday.',
      translation: 'Tom 昨天在公园遇见的是 Lily。',
    },
    {
      label: '焦点是地点',
      sentence: 'It was in the park that Tom met Lily yesterday.',
      translation: 'Tom 昨天是在公园遇见 Lily 的。',
    },
    {
      label: '焦点是时间',
      sentence: 'It was yesterday that Tom met Lily in the park.',
      translation: 'Tom 是昨天在公园遇见 Lily 的。',
    },
  ]}
/>

状语焦点还可以是原因或方式，不限于时间和地点。

<EnglishExamples
  title="原因与方式作分裂句焦点"
  items={[
    {
      label: '原因焦点',

    },
    {

      translation: '我们是通过合作解决这个问题的。',
    },
  ]}
/>

it 是结构中的形式成分，be 通常保持单数：**It is the students who need help.**（需要帮助的是这些学生。）不能因焦点 students 是复数而写成 It are。

普通 it 分裂句不直接把一个孤立的谓语动词放到焦点位置。强调动作可用助动词重读或后面的 wh 分裂句。

### 连接形式

在学校语法和基础书面表达中，按焦点所指对象及其句法作用选择连接形式。

1. **焦点指人**：
   - 在其余部分作主语，用 that 或 who。
   - 在其余部分作宾语，可用 that 或 who；较正式的 whom 也可见。
2. **焦点指物、时间、地点、原因或方式**：基础书面句型用 that。

<EnglishExamples
  title="分裂句的连接形式"
  items={[
    {
      label: '指人：主语焦点',
      sentence: 'It was Tom who called.',
      analysis: [
        '焦点指人并在其余部分作主语，用 that 或 who；也可写作「It was Tom that called.」。',
      ],
    },
    {
      label: '指人：宾语焦点',
      sentence: 'It was Tom that I called.',
      analysis: ['焦点指人并在其余部分作宾语，可用 that 或 who；较正式的 whom 也可见。'],
    },
    {
      label: '指物',
      sentence: 'It was this book that I bought.',
    },
    {
      label: '地点介词保留',
      sentence: 'It was in London that we met.',
      analysis: ['地点介词 in 保留，不改用 where 代替该句型中的 that。'],
    },
  ]}
/>

**不要把普通定语从句的关系词选择直接搬过来**。标准基础句型写 It was in London **that** we met. 不因焦点是地点而机械换成 where；物作焦点也通常不用 which。

非正式表达中，连接词在不承担从句主语时有时可省略：**It was Lily I met**.（我遇见的是 Lily。）正式写作中保留 that 更清楚。若连接词承担从句主语，通常保留：It was Lily **who called**.

### 时间视角与一致

is 与 was 常随现在或过去语境选择，但 **不必机械复制从句时态**。

  title="分裂句的时间视角"
  items={[
    {
      label: '过去叙述',
      sentence: 'It was Tom who called yesterday.',
      translation: '昨天打电话的是 Tom。',
      analysis: ['以过去事件为叙述视角。'],
    },
    {
      label: '现在辨认',
      sentence: 'It is Tom that you saw yesterday.',
      translation: '你昨天看见的就是 Tom。',
      analysis: ['现在辨认昨天所见的人。'],
    },
    {
      label: '将来表达',
      sentence: 'It will be Lily who leads the team next year.',
      translation: '明年带队的将是 Lily。',
      analysis: ['be 也可以采用将来表达。'],
    },
  ]}
/>

从句若由焦点成分充当主语，谓语通常按该成分确定数。

<EnglishExamples
  title="焦点与 who 从句的一致"
  items={[
    {
      label: '单数焦点',
      sentence: 'It is Tom who knows the answer.',
      translation: '知道答案的是 Tom。',
    },
    {
      label: '复数焦点',
      sentence: 'It is the students who know the answer.',
      translation: '知道答案的是这些学生。',

/>

这里 the students 决定 who 从句中用 know，而结构开头仍用 It is。其他一致关系见 [主谓一致](/docs/note/english/grammar/sentences/subject-verb-agreement)。

人称代词存在正式与口语差异。正式学校语法常用「**It is I who am responsible**.」；口语常用 **It's me** 作焦点，人称呼应也有变体。备考改写宜采用题目要求的正式形式，不把一种语体的形式推广成所有英语的唯一答案。

### 否定与疑问

否定可落在焦点上：**It wasn't Tom who called**.（打电话的不是 Tom。）这不等于 Tom 没有做任何事情，而是在排除这个焦点。

构造疑问时，先确定分裂句外层谓语的形式。外层提问不使 that/who 后的从句倒装。

1. **询问某个给定焦点是否正确**：保留焦点与其余部分，再调整外层谓语；
   - **只有 is、was 等限定 be**：把 be 放在 it 前。
   - **已有 will 等助动词或情态动词**：只提前第一个，其余动词保留在 it 后。
2. **询问焦点本身**：用疑问词替换焦点并前置，再按相同条件安排外层谓语；
   - **只有限定 be**：疑问词 + be + it + that + 其余部分。
   - **已有 will 等助动词或情态动词**：疑问词 + 第一个助动词 + it + 其余动词 + that + 其余部分。
3. **把上述问题嵌入另一分句**：疑问词保留在前，恢复 it + 完整谓语的陈述语序。

<EnglishExamples
  title="分裂句的独立疑问与嵌入疑问"
  items={[
    {
      label: '一般疑问：限定 be',
      sentence: 'Was it Tom that called?',
      translation: '打电话的是 Tom 吗？',
    },
    {
      label: '一般疑问：will be',
      sentence: 'Will it be Lily who leads the team next year?',
      translation: '明年带队的将是 Lily 吗？',
    },
    {
      label: '询问人物：限定 be',
      sentence: 'Who was it that called?',
      translation: '打电话的究竟是谁？',
    },
    {
      label: '询问时间：限定 be',
      sentence: 'When was it that you met him?',
      translation: '你究竟何时遇见他的？',
    },
    {
      label: '询问地点：限定 be',
      sentence: 'Where is it that you live?',
      translation: '你究竟住在哪里？',
    },
    {
      label: '询问人物：will be',
      sentence: 'Who will it be that leads the team next year?',
      translation: '明年带队的究竟会是谁？',
    },
    {
      label: '嵌入疑问：限定 be',
      sentence: 'I wonder when it was that you met him.',
      translation: '我想知道你究竟何时遇见他的。',
    },
    {
      label: '嵌入疑问：will be',
      sentence: 'I wonder who it will be that leads the team next year.',
      translation: '我想知道明年带队的究竟会是谁。',
    },
  ]}
/>

- 疑问词承担原焦点的作用，不能在同一焦点位置重复填入答案。
- Who will it be that... 中，who 对应 that 从句的主语位置，外层分裂句的主语仍是 it；不能因此把整句当成无需倒装的普通主语疑问句。
- 嵌入疑问保留 when it was、who it will be，不能照抄独立问句的 when was it、who will it be。

**not until** 可作为完整焦点进入分裂句：

<EnglishExamples
  title="not until 的不同强调形式"
  items={[
    {
      label: '原句',
      sentence: 'I did not understand it until yesterday.',
    },
    {
      label: 'it 分裂句',

      translation: '我直到昨天才明白。',
      analysis: ['that 后不倒装，句内强调与倒装要分别判断。'],
    },
    {

      sentence: 'It was not until he arrived that we began.',
    },
    {
      label: '另加 do 强调',
      sentence: 'It was not until he arrived that we did begin.',
      analysis: ['主语 we 仍在 did 前，不能写 that did we begin。'],
    },
    {
      label: '否定状语前置倒装',
      sentence: 'Not until yesterday did I understand it.',
      analysis: ['与分裂句中的陈述语序区分。'],
    },
  ]}
/>

倒装触发条件见 [倒装](/docs/note/english/grammar/sentences/inversion)。

### 与其他 it 结构的区别

把焦点放回原来的位置，能恢复原命题，是识别 it 分裂句的实用方法；但它只是辅助检查，还需看句法关系与语义。

<EnglishExamples
  title="相似 it 结构的区别"
  items={[
    {
      label: 'it 分裂句',
      sentence: 'It was at midnight that he returned.',
      analysis: ['焦点可放回其余部分，恢复为「He returned at midnight.」。这是分裂句。'],
    },
    {
      label: 'when 时间从句',
      sentence: 'It was midnight when he returned.',
      translation: '他回来时是午夜。',
      analysis: ['when 从句交代时间。'],
    },
    {
      label: '形式主语 it',
      sentence: 'It is true that he returned.',
      analysis: ['it 代替内容从句作形式主语；被判断为真的内容是 that 从句。'],
    },
    {
      label: 'since 标记起点',
      sentence: 'It has been three years since he returned.',
      translation: '距他回来已经过去 3 年。',
    },
  ]}
/>

不能把所有 It is/was... 开头的句子都归为强调句，也不能把分裂句中的 that 一律解释为修饰焦点名词的普通定语从句关系词。

## wh 分裂句

**wh 分裂句**（Wh-Cleft Sentence），也称伪分裂句，常用 **what 引导的从句 + be + 焦点**。what 从句通常交代已知或待说明的内容，be 后给出焦点。

<EnglishExamples
  title="wh 分裂句的焦点"
  items={[
    {
      label: '所需事物',
      sentence: 'What I need is a break.',
      translation: '我需要的是休息。',
    },
    {
      label: '令人吃惊的事',
      sentence: 'What surprised me was his honesty.',
      translation: '让我吃惊的是他的诚实。',
    },
    {
      label: '所做动作',
      sentence: 'What she did was cancel the meeting.',
      translation: '她做的事情是取消会议。',
    },
  ]}
/>

最后一句把动作 cancel the meeting 放到焦点位置。因此，「英语强调结构都不能突出动作」范围过大；限制主要针对普通 it 分裂句直接强调孤立谓语动词的做法。

## 助动词强调

陈述句与疑问句先检查已有的助动词、情态动词或 be，再判断能否补 do。祈使句按独立构式处理。

### 已有助动词的情况

陈述句或疑问句已有助动词、情态动词或 be 时，重读已有动词，不再额外插入 do。

<EnglishExamples
  title="重读已有助动词或 be"
  items={[
    {
      label: '完成助动词',
      sentence: 'I HAVE finished it.',
      translation: '我确实完成了。',
    },
    {
      label: '情态动词',
      sentence: 'She CAN swim.',
      translation: '她真的会游泳。',
    },
    {
      label: '系动词 be',
      sentence: 'He IS ready.',
      translation: '他确实准备好了。',
    },
  ]}
/>

不能写成「I do have finished it.」「She does can swim.」或「He does be ready.」。

否定句和疑问句本来就可能需要 do，此时也能重读原有助动词表达态度。因此，「否定句和疑问句永远不能强调」不成立。

### do、does 与 did

若普通肯定陈述句的谓语是实义动词，且没有上述助动词、情态动词或 be，再按时间和主语分支添加 **do/does/did + 动词原形**：

1. **一般现在时**：第三人称单数用 does + 原形，其他主语用 do + 原形；
2. **一般过去时**：用 did + 原形。

<EnglishExamples
  title="do 强调与实义动词原形"
  items={[
    {
      label: 'does',
      sentence: 'She does know the answer.',
    },
    {
      label: 'do',
      sentence: 'I do understand.',
    },
    {
      label: 'did',
      sentence: 'He did come yesterday.',
      translation: '他昨天确实来了。',
    },
  ]}
/>

**时态和人称已经由 do/does/did 承担，后面的动词用原形**。He did went. 与 She does knows. 都不成立。

### 祈使句

肯定祈使句可在原形前加 do，加强请求或劝告；这一构式也允许 do + be。

<EnglishExamples
  title="祈使句中的 do 强调"
  items={[
    {
      label: '加强请求',
      sentence: 'Do sit down.',
      translation: '请坐下吧。',
    },
    {
      label: 'do + be',
      sentence: 'Do be careful.',
      translation: '务必小心。',
    },
  ]}
/>

祈使句中的 Do be careful 不能推广为普通陈述句中的 He does be careful.

## 强调词与作用范围

### 反身代词

**反身代词**（Reflexive Pronoun）可作强调成分，表示亲自或本人。

<EnglishExamples
  title="反身形式作强调成分"
  items={[
    {
      label: '强调本人',
      sentence: 'The teacher himself checked the papers.',
      translation: '老师亲自检查了试卷。',
    },
    {
      label: '强调亲自看见',
      sentence: 'I saw it myself.',
      translation: '我亲眼看见了。',
    },
  ]}
/>

部分语法体系把这种强调用法单列为 **强调代词**（Intensive Pronoun）。它与反身宾语使用相同形式，但句法功能不同，不能仅凭 myself 等词形决定分析。

与反身宾语比较：He hurt **himself**. 中 himself 是 hurt 的宾语，不能仅当作随意删去的强调词。

### 强调副词与程度词

程度词和加强断言的副词需服从各自搭配，不能相互无条件替换。

- **加强断言**：indeed、really、truly。
- **加强可分级形容词或副词的程度**：very、really。
  - **very fast**、**really interesting**。
- **表示强程度或完整程度**：absolutely、completely、totally，按各自搭配选择。
  - **absolutely sure**、**completely wrong**、**totally different**。
- **突出「简直、恰好」等意义**：just，具体解释依语境。
- **扩展相关时间范围**：ever。
  - ever 不是过去时标记；例句的过去视角由 wanted、was 表达。

  title="加强断言与范围的具体搭配"

### the very

**the very + 名词** 强调恰好是某个对象；**the very + 最高级** 加强最高程度。

the **very beginning** 表示最开始的部分，与 very fast 中的程度修饰不同。

### only 与 even

**焦点词**（Focus Particle）的含义取决于它作用于哪个成分。位置与重音共同决定解释。

  ]}
/>

不能把 only、even 都当成不影响命题范围的普通语气加强词。正式写作宜让它们靠近所作用的成分，减少歧义。

### 疑问表达

  title="加强疑问语气的表达"

      translation: '你到底在做什么？',

/>

the hell 等也会加强疑问语气，但带有强烈情绪或粗俗色彩，不能当作 on earth 在所有语境中的中性替换。

## 感叹、倒装与重复

感叹句本身也能突出程度，注意 what 与 how 所带成分不同。

- **突出形容词或副词的程度**：How + 形容词或副词 + 主语 + 谓语。
- **突出名词短语**：What + 名词短语 + 主语 + 谓语。

<EnglishExamples
  title="what 与 how 感叹结构"
  items={[
    {
      label: '突出程度',
      sentence: 'How useful this book is!',
    },
    {
      label: '突出名词短语',
      sentence: 'What a useful book you found!',
    },
  ]}
/>

感叹句中的主语与谓语通常不倒装；不能因为语气强烈就写成 How useful is this book! 来替代这一常规句型。

倒装与重复则可改变信息呈现方式或加强持续、递进的意味。

倒装的触发条件详见 [倒装](/docs/note/english/grammar/sentences/inversion)。
on earth 等带有明显语气，倒装也常有正式或修辞色彩。考试写作应按语境使用，不必为显得复杂而堆叠强调形式。
