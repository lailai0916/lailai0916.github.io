## 简介

**系动词**（Linking Verb），又称 **连系动词**，连接主语与 **主语补足语**（Subject Complement，传统称 **表语**）。表语说明主语的身份、性质或状态。基本结构为 **主语 + 系动词 + 表语**。

表语可以说明身份、类别、性质或状态：

<EnglishExamples
  title="系动词与表语"
  items={[
    {
      sentence: 'She became a doctor.',
      label: '身份或类别',
      translation: '她成了医生。',
      analysis: ['a doctor 说明 she 获得的身份。'],
    },
    {
      sentence: 'The sky is blue.',
      label: '性质或状态',
      translation: '天空是蓝色的。',
      analysis: ['blue 描述 sky 的颜色。'],
    },
  ]}
/>

表语不是动作承受者，不能把动词后面的成分都判作宾语。系动词也有意义差别：be 主要起连接作用，become 表变化，remain 表持续，seem 表判断中的不确定性。

## 表语形式

be 可接以下形式；其他系动词须按各自搭配选用，不能任意替换。

- **名词短语（含代词单独使用）**：可说明身份、归属、数量等，包括普通名词短语、代词和度量名词短语。
- **形容词短语**：说明性质或状态。
- **介词短语**：说明状态。
- **分句**：可说明目标、活动或命题内容，包括不定式分句、-ing 分句和 that 分句。

  title="表语的形式"

    },
    {
      sentence: 'The price is fifty dollars.',
      label: '度量名词短语',
      translation: '价格是五十美元。',
      analysis: ['fifty dollars 表示金额，仍是名词短语。'],
    },
    {
      sentence: 'He looks very tired.',
      label: '形容词短语',
      translation: '他看起来很累。',
    },
    {
      sentence: 'She is in trouble.',
      label: '介词短语',
      translation: '她有麻烦了。',
    },
    {
      sentence: 'My goal is to study abroad.',
      label: '不定式分句',
      translation: '我的目标是出国学习。',
    },
    {
      sentence: 'Her hobby is collecting stamps.',
      label: '-ing 分句',
      translation: '她的爱好是集邮。',
    },
    {
      sentence: 'The truth is that he lied.',
      label: 'that 分句',
      translation: '事实是他撒了谎。',
    },
  ]}
/>

搭配与分析须分 2 种情况：

- **动词选择受限**：seem to know 是自然结构，become to know 不是 become 的常规搭配。
- **语法体系命名不同**：He is **in the room**. 中，地点短语 in the room 在学习语法中常归为表语，部分体系另称地点补足语。这 2 种分析都不把它当作宾语。

## 语义分类

以下按主要意义分组，组间可以重叠；look 同时涉及外在表象和视觉感知。

### 状态系动词

**be** 连接主语与当前性质或状态。

<EnglishExamples
  title="状态系动词"
  items={[
    {
      sentence: 'She is calm.',
      label: '状态',
      translation: '她很镇定。',
    },
  ]}
/>

### 持续系动词

- **keep、remain、stay**：表示状态延续。
- **continue**：也有连系用法，语体较正式。

<EnglishExamples
  title="持续系动词"
  items={[
    {
      sentence: 'He kept silent.',
      label: 'keep',
      translation: '他一直沉默。',
    },
    {
      sentence: 'She remained calm.',
      label: 'remain',
      translation: '她保持镇定。',
    },
    {
      sentence: 'Please stay still.',
      label: 'stay',
      translation: '请保持不动。',
    },
    {
      sentence: 'The weather continued fine.',
      label: 'continue',
      translation: '天气继续晴好。',
      analysis: ['日常表达也可用 stayed fine。'],
    },
  ]}
/>

### 变化系动词

按要表达的变化选择动词，并核对具体搭配：

- **become + 名词或形容词**：可说明身份或性质改变，语体较中性或正式。例如 become a doctor、become famous。
- **get + 形容词**：用于状态改变，在日常表达中常见。例如 get tired、get cold、get better。
- **grow + 形容词**：可突出逐渐发展，例如 grow old、grow impatient；不能任意接所有形容词。
- **turn + 形容词**：可说明颜色、天气或性质改变，例如 turn red、turn cold、turn sour；不保证变化渐进。
- **go + 特定表语**：例如 go bad、go blind、go quiet；go quiet 不必表示坏事。
- **come + 特定表语**：例如 come true、come alive、come loose；come loose 不必表示好事。
- **fall + 特定表语**：表示进入某种状态，例如 fall asleep、fall ill、fall silent。
- **run + 特定表语**：搭配范围较窄，例如 run dry、run short。

「go 接负面，come 接正面」仅能提示部分搭配。实际选词以动词和表语的搭配为准。

### 表象系动词

seem、appear、look 表示根据迹象或外观作出的判断。seem/appear 可接形容词或不定式，二者不固定划成「seem 主观、appear 客观」；look 也属于下节的感官类。

<EnglishExamples
  title="表象与判断"
  items={[
    {

    },
    {
      sentence: 'She appears tired.',
      label: 'appear + 形容词',
      translation: '她似乎累了。',
    },
    {
      sentence: 'She seems to know the answer.',
      label: 'seem + 不定式',
      translation: '她似乎知道答案。',
    },
    {
      sentence: 'He appears to be a doctor.',

      analysis: [
        '表达身份时可用 to be + 名词；不能把 She seems a doctor 当作所有语体中都自然的替代句。',
      ],
    },
  ]}
/>

look、sound、smell、taste、feel 通过感官描述主语的性质或状态。描述健康状态的 well 是形容词。

    },
    {

      label: '听觉',
      translation: '音乐听起来很美。',
    },
    {
      sentence: 'The flowers smell sweet.',
      label: '嗅觉',
      translation: '花闻起来很香。',
    },
    {
      sentence: 'The soup tastes salty.',
      label: '味觉',
      translation: '汤尝起来很咸。',
    },
    {
      sentence: 'The silk feels soft.',
      label: '触觉',

  ]}
/>

### 结果系动词

- **结果显示某种性质**：用 prove (to be) + 表语，或 turn out (to be) + 表语。
- **证明某个对象**：prove 作及物动词，后接宾语，可作对应被动转换。

<EnglishExamples
  title="结果判断与及物 prove"
  items={[
    {
      sentence: 'The task proved difficult.',
      label: '直接接表语',
      translation: '这项任务结果证明很难。',
      analysis: ['difficult 描述 task。'],
    },
    {
      sentence: 'The task proved to be difficult.',
      label: 'to be + 表语',
      translation: '这项任务结果证明很难。',
      analysis: ['difficult 描述 task。'],
    },
    {
      sentence: 'The plan proved to be a mistake.',
      label: '名词表语',
      translation: '这项计划结果证明是个错误。',
      analysis: ['a mistake 说明 plan 的性质。'],
    },
    {
      sentence: 'The story turned out to be true.',
      label: 'turn out',
      translation: '这件事结果证明是真的。',
      analysis: ['结果判断不必包含从一种性质到另一种性质的变化。'],
    },
    {
      sentence: 'The evidence proved his innocence.',
      label: '及物主动',
      translation: '证据证明了他的清白。',
      analysis: ['his innocence 是宾语。'],
    },
    {
      sentence: 'His innocence was proved by the evidence.',
      label: '及物被动',
      translation: '证据证明了他的清白。',
    },
  ]}
/>

及物 prove 的被动转换不适用于 The task proved difficult. 的连系结构。

## 结构辨析

### 形容词与副词

按修饰对象选词，不能把词序当作充分判据：

- **描述主语的性质或状态**：用形容词表语。
- **修饰动作的方式**：用副词。
- **副词修饰时间、持续等意义**：可与表语共存。

<EnglishExamples
  title="形容词表语与副词修饰语"
  items={[
    {
      sentence: 'She looked angry.',
      label: '描述主语',
      translation: '她显得生气。',
      analysis: ['angry 描述 she。'],
    },
    {
      sentence: 'The medicine tastes bitter.',
      label: '描述主语',
      translation: '药尝起来很苦。',
      analysis: ['bitter 描述药的味道。'],
    },
    {
      sentence: 'She looked angrily at me.',
      label: '修饰动作',
      translation: '她生气地看着我。',
      analysis: ['angrily 修饰看的动作。'],
    },
    {
      sentence: 'The soup still tastes good.',
      label: '副词与表语共存',
      translation: '汤的味道仍然不错。',
      analysis: ['still 是副词，good 是表语。'],
    },
  ]}
/>

表达「她看起来很漂亮」用 looked **beautiful**，不用 looked beautifully。副词仍可出现在系动词附近，因此「系动词后永远不能出现副词」不成立。

### 进行体与被动

- **表示变化过程**：可用进行体。
- **把状态呈现为暂时行为**：可用 be 的进行体，不能仅因 be 作系动词就删去 being。
- **连系结构不带宾语**：不能直接按及物句式转换被动。The soup tastes good. 没有相应的被动转换。
- **改作及物动作用法**：可按宾语转换被动。
