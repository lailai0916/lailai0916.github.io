## 简介

**非限定动词形式**（Non-finite Verb Form），传统学习语法常称 **非谓语动词**。它不独立标示分句时态及人称数变化，仍保留动词的句法性质。

传统语法按形式与功能区分 4 类：

- **不定式**（Infinitive）：基本形式为 to do，在许可裸不定式的构式中用 do。可作主语、补语、定语或状语等。
- **动名词**（Gerund）：采用 doing，在主语、宾语等位置使用。
- **现在分词**（Present Participle）：也采用 doing，构造进行体，或作修饰语、补语、状语等。
- **过去分词**（Past Participle）：用 done 代表，构造完成体、被动，或作修饰语、补语、状语等。

动名词与现在分词的词形相同，现代语法有时统一称为 **动名词分词**（Gerund-participle）。考试分析可沿用传统名称，但不能据此认为它们是 2 套不同拼写。

过去分词是形态名称：written、gone、known 都是过去分词，不是都以 -ed 结尾。过去分词也不等于一般过去式。

## 形式与相对时间

### 形式矩阵

下面用 do、doing、done 代表相应动词形式。表格展示常用组合，不表示每个动词和语境都接受每一格。

|  不定式  |        主动        |          被动           |
| :------: | :----------------: | :---------------------: |
|   一般   |       to do        |       to be done        |
|   进行   |    to be doing     |    to be being done     |
|   完成   |    to have done    |    to have been done    |
| 完成进行 | to have been doing | to have been being done |

| -ing 结构 |    主动     |       被动       |
| :-------: | :---------: | :--------------: |
|   一般    |    doing    |    being done    |
|   完成    | having done | having been done |

进行被动不定式 to be being done 较少使用，完成进行被动不定式 to have been being done 极少使用。需要表达同样的持续过程时，可改用主动等较短结构。

被动 -ing 也能作动词或介词的补语：I dislike **being interrupted**.（我不喜欢被打断。）being interrupted 描述主语承受打断，不是主语正在打断别人。

不带 to 的不定式也能包含完成、进行和被动：may **have left**、must **be working**、can **be repaired**。否定整个非限定结构可用 **not to go**、**not knowing**、**not having been told**；not 的作用范围要与所否定的内容对应。

非限定形式的时间依靠上层动词和语境解释，而不是直接以说话时刻为原点。

完成式常表达 **相对于有关参照时间更早**，但不自动保证事件真实发生：I would like **to have met** her. 可以表达未实现的愿望。

「doing 主动或进行、done 被动或完成」可作初步提示，不能当作无条件等式：

- **Swimming** is good exercise.（游泳是很好的锻炼。）不描述正在游泳。
- **fallen leaves**（落叶）中，fall 是不及物用法，没有「叶子被落下」的被动关系。
- the language **spoken here**（这里使用的语言）表示被动关系，不限定为过去才说。

## 不定式

### 句法功能

- **主语**：整个不定式分句作主语。
- **补语**：依上层词的构式确定位置。
  - **动词或形容词的补语**：补足相应动词或形容词的意义。
  - **表语**：说明主语所指内容。
  - **宾补**：前面的宾语是不定式的逻辑主语。
- **名词修饰语**：传统称后置定语。先确定名词与不定式中的关系，再选择主动或被动以及是否保留介词。
  - **名词是不定式的逻辑主语**：a person **to help us**，person 执行 help。
  - **名词对应动词的宾语空缺**：a book **to read**，book 是 read 的逻辑宾语。
  - **名词对应介词的宾语空缺**：a chair **to sit on**，chair 是 on 的宾语，保留 on。
  - **主动与被动的选择**：不能仅因名词承受动作，就把所有定语不定式改成被动。
- **状语**：依构式和上下文区分意义。
  - **目的**：说明行动意图。
  - **结果**：按构式区分意外结果和发展后的结果。
  - **评注中的假设情境**：条件读法来自这个评注结构，不是句首不定式的固定意义。

### 特定构式

- **主语外置**：it 占据主语位置，不定式内容后置。
- **宾语外置**：it 占据宾语位置，形容词作宾补，不定式给出评价内容；也可直接把内容放在宾语位置。
- **程度构式**：enough 与不定式共同说明条件足够，不断言动作已经实现。

### 裸不定式

不带 to 的不定式称为 **裸不定式**（Bare Infinitive）。

- **核心情态动词 + do**：can **swim**、must **leave**。
- **主动使役 make/let/have + 宾语 + do**：make him **wait**、let her **go**、have him **call**。
- **感知动词 + 宾语 + do**：see him **leave**、hear her **sing**，把感知到的事件作为整体呈现；过程读法可用 doing。
- **had better/would rather + do**：had better **rest**、would rather **stay**。had better 的否定为 **had better not do**。
- **Why not + do**：疑问形式的建议。
- **help (to) do / help someone (to) do**：help 后这 2 种补语模式都允许保留或省略 to。
- **but/except 的固定构式**：按完整搭配选择，不把前文任意 do 当作省 to 的许可。
  - **do nothing but do**：but 后用原形。
  - **have no choice but to do**：保留 to。

- **主动 see + 宾语 + -ing**：对应被动结构保留过程形式。

## 分词

现在分词用 doing 代表，过去分词用 done 代表。两者可有相同功能，语态和相对时间另行判断。

### 句法功能

- **定语**：the boy **running over there**（在那边跑的男孩）；the report **written yesterday**（昨天写的报告）。
- **补语**：描述宾语所参与的活动或状态。
- **状语**：按上下文表达时间、条件等关系。
- **动词链的一部分**：构造进行体、完成体或被动语态。

分词修饰名词时，按结构与词义选择位置：

- 不带展开成分的分词可前置：a **sleeping child**、a **written report**。
- 分词后带宾语、状语等成分时，整个短语后置：the boy **running over there**、the report **written yesterday**。
- 词汇指定的后置用法按词义处理：the people **involved** 表「有关人员」；an **involved** explanation 则表「复杂的说明」。不能仅按词数决定 involved 的位置。

      analysis: ['过去分词结构也可交代原因。'],
    },
  ]}
/>

the **rising sun**（正在升起的太阳）、**running water**（流动的水）体现主动或过程视角；**falling leaves** 与 **fallen leaves** 则分别呈现落下的过程和已落下的状态。后一组都来自不及物 fall，不能把 fallen 当成「被落下」。

interesting/interested、boring/bored 等可以形成形容词对照：

不能总结成「-ing 修饰物，-ed 修饰人」。前者常描述引起某种感受的性质，后者常描述感受或状态，主语可以是人也可以是物。也不是所有 -ing/-ed 形容词都属于感情词，missing、skilled 等需要按各自词义学习。

## 逻辑主语与语态

### 分词状语

对没有显式主语、用于描述主句参与者的普通分词状语，以主句主语作为逻辑主语，检查主动被动及先后关系：

<EnglishExamples
  title="分词状语的逻辑主语"
  items={[
    {
      sentence: 'Walking down the street, I saw an old friend.',
      label: '主动关系',
      translation: '沿街走时，我遇见一位老朋友。',
      analysis: ['走路的是 I。'],
    },
    {
      sentence: 'Having finished the work, she went home.',
      label: '主动与先行事件',
      translation: '完成工作后，她回家了。',
      analysis: ['完成工作的是 she。'],
    },
    {
      sentence: 'Having been warned, he acted cautiously.',
      label: '被动与先行事件',
      translation: '受到警告后，他谨慎行事。',
      analysis: ['he 承受 warn，且警告先于主句事件。'],
    },
  ]}
/>

Walking down the street, **the rain** began to fall. 会把走路者错误地关联到 the rain，属于常见的 **悬垂修饰**（Dangling Modifier）。应改成 While **I was walking** down the street, the rain began to fall.

主动与被动也要围绕逻辑主语判断。不能写成 Seeing from the hill, the field looks beautiful. 让田野成为观看者。

<EnglishExamples
  title="seeing 与 seen 的逻辑主语"
  items={[
    {
      sentence: 'Seen from the hill, the field looks beautiful.',
      label: '被动关系',
      translation: '从山上看，这片田野很美。',
      analysis: ['田野被看见，用 seen。'],

    {
      sentence: 'Seeing the field, the rabbit ran towards it.',
      label: '主动关系',
      translation: '看见田野，兔子朝它跑去。',
      analysis: ['兔子执行看见，用 seeing。'],
    },
  ]}
/>

分词状语与主句的时间、原因、条件等关系依靠语境解释，不是 seeing 永远表时间、being 永远表原因。一般式也可能表达紧接发生的先行事件，不是所有「先做」都必须写成 having done。

### 独立主格

逻辑主语不同时，可用含显式主语的 **独立主格结构**：

<EnglishExamples
  title="独立主格的显式主语"
  items={[
    {
      sentence: "Weather permitting, we'll have a picnic.",
      label: '主动关系',
      translation: '天气允许的话，我们去野餐。',
    },
    {
      sentence: 'The work finished, they went home.',
      label: '被动关系',
      translation: '工作完成后，他们回家了。',
    },
  ]}
/>

这种结构较书面，先掌握普通状语从句再使用，详见 [独立主格](/docs/note/english/grammar/sentences/absolute-constructions)。generally speaking、judging by 等固定表达有自己的惯常解释，不宜直接套用普通悬垂修饰的判定。

## 补语选择

### 常见搭配

先确认支配非限定结构的词及其义项，再选择该构式接受的补语：

- **动词 + to do**：want、hope、decide、plan、agree、promise、refuse、manage、learn。
- **动词 + doing**：enjoy、finish、mind、avoid、advise、escape、suggest、consider、practise、keep。被动关系可进入 being done。
- **动词 + 人 + to do**：want、ask、tell、advise、allow、encourage。advise 没有人的宾语时也可用 advise doing。
- **介词 + doing**：after、without、by 等后接动词结构时用 -ing；look forward to、be used to、devote oneself to、object to 中的 to 也是介词。
- **动词短语 + doing**：insist on、give up、feel like、put off。其中 up、off 不因后接 doing 就变成介词，形式由完整搭配决定。
- **固定表达 + doing**：can't help、it's no use、there is no point (in)。
- **形容词 + to do**：be eager/glad/willing/able to do。
- **名词 + to do**：a chance/decision/plan/right to do。

还需检查具体词汇和所带成分：

- **to 的身份**：want **to leave** 中是不定式标记，object **to leaving** 中是介词；不能仅看见 to 就接原形。
- **suggest 与 advise**：suggest 可接 doing 或 that 分句，不采用 suggest somebody to do；不要把 advise somebody to do 的模式移给 suggest。
- **keep 的宾语**：keep **doing** 表持续做；keep **someone doing** 含宾语和分词补语：We **kept him waiting**.（我们让他一直等。）
- **拼写变体**：英式动词 practise、美式动词 practice 都可接 -ing。

同一动词还可能接受其他构式；以上模式的适用域是所列的具体搭配，不是该单词所有用法的穷举。

### 同词不同补语

|   动词   |            to do             |       doing        |
| :------: | :--------------------------: | :----------------: |
| remember |      记住并落实要做的事      |    回忆做过的事    |
|  forget  |       忘记执行要做的事       |   忘记曾做过的事   |
|  regret  |    常见于正式告知遗憾消息    | 对有关行为感到遗憾 |
|   stop   | 停下原活动，以便去做另一件事 |    停止所接活动    |
|   try    |        努力、设法做到        |    试用某种办法    |
|   mean   |            打算做            |   意味着、需要做   |
|  go on   |        接着做另一件事        |    继续同一活动    |
