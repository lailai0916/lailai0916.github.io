## 简介

**动词**（Verb）是英语句子组织谓语的核心。分类时分别检查 3 个维度：

- **动词短语功能**：提供词汇意义的是主要动词；构造进行、完成、被动或疑问否定等形式的是助动词。情态助动词还表达能力、许可、推断等意义。
- **补足结构**：检查当前用法是否带宾语，带几个宾语，是否要求宾补、表语或其他补足成分。
- **词汇意义**：检查此处描述活动、过程、变化，还是认知、拥有、关系等状态。

这些维度可以交叉：

      analysis: ['has 是完成助动词，known 是主要动词。', 'know 带宾语 him，描述认知状态。'],

## 谓语结构

### 动词与谓语

按主语与谓语的传统分析，**谓语**（Predicate）包含动词短语及其有关成分，不等于某一个动词词形。

<EnglishExamples
  title="动词与谓语的范围"
  items={[
    {
      sentence: 'The cat eats a fish.',
      translation: '猫吃一条鱼。',
      analysis: ['谓语是 eats a fish，主要动词是 eats。'],
      label: '单个动词的谓语',
    },
    {
      sentence: 'The cat may have eaten a fish.',
      translation: '猫可能吃过一条鱼。',
      analysis: ['同一谓语包含 may、have、eaten 3 个动词形式。'],
      label: '动词链',
    },
    {
      sentence: 'She opened the book and began to read.',
      translation: '她打开书，开始阅读。',
      analysis: ['1 个主语可以对应并列谓语。'],
      label: '并列谓语',
    },
  ]}
/>

检查句子时，先划分分句，再分析各自的动词链；遇到并列谓语，分别检查并列项。祈使句和省略结构按各自构造分析，不能用动词单词数直接计算分句数。

### 限定与非限定

**限定形式**（Finite Form）承担分句的时态、主谓一致或情态等语法功能；**非限定形式**（Non-finite Form）本身不独立标示分句的时态和人称数变化。

<EnglishExamples
  title="限定与非限定形式"
  items={[
    {
      sentence: 'She reads every day.',
      analysis: ['reads 是限定形式。'],
      label: '单独限定形式',
    },
    {
      sentence: 'She is reading now.',
      analysis: ['is 是限定形式，reading 是非限定形式。'],
      label: '进行体',
    },
    {
      sentence: 'She may have left.',
      analysis: ['may 是限定形式，have 和 left 是非限定形式。'],
      label: '情态动词链',
    },
    {
      sentence: 'I want to leave.',
      analysis: ['want 是限定形式，to leave 是非限定形式。'],
      label: '不定式补语',
    },
    {
      sentence: 'She has been reading.',
      analysis: [
        'has 承担时态与一致关系；been 和 reading 共同构造完成进行体，不能把 3 个词形当作 3 个分句。',
      ],
      label: '完成进行体',
    },
  ]}
/>

非限定形式并非「没有动词性质」：reading a book 中，reading 仍然带宾语 a book。详见 [非谓语动词](/docs/note/english/grammar/verbs/non-finite-verbs)。

## 补足结构

### 五种基本句型

传统学习语法用五种基本句型整理动词补足结构。S 表示主语，V 表示动词，O 表示宾语，C 表示补语；IO（Indirect Object）表示间接宾语，DO（Direct Object）表示直接宾语。

- **不及物：S + V**。不要求宾语或表语。
- **单及物：S + V + O**。接 1 个宾语，不要求描述该宾语的补语。
- **双及物：S + V + IO + DO**。带间接与直接宾语。
- **复杂及物：S + V + O + C**。宾补描述宾语。
- **连系：S + V + C**。表语描述主语。

  title="五种句型的补足关系"

      translation: '她打开门。',
      analysis: ['the door 是宾语。'],

      label: '双及物',

### 及物性属于用法

**及物动词**（Transitive Verb）在特定用法中带宾语；**不及物动词**（Intransitive Verb）在特定用法中不带宾语。不能先把每个单词永久放进互斥词表，再据此判断所有句子。

| 同一动词 |                  不及物用法                  |                 及物用法                 |
| :------: | :------------------------------------------: | :--------------------------------------: |
|   open   |       The door **opened**.（门开了。）       |  She **opened the door**.（她开了门。）  |
|  close   |      The door **closed**.（门关上了。）      |  She **closed the door**.（她关了门。）  |
|   read   | She **reads** every evening.（她每晚阅读。） | She **read the report**.（她读了报告。） |
|   grow   | The plants **grow** quickly.（植物长得快。） | They **grow tomatoes**.（他们种番茄。）  |

look 的介词结构和连系用法另按补足关系区分：

<EnglishExamples
  title="look 的补足关系"
  items={[
    {
      sentence: 'She looked at me.',
      label: '介词结构',
      translation: '她看着我。',
      analysis: ['me 是介词 at 的宾语，不能因为后面出现名词就把 look 直接判为及物动词。'],

    {
      sentence: 'She looked tired.',
      label: '连系用法',
      translation: '她显得很累。',

    },

/>

查词典时，应连同词义、句型和搭配一起记录。

## 动词短语功能

### 主要动词与系动词

**主要动词**（Main Verb）提供动词短语的核心词汇意义。传统语法把许多具有动作或状态意义的词称为 **实义动词**（Lexical Verb），另列系动词方便讲解。

**系动词**（Linking Verb）把主语与描述它的表语连接起来，也属于主要动词功能的一种。be、become、seem 及部分感官动词有连系用法，详见 [系动词](/docs/note/english/grammar/verbs/linking-verbs)。

### 助动词与情态动词

**助动词**（Auxiliary Verb）帮助构造进行体、完成体、被动语态和疑问否定等结构。基本助动词是 be、have、do。

**情态动词**（Modal Verb）在这里采用的现代语法分类中作为助动词的一类，表达能力、许可、必要、推测、意愿等。can、may、must、will 等都属于这一类。因此，「助动词」和「情态动词」不一定是互斥的上位分类。

同一单词也能切换功能：

<EnglishExamples
  title="同一词形的不同功能"
  items={[
    {
      sentence: 'She has a bike.',
      translation: '她有一辆自行车。',

    },
  ]}
/>

详见 [助动词与情态动词](/docs/note/english/grammar/verbs/auxiliary-modal-verbs)。

## 动作与状态

**动作动词**（Dynamic Verb）描述活动、过程或变化；**状态动词**（Stative Verb）描述认知、拥有、关系等状态。这同样要结合词义判断。

<EnglishExamples
  title="动词意义与体的选择"
  items={[
    {
      sentence: 'I think you are right.',
      translation: '我认为你是对的。',
      analysis: ['think 表示稳定看法；中性的标准书面表达采用非进行形式。'],
      label: 'think：状态',
    },
    {
      sentence: 'I am thinking about the problem.',
      translation: '我正在思考这个问题。',
      analysis: ['think about 表示思考活动，可以用进行体。'],
      label: 'think about：活动',
    },
    {
      sentence: 'She has a car.',
      translation: '她有一辆车。',
      analysis: ['have 表示拥有。'],
      label: 'have：拥有',
    },
    {
      sentence: 'She is having lunch.',
      translation: '她正在吃午饭。',
      analysis: ['have lunch 表示活动。'],
      label: 'have lunch：活动',
    },
  ]}
/>

选择体时，先确定词义：know、belong 等表达稳定认知或所属关系的用法采用非进行形式；think about、have lunch 等活动用法可以采用进行体。若说话人把状态重新呈现为暂时表现或变化，再检查该词是否接受这种读法，详见 [动词时态](/docs/note/english/grammar/verbs/verb-tenses)。
