## 简介

**语气**（Mood）是与分句形式有关的语法范畴。传统英语学习区分 **陈述语气**（Indicative Mood）、**祈使语气**（Imperative Mood）和 **虚拟语气**（Subjunctive Mood）。

- **陈述**：用于陈述、询问、描述等；陈述形式不保证内容真实。
- **祈使**：用于命令、请求、指示、建议等；祈使句不必是强硬命令。
- **虚拟**：传统分类汇集建议要求、愿望、遥远假设等。

**情态**（Modality）涉及可能、必要、能力、意愿等意义，常由情态动词等手段表达。形式和意义不是一一对应：must 可以表示推断，也可以表示义务；would 可以表示过去将来、礼貌或假设结果。

传统「虚拟语气」是一个较宽的教学集合。现代描述语法常将它分开处理：

- **原形虚拟结构**：动词保持原形。
- **非现实 were**：与普通过去形式区分。
- **表达遥远假设的过去形式**：形式上的过去不一定指过去时间。
- **情态动词结构**：按具体情态意义和时间解释。

保留传统术语有助于应试，但不应把每个 may/should/would 都判为同一种虚拟形式。

## 祈使结构

祈使结构采用动词原形。普通直接祈使句无显式主语时，听话人 you 是理解上的主语；需要对照或点名时，也可以保留主语。主语不必是动作执行者：

<EnglishExamples
  title="祈使主语的动作与状态关系"
  items={[
    {
      sentence: 'Be warned!',
      label: '被动关系',
      translation: '当心！',
      analysis: ['you 是 warn 的承受者。'],
    },
    {
      sentence: 'Be quiet!',
      label: '状态关系',
      translation: '安静！',
      analysis: ['描述状态。'],
    },
  ]}
/>

- **肯定祈使**：原形开头。
- **否定祈使**：don't + 原形，包括 be。
- **礼貌请求**：please 可置于句首或句尾。
- **加强语气**：do + 原形。
- **让自己或第三方行动**：let + me/him/her 等 + 原形。
- **包含说话人的建议**：let's + 原形；否定采用 let's not + 原形。
- **保留主语以形成对照**：不能以「必须省略 you」定义祈使句。

## 条件与假设

### 判断维度

分析条件句时，分别判断：

1. 条件和结果各指现在、过去还是将来；
2. 说话人将条件作为开放可能，还是表达距离现实较远的设想。

条件句不等于虚拟句：

<EnglishExamples
  title="一般规律与开放条件"
  items={[
    {
      sentence: 'If water reaches its boiling point, it boils.',
      label: '一般规律',
      analysis: ['表规律。'],
    },
    {
      sentence: "If it rains tomorrow, we'll stay home.",
      label: '开放条件',
      analysis: ['把下雨作为开放的将来条件。'],
    },
  ]}
/>

### 基本对照

|         类型         |      if 从句的典型形式       |          结果句的典型形式           |                                示例                                |
| :------------------: | :--------------------------: | :---------------------------------: | :----------------------------------------------------------------: |
|       一般规律       |           一般现在           |              一般现在               |          If you heat ice, it melts.（加热冰，冰会融化。）          |
|    开放的将来条件    |           现在形式           |  will/can/may + 原形；也可用祈使句  |     If it rains, we'll stay home.（下雨的话，我们待在家里。）      |
| 遥远的现在或将来假设 | 过去形式；be 可用非现实 were |      would/could/might + 原形       |  If I had more time, I would help.（若我有更多时间，我会帮忙。）   |
|    过去反事实假设    |        had + 过去分词        | would/could/might + have + 过去分词 | If I had known, I would have helped.（若我当时知道，我本会帮忙。） |

这组常称零、第一、第二、第三条件句，是典型模式，不是穷尽所有条件结构的 4 条公式。

- **开放条件**：可以谈现在，条件从句不因此断言条件已经成立。
- **第二条件句**：过去形式可以指现在或将来，表达 **情态距离**，不表示条件发生在过去。

<EnglishExamples
  title="开放条件与情态距离"
  items={[
    {
      sentence: "If he is at home now, I'll call him.",
      label: '开放的现在条件',
      translation: '若他现在在家，我会给他打电话。',
      analysis: [
        '条件中的 is 不断言他确实在家；now 也不自动要求虚拟形式，仍要看说话人是否把条件作为开放可能。',
      ],
    },
    {
      sentence: 'If I won the lottery tomorrow, I would buy a house.',
      label: '遥远的将来假设',
      translation: '若我明天中了彩票，我会买房。',
      analysis: ['过去形式表达情态距离，不表示条件发生在过去。'],
    },
  ]}
/>

未来尚未发生，不能一律称为「与将来事实相反」。采用第二条件句时，说话人把事件呈现为较不可能或较遥远；采用第一条件句时，条件保持为开放可能。这是对条件的表达立场，不是按客观概率划定的硬阈值。

### were、should 与 were to

- **非现实 were**：采用正式书面规范或考试要求的非现实形式时，用 **If I were you**。非正式英语也有 If I was ...。若从句是在核实真实过去，则保留普通过去形式。
- **if + should + 原形**：表达试探或「万一发生」的条件；结果按要表达的行动选择，不固定配 would。
- **if + were to + 原形**：把将来情况呈现为较遥远的假设，并不据此断言计划必然不会失败。

  title="were、should 与 were to 的条件句"

      translation: '若我昨天失礼了，我道歉。',

    },
    {
      sentence: 'If you should need help, call me.',
      label: 'should 与祈使结果',
      translation: '万一需要帮助，给我打电话。',
      analysis: ['结果是行动指示。'],
    },
    {
      sentence: 'If it should rain, we will cancel the trip.',
      label: 'should 与将来结果',

      analysis: ['结果是将来的决定。'],
    },
    {
      sentence: 'If the plan were to fail, what would we do?',
      label: 'were to 的假设',
      translation: '若计划失败，我们怎么办？',
      analysis: ['并不据此断言计划必然不会失败。'],
    },
  ]}
/>

### 混合时间与含蓄条件

条件与结果的时间可以不同，不能为了套一行公式而统一改动两边。

<EnglishExamples
  title="条件与结果的混合时间"
  items={[
    {
      sentence: "If you had taken my advice, you wouldn't be in trouble now.",
      translation: '若你当初听了建议，现在就不会有麻烦。',
      analysis: ['过去条件，当前结果。'],
      label: '过去条件与当前结果',
    },
    {
      sentence: "If I were more organized, I wouldn't have missed yesterday's deadline.",
      translation: '若我平时更有条理，就不会错过昨天的截止日期。',
      analysis: ['持续的性格条件，过去结果。'],
      label: '持续条件与过去结果',
    },
  ]}
/>

条件也能由 without、but for、otherwise 或上下文提供：

<EnglishExamples
  title="不使用 if 的含蓄条件"
  items={[
    {
      sentence: 'Without your help, I would have failed.',
      label: 'without',
      translation: '没有你的帮助，我本会失败。',
    },
    {
      sentence: 'But for the rain, we would have gone out.',
      label: 'but for',
      translation: '要不是下雨，我们本会出门。',
    },
    {
      sentence: "He didn't tell me; otherwise, I would have come.",
      label: 'otherwise',
      translation: '他没有告诉我，否则我本会来。',
    },
  ]}
/>

这些词不自动触发虚拟结构：Without water, plants die.（没有水，植物会死。）仍是一般规律。

### 条件倒装

省略 if 的条件倒装用于较正式表达，并受具体构造限制：

- **非现实 were** 移到主语前：If I were you, ... → **Were I you**, ...
- **过去完成 had** 移到主语前：If I had known, ... → **Had I known**, ...
- **条件 should** 移到主语前：If you should need help, ... → **Should you need help**, ...
- **were to 结构** 将 were 移到主语前：If the plan were to fail, ... → **Were the plan to fail**, ...

构造倒装时，否定 not 留在主语后：**Had I not known**, ...。这条构造不允许任意过去动词倒装：If I knew ... 不能直接变成 Knew I ...。详见 [倒装](/docs/note/english/grammar/sentences/inversion)。

## 建议与要求

### 原形与 should 结构

表示要求、建议、命令或必要性的 that 从句，可以采用 **动词原形**。原形不因第三人称单数加 -s，be 也保持 be：

<EnglishExamples
  title="原形虚拟结构"
  items={[
    {
      sentence: 'They demanded that he leave immediately.',
      translation: '他们要求他立即离开。',
      label: '第三人称仍用原形',
    },
    {
      sentence: 'It is essential that she be present.',
      translation: '她到场很有必要。',
      label: 'be 保持原形',
    },
    {
      sentence: 'We recommend that he not drive.',
      translation: '我们建议他不要开车。',
      analysis: ["否定放在原形前，不加 doesn't。"],
      label: 'not 加原形',
    },
  ]}
/>

英式英语中也常用 **should + 原形**。原形结构在美式英语中尤其常见，英式英语也使用；这不是按国别互斥的 2 套规则。

被动同样按原形构造；即使主句在过去，从句原形也不会机械变成 was submitted。

<EnglishExamples
  title="要求从句的 should 与被动"
  items={[
    {
      sentence: 'They demanded that he should leave.',
      label: 'should + 原形',
    },
    {
      sentence: 'They requested that the report be submitted by Friday.',
      label: '被动原形',
      translation: '他们要求周五前提交报告。',
      analysis: ['即使主句在过去，从句原形也不会机械变成 was submitted。'],
    },
  ]}
/>

### 触发意义

先判断上层表达是否提出需要执行的要求、建议或必要行动，再选择结构。以下词语在相应意义下可以引出这类从句：

- **动词**：insist、order、command、demand、suggest、advise、propose、recommend、request、require、ask、desire。
- **形容词**：necessary、important、essential、vital、urgent、advisable。
- **名词**：suggestion、advice、order、request、demand、proposal。

<EnglishExamples
  title="引出要求或建议的表达"
  items={[
    {
      sentence: 'She suggested that he rest.',
      label: '动词',
      translation: '她建议他休息。',
    },
    {
      sentence: 'It is necessary that he be informed.',
      label: '形容词',
      translation: '有必要通知他。',
    },
    {
      sentence: 'Their proposal was that we leave early.',
      label: '名词',
      translation: '他们的提议是我们早点离开。',
    },
  ]}
/>

有多种意义的词，按当前词义分支处理：

- **insist 表「坚称某事属实」**：从句陈述坚持的命题，采用相应时态。
- **insist 表「要求」**：从句交代要求执行的行动，可用原形或 should + 原形。
- **suggest 表「显示、暗示」**：从句是证据支持的判断，采用相应时态。
- **suggest 表「建议」**：从句交代建议的行动，可用原形或 should + 原形。

同一种建议内容还可以出现在名词后的内容从句中，或放在被动报告结构中。idea 等一般名词也不保证从句表示要求。

  title="词义分支与建议内容从句"
  items={[

    },
    {
      sentence: 'He insisted that we leave.',
      label: '提出要求',
      translation: '他坚持要我们离开。',
    },
    {
      sentence: 'The evidence suggests that he is innocent.',
      label: '显示或暗示',
      translation: '证据表明他是无辜的。',
    },
    {
      sentence: 'She suggested that he see a doctor.',
      label: '提出建议',
      translation: '她建议他去看医生。',
    },
    {
      sentence: 'His suggestion that we leave early was accepted.',
      label: '名词后的内容从句',
      translation: '他关于我们早点离开的建议被采纳了。',
      analysis: ['这里的 that 从句交代被采纳的建议内容，并不断言离开已经发生。'],
    },
    {
      sentence: 'It was suggested that we leave early.',
      label: '被动报告结构',
      translation: '有人建议我们早点离开。',

## 愿望与偏好

### wish 与 if only

按愿望所指的时间与内容选择补语：

- **对现在或将来情况的非现实愿望**：wish + 过去形式。
- **对过去情况遗憾**：wish + had + 过去分词。
- **希望行为或情况改变**：wish + would + 原形。这一构造着重不满、拒绝或所期待的变化，不能作为所有将来愿望的通式。
- **能力或机会方面的愿望**：wish + could + 原形。
- **强烈愿望**：if only + 相应形式，时间关系仍按上述分支判断。

补充形式和语义分支：

- **that**：wish 的内容从句允许省去 that；对过去遗憾采用过去完成。
- **非现实 be**：正式书面规范采用 were；非正式英语也使用 was，按所采用的语体选择。
- **将未来事件作为开放的希望**：采用 hope。这与对已知情况表达非现实愿望不同，不把 I wish I would ... 当作自己所有将来愿望的表达。
- **only if**：表示「仅当」，与愿望 if only 不同。

### would rather

先判断主句主语与补语的逻辑主语是否同指，再确定偏好所指的时间：

|  偏好时间  |                                  同一主语                                   |                                         不同主语                                          |
| :--------: | :-------------------------------------------------------------------------: | :---------------------------------------------------------------------------------------: |
| 现在或将来 |          would rather + 原形：I'd rather **stay**.（我宁愿留下。）          | would rather + 主语 + 过去形式：I'd rather you **stayed** tonight.（我宁愿你今晚留下。）  |
|    过去    | would rather + have done：I'd rather **have stayed**.（我宁愿当时留下了。） | would rather + 主语 + had done：I'd rather you **had told** me.（我宁愿你当时告诉了我。） |

同主语结构还需区分主动和被动；不同主语结构中的过去形式不直接表示过去时间。

  title="would rather 的主语与时间解读"

    {
      sentence: 'I would rather you stayed.',

        '过去形式来自这一不同主语的偏好结构，不能仅凭 would 推广到所有补语。',
      ],
    },
    {
      sentence: "I'd rather be left alone.",
      label: '同主语的被动补语',
      translation: '我宁愿独处。',
      analysis: [
        '主语同指不要求它是动作执行者。',
        'I 是被留下的一方，仍使用同主语的裸不定式；补语内部用 be left 表被动。',
      ],
    },
  ]}
/>

### It is time

- **It is (high/about) time + 主语 + 过去形式**：表示当前该采取行动了；high/about 加强「已经有些迟」的意味。
- **正式表达中的 should + 原形**：不按建议要求从句的规则把 should 任意删去；删成 It is time we leave. 不能由这一分支直接推出。
- **不定式结构**：采用 for + 逻辑主语 + to 不定式。
