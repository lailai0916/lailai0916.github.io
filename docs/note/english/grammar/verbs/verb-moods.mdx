## 简介

**语气**（Mood）是与分句形式有关的语法范畴。传统英语学习通常区分 **陈述语气**（Indicative Mood）、**祈使语气**（Imperative Mood）和 **虚拟语气**（Subjunctive Mood）。

| 传统类别 |          典型用途          |                       示例                       |
| :------: | :------------------------: | :----------------------------------------------: |
|   陈述   |     陈述、询问、描述等     |       He is a student. / Is he a student?        |
|   祈使   |   命令、请求、指示、建议   |          Close the door.（把门关上。）           |
|   虚拟   | 建议要求、愿望、遥远假设等 | They demanded that he leave.（他们要求他离开。） |

陈述形式不保证内容真实：He is a millionaire. 也可能是说谎。祈使句不必是强硬命令：Have a nice day. 是祝愿。

**情态**（Modality）涉及可能、必要、能力、意愿等意义，常由情态动词等手段表达。形式和意义不是一一对应：must 可以表示推断，也可以表示义务；would 可以表示过去将来、礼貌或假设结果。

传统「虚拟语气」是一个较宽的教学集合。现代描述语法常分别处理 **原形虚拟结构**、**非现实 were**、**表达遥远假设的过去形式** 以及情态动词结构。保留传统术语有助于应试，但不应把每个 may/should/would 都判为同一种虚拟形式。

## 祈使结构

祈使句通常省略主语，理解为 you，动词用原形。

|       类型       |             形式             |                 示例                 |
| :--------------: | :--------------------------: | :----------------------------------: |
|       肯定       |             原形             |  **Close** the door.（把门关上。）   |
|       否定       |         don't + 原形         |    **Don't be** late.（别迟到。）    |
|     礼貌请求     | please + 原形；或句尾 please |    **Please sit** down.（请坐。）    |
|       加强       |          do + 原形           | **Do come** early.（请一定早点来。） |
|   自己或第三方   |  let me/him/her ... + 原形   |  **Let him decide**.（让他决定。）   |
| 包含说话人的建议 |         let's + 原形         |     **Let's go**.（我们走吧。）      |

否定建议常用 Let's **not go**.（我们别去了。）祈使句也能显式保留主语：**You stay here**, and I'll go.（你留在这里，我去。）不能把「省略 you」当成无例外的定义。

## 条件与假设

### 两个独立判断

分析条件句时，分别判断：

1. 条件和结果各指现在、过去还是将来；
2. 说话人将条件作为开放可能，还是表达距离现实较远的设想。

条件句不等于虚拟句。If water reaches its boiling point, it boils. 表规律；If it rains tomorrow, we'll stay home. 把下雨作为开放的将来条件。

### 基本对照

|         类型         |   if 从句的典型形式    |          结果句的典型形式           |                                示例                                |
| :------------------: | :--------------------: | :---------------------------------: | :----------------------------------------------------------------: |
|       一般规律       |        一般现在        |              一般现在               |          If you heat ice, it melts.（加热冰，冰会融化。）          |
|    开放的将来条件    |        现在形式        |  will/can/may + 原形；也可用祈使句  |     If it rains, we'll stay home.（下雨的话，我们待在家里。）      |
| 遥远的现在或将来假设 | 过去形式；be 常用 were |      would/could/might + 原形       |  If I had more time, I would help.（若我有更多时间，我会帮忙。）   |
|    过去反事实假设    |     had + 过去分词     | would/could/might + have + 过去分词 | If I had known, I would have helped.（若我当时知道，我本会帮忙。） |

这组常称零、第一、第二、第三条件句，是典型模式，不是穷尽所有条件结构的四条公式。

开放条件也可以谈现在：If he **is at home now**, I'll call him.（若他现在在家，我会给他打电话。）条件中的 is 不断言他确实在家；now 也不自动要求虚拟形式，仍要看说话人是否把条件作为开放可能。

第二条件句中的过去形式可以指现在或将来，表达 **情态距离**，不表示条件发生在过去：If I **won** the lottery tomorrow, I **would buy** a house.（若我明天中了彩票，我会买房。）

未来尚未发生，不能一律称为「与将来事实相反」。第二条件句常把事件呈现为较不可能或较遥远，第一条件句则保持为开放可能；区别也包含说话人的立场，不是客观概率的硬阈值。

### were、should 与 were to

**If I were you** 是典型的非现实 were，正式表达和考试中通常保留 were。非正式英语中也能见到 If I was ...，但应区分非现实假设与真实过去的不确定条件：If I **was rude** yesterday, I apologize.（若我昨天失礼了，我道歉。）这里是在核实过去事实。

**if + should + 原形** 可表达试探、万一发生的条件，结果不必用 would：

- If you **should need** help, **call** me.（万一需要帮助，给我打电话。）
- If it **should rain**, we **will** cancel the trip.（万一下雨，我们会取消行程。）

**if + were to + 原形** 常把将来情况呈现为较遥远的假设：If the plan **were to fail**, what **would** we do?（若计划失败，我们怎么办？）这也不是断言计划必然不会失败。

### 混合时间与含蓄条件

条件与结果的时间可以不同，不能为了套一行公式而统一改动两边。

- If you **had taken** my advice, you **wouldn't be** in trouble **now**.（若你当初听了建议，现在就不会有麻烦。）过去条件，当前结果。
- If I **were** more organized, I **wouldn't have missed** yesterday's deadline.（若我平时更有条理，就不会错过昨天的截止日期。）持续的性格条件，过去结果。

条件也能由 without、but for、otherwise 或上下文提供：

- **Without your help**, I **would have failed**.（没有你的帮助，我本会失败。）
- **But for the rain**, we **would have gone** out.（要不是下雨，我们本会出门。）
- He didn't tell me; **otherwise**, I **would have come**.（他没有告诉我，否则我本会来。）

这些词不自动触发虚拟结构：Without water, plants die.（没有水，植物会死。）仍是一般规律。

### 条件倒装

较正式表达中可以省略 if，将 were、had 或 should 提至主语前。

|           普通条件            |            倒装形式            |
| :---------------------------: | :----------------------------: |
|      If I were you, ...       |      **Were I you**, ...       |
|      If I had known, ...      |      **Had I known**, ...      |
| If you should need help, ...  | **Should you need help**, ...  |
| If the plan were to fail, ... | **Were the plan to fail**, ... |

否定通常放在主语后：**Had I not known**, ...不能把这条规则扩展为任意过去动词都可倒装，例如 If I knew ... 不能直接改成 Knew I ...详见 [倒装](/docs/note/english/grammar/sentences/inversion)。

## 建议与要求

### 原形与 should 结构

表示要求、建议、命令或必要性的 that 从句，可以采用 **动词原形**。原形不因第三人称单数加 -s，be 也保持 be：

- They demanded that he **leave** immediately.（他们要求他立即离开。）
- It is essential that she **be** present.（她到场很有必要。）
- We recommend that he **not drive**.（我们建议他不要开车。）否定放在原形前，不加 doesn't。

英式英语中也常用 **should + 原形**：They demanded that he **should leave**. 原形结构在美式英语中尤其常见，英式英语也使用；这不是按国别互斥的两套规则。

被动同样按原形构造：They requested that the report **be submitted** by Friday.（他们要求周五前提交报告。）即使主句在过去，从句原形也不会机械变成 was submitted。

### 触发意义

|   上层表达   |                                              常见词语                                              |                    示例                     |
| :----------: | :------------------------------------------------------------------------------------------------: | :-----------------------------------------: |
|     动词     | insist、order、command、demand、suggest、advise、propose、recommend、request、require、ask、desire |       She suggested that he **rest**.       |
| 形容词或表语 |                     necessary、important、essential、vital、urgent、advisable                      |  It is necessary that he **be** informed.   |
|     名词     |                        suggestion、advice、order、request、demand、proposal                        | Their proposal was that we **leave** early. |

决定结构的是词在此处的 **意义**，不是看到某个单词就触发固定口令。表示事实判断的用法按一般时态处理：

- He **insisted that he was innocent**.（他坚称自己是无辜的。）insist 表坚持认为。
- He **insisted that we leave**.（他坚持要我们离开。）insist 表要求。
- The evidence **suggests that he is innocent**.（证据表明他是无辜的。）suggest 表显示、暗示。
- She **suggested that he see a doctor**.（她建议他去看医生。）suggest 表建议。

同一种建议内容还可以出现在名词后的内容从句中：His **suggestion that we leave early** was accepted.（他关于我们早点离开的建议被采纳了。）这里的 that 从句交代被采纳的建议内容，并不断言离开已经发生。

建议内容也可放在被动报告结构中：**It was suggested that we leave early**.（有人建议我们早点离开。）主句 was suggested 是过去的被动形式，从句 leave 仍用原形。

idea 等一般名词也不保证从句表示要求：The idea that the Earth is flat is wrong.（地球是平的这一观点是错误的。）这里是被讨论的命题内容，不是建议地球变平。

## 愿望与偏好

### wish 与 if only

|         意义         |      常见形式      |                          示例                          |
| :------------------: | :----------------: | :----------------------------------------------------: |
|   对现在情况不满意   |  wish + 过去形式   |   I wish I **knew** the answer.（但愿我知道答案。）    |
|    对过去情况遗憾    |  wish + had done   | I wish I **had studied** harder.（但愿我当初更用功。） |
|  希望行为或情况改变  |  wish + would do   |   I wish it **would stop** raining.（但愿雨能停。）    |
| 能力或可能方面的愿望 |  wish + could do   |       I wish I **could swim**.（但愿我会游泳。）       |
|       强烈愿望       | if only + 相应形式 | If only I **had listened**!（要是我当时听了就好了。）  |

wish 后的 that 常可省略：I wish **(that) you were here now**.（但愿你现在在这里。）were 不因此表示过去到场；对过去的遗憾可用 I wish you **had been here yesterday**.（但愿你昨天在这里。）

wish 后的 be 在正式非现实表达中常用 were：I wish I **were taller**.（但愿我再高些。）非正式用法也可见 was；做题时应识别题目采用的规范。

wish + would 常表达对不受自己直接控制的行为、拒绝或变化的不满与期待，不是「所有将来愿望」的通用公式。希望可实现的未来事情常用 hope：I **hope you pass** the exam.（希望你通过考试。）

希望自己未来有某种机会时，可用 I wish I **could see you tomorrow**.（但愿我明天能见到你。）若把见面视为可实现的希望，可用 I **hope to see you tomorrow**.不能把 I wish I would ... 当作所有自己将来愿望的通式；wish + would 通常着重希望行为或情况发生改变。

if only（但愿、要是……就好了）与 only if（仅当）不同：I'll go **only if** you come too.（仅当你也来，我才去。）

### would rather

|      主语关系与时间      |              形式              |                           示例                            |
| :----------------------: | :----------------------------: | :-------------------------------------------------------: |
|        同一执行者        |      would rather + 原形       |           I'd rather **stay**.（我宁愿留下。）            |
| 同一执行者，对过去的偏好 |    would rather + have done    |     I'd rather **have stayed**.（我宁愿当时留下了。）     |
| 不同主语，现在或将来偏好 | would rather + 主语 + 过去形式 | I'd rather you **stayed** tonight.（我宁愿你今晚留下。）  |
|  不同主语，对过去的偏好  | would rather + 主语 + had done | I'd rather you **had told** me.（我宁愿你当时告诉了我。） |

I would rather you stayed. 不必断言对方一定不留下；过去形式把偏好呈现为一种非直接断言。

### as if 与 as though

as if/as though 后可以用常规形式，也可用表达距离现实较远的过去形式。

- It looks as if it **is going to rain**.（看起来快下雨了。）说话人认为有现实依据。
- He talks as if he **knew** everything.（他说话好像无所不知。）说话人通常不认同他全知。
- She looked as if she **had seen** a ghost.（她看上去仿佛见了鬼。）有关事件早于 looked 的过去参照时间。

不能仅因出现 as if 就强制使用虚拟形式，也不能把 had seen 自动解释为「事实证明没有见过」，实际立场还要结合上下文。

### It is time

It is (high/about) time + 主语 + 过去形式，表示该做某事了，常带已经有些迟的意味：It is high time we **left**.（我们早该走了。）left 指当前该发生的行动，不是过去离开。

部分正式用法也采用 should + 原形，should 不能按建议要求从句的规则随意删去。日常更常用过去形式，或改成 It is time **for us to leave**.

## 相关从句边界

so that、in order that 等目的从句和让步从句可以包含情态动词，但不能因此一律标为「与事实相反的虚拟语气」。

- He spoke slowly **so that we could understand**.（他说得慢，好让我们听懂。）could 表目的中的能力或可能。
- He spoke slowly **in order that everyone might understand**.（他说得慢，好让大家听懂。）might 可出现在过去的目的语境中，不断言大家实际没有听懂。
- I'll write it down **so that I don't forget**.（我把它写下，以免忘记。）目的从句也可以没有 may/might/should。
- Take an umbrella **lest it rain / should rain**.（带把伞，以防下雨。）lest 较正式，后面常见原形或 should。
- **Whatever he says / may say**, don't believe him.（无论他说什么，都别信。）may 增加让步表达，不是必需成分。
- She left early **for fear that she might miss** the train.（她早早离开，生怕误车。）might miss 描述所担忧的可能事件。

这些结构应按照连接词、情态意义与上下文分析，不宜归结成「目的从句必须 may/might/should」或「whatever 后必须虚拟」。

## 自测

1. If I won the competition tomorrow, I would celebrate. 中，won 是否表示比赛已经发生？
2. 要表达「医生建议她多休息」，The doctor suggested that she `___` more rest. 应填 get 还是 gets？要表达「结果表明她身体健康」，The results suggest that she `___` healthy. 中可否用 is？
3. If I had left earlier, I would be home now. 为什么两边没有都用完成式？
4. It looks as if it is going to rain. 是否必须把 is 改成 were？
5. Should you need help, call me. 是什么条件的倒装？结果句为什么可以用祈使句？

1. 不是。tomorrow 定位将来，won 表达遥远假设，不是过去发生的事实；
2. 第一处选 get，也可用 should get，suggest 表建议；第二处可用 is，suggest 表证据显示，不触发建议要求结构。题干明确了两种词义，不能仅凭 suggest 的拼写决定结构；
3. 从句设想改变过去的离开时间，主句描述当前的结果，两边按各自时间组织；
4. 不需要。说话人可以认为下雨有现实依据，采用普通形式；
5. 相当于 If you should need help, call me. should 表万一发生的条件，结果句可直接给出行动指示，不必使用 would。
