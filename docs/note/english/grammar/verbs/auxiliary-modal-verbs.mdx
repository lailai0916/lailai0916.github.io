## 简介

**助动词**（Auxiliary Verb）在动词短语中承担语法功能。**情态动词**（Modal Verb）表达能力、许可、必要、推测、意愿等意义；在现代语法的这一分类中，情态动词也是助动词。

按构造区分 **基本助动词 be、have、do** 和 **情态助动词 can、may、must 等**。同一词形在不同结构中可以承担不同功能：

## 基本助动词

### 功能与形式

- **进行体**：be + -ing 分词。
- **被动语态**：be + 过去分词。
- **完成体**：have + 过去分词。
- **do 支持**：do/does/did + 原形，用于相应结构中的疑问、否定和强调。

<EnglishExamples
  title="基本助动词的功能"
  items={[
    {
      sentence: 'She is reading.',
      label: '进行体',
      translation: '她正在读书。',
    },
    {
      sentence: 'It was written in 2020.',
      label: '被动语态',
      translation: '它写于 2020 年。',
    },
    {
      sentence: 'She has left.',
      label: '完成体',
      translation: '她已经离开。',
    },
    {
      sentence: 'Did she leave?',
      label: 'do 支持',
      translation: '她走了吗？',
    },
  ]}
/>

be、have 的具体词形由时态、主语和前一动词的要求共同决定：is reading、has been reading、may have been reading。详见 [动词时态](/docs/note/english/grammar/verbs/verb-tenses)。

### 动词链次序

常规助动词链按 **情态 + 完成 have + 进行 be + 被动 be + 主要动词** 排列。确定所需模块后，保留这个次序，逐项决定后一个动词的形式：

1. 核心情态动词要求后一动词用 **原形**；
2. 完成助动词 have 要求后一动词用 **过去分词**；
3. 进行助动词 be 要求后一动词用 **-ing 形式**；
4. 被动助动词 be 要求后一动词用 **过去分词**。

各模块可以缺省。由相邻模块的要求计算词形，而不是把整条链当作固定短语：

<EnglishExamples
  title="动词链逐项构造"

**have been being done** 在结构上可以成立。在日常交流和一般说明文中，完成进行被动很少使用；需要强调持续过程时，可以改用主动句等较短表达。结构可组合性与实际使用频率是 2 个问题。

### 疑问、否定与强调

以下先处理普通限定陈述句的 not 否定，以及一般疑问句和疑问成分前置的直接疑问句。

先按动词结构确定 **否定或倒装的操作对象**，依次判断，命中后停止：

1. **已有助动词**：使用第一个限定助动词，如 She **has** been working. 中的 has；
2. **没有其他助动词，主要动词是限定 be**：直接使用 be，如 She **is** happy. 中的 is；
3. **其余一般现在或一般过去句**：需要 not 否定或疑问倒装时，添加 do/does/did，主要动词改回原形。

再按所需操作处理：

- **not 否定**：将 not 放在上述操作对象后。
  - **已有助动词或限定 be**：直接在其后否定。
  - **需要 do 支持**：使用 do/does/did，主要动词改回原形。
- **主语疑问**：疑问成分本身是主语且询问主语身份时，保留主语在前、谓语在后的次序，不因疑问而添加 do。
  - **肯定式**：不添加 do。
  - **否定式需要 do 支持**：do 由否定触发。
  - **已有助动词的否定式**：直接对第一个限定助动词否定。
- **一般疑问句，或前置疑问成分不是主语**：把操作对象移到主语前。

- **跨地区通用的普通动词构造**：采用 do。
- **部分英式用法**：保留直接倒装和否定。这类形式在当代口语中不如 do 结构和 have got 结构常见。
- **have got 结构**：对 have 操作。

- **强调没有其他助动词的普通动词肯定陈述**：一般现在或一般过去可用 do/does/did + 原形。已有助动词或限定 be 时，重读相应词，不添加 do。
- **否定祈使句**：don't + 原形，包括 be。
- **语境许可的省略**：可以仅保留助动词，主要动词由前文恢复。
- **do 自身是主要动词**：按其词汇意义和当前结构区分，不把每个 do 都当作助动词。

## 情态系统

### 核心情态与相关表达

核心情态动词包括 can、could、may、might、must、shall、should、will、would。标准英语中的核心情态结构具有以下形式限制：

- 不随第三人称单数加 -s。
- 后接原形，不加 to。
- 直接构成疑问和否定。
- 没有普通动词那套完整的不定式和分词形式，不能写 to can 或 musting。
- 不直接叠加 2 个核心情态动词：用 will **be able to**，不用 will can。

<EnglishExamples
  title="核心情态动词的形式限制"
  items={[
    {
      sentence: 'He can swim.',
      label: '第三人称不加 -s',
    },
    {
      sentence: 'She must leave.',
      label: '后接原形不加 to',
    },
    {
      sentence: 'Could you help?',
      label: '直接构成疑问',
    },
    {
      sentence: "You mustn't go.",
      label: '直接构成否定',
    },
  ]}
/>

表达相近意义的其他结构，按各自构造变化：

- **have to、be able to、be going to**：可以出现 has to、had to、will be able to 等形式。
- **ought to**：保留 to，不随第三人称单数加 -s；属于边缘情态表达。
- **need、dare**：先确定采用情态用法还是普通动词用法，再决定词形、to 和疑问否定方式。
- **used to**：表示过去习惯或状态，不具有完整的核心情态范式。

can → could、may → might、will → would、shall → should 有历史过去形式或转述上的联系，但这些词形不直接决定实际时间：

### need 与 dare

- **采用情态构造**：不加第三人称 -s，后接原形，直接构成疑问否定。
- **采用普通动词构造**：按主语和时态变化，以 do 构成相应疑问否定。dare 的普通动词用法在否定、疑问环境中还允许省去 to。

<EnglishExamples
  title="need 与 dare 的 2 种构造"

      translation: '你不必去。',
    },
    {
      sentence: 'He dare not ask.',
      label: '情态 dare',
      translation: '他不敢问。',
    },

    {
      sentence: "You don't need to go.",
      label: '普通动词 need',

    {
      sentence: 'He dares to ask.',
      label: '普通动词 dare',

情态 need 的使用环境受限制，不能与普通 need 在所有肯定句中互换：

- **否定或疑问环境**：情态 need 可用于这些结构。
- **含否定或限制意义的环境**：情态 need 也可使用。
- **中性的肯定陈述**：采用普通动词构造；不采用 He need wait. 作为日常表达。

**How dare you!**（你怎么敢！）是表达愤怒或惊讶的质问，不能仅按「是否有能力」解释。

### 意义分类

先确定语境讨论什么，再解释情态词：

- **能力**：can、could、be able to。
- **许可**：can、may；请求中也用 could。
- **义务、必要**：must、have to；should、ought to 还可表应当。
- **可能性、推断**：may、might、could、must、can't、should。
- **意愿、拒绝**：will、would、won't。
- **习惯、倾向**：will、would、used to。
- **建议、征询**：should、ought to、shall。
- **正式祝愿**：may 也可用于祝愿，不是询问许可或判断成功概率。

礼貌程度受语境、语调和完整措辞影响，不能仅给某个单词标定固定礼貌等级。

### 推断与时间

根据推断所依据的内容区分读法：

- **保留不确定性**：may/might/could 的词形差异受语境和语体影响，不能换算成固定百分比。
- **依据正常安排或预期**：可用 should。
- **依据证据作较有把握的推断**：可用 must。
- **依据证据排除可能性**：可用 can't。

肯定句中的 can 表达一般可能性。针对特定场合、缺乏确定证据的猜测，采用 may/might/could；不以 He can be at home. 直接替代这一读法。

will 和 should 也不能仅按词形名称分配时间：

- **will 表惯常倾向**：不一定指将来。
- **will 表当前推断**：不把事件强行定位到将来。
- **should 表建议、义务或期待**：这些现代常用意义不能直接拿来替代 would 构造过去将来。

## 完成式与否定

### 情态动词加完成式

**情态动词 + have + 过去分词** 将事件或状态关联到有关参照时间之前。先确定参照时间，再判断是在推断、评价还是设想结果；不能统一译作「过去猜测」。

- **must have done**：根据证据推断已发生。
- **may/might/could have done**：不确定的过去可能。
- **can't/couldn't have done**：推断不可能发生。
- **could have done**：也可表示当时未实现的可能或能力。
- **should/ought to have done**：按义务或评价读法表示本该做；按预期读法则未必断言没有做。
- **needn't have done**：回顾已做但无必要的事。
- **would have done**：可表反事实结果，也可用于过去视角的完成预测，不能仅凭形式认定事情没有发生。

参照时间由语境确定，完成式不直接等于「现在之前」。

### 否定的作用范围

先确定情态意义，再确定 not 否定的对象：

- **义务语境的 mustn't**：禁止做，不是「没有必要」。
- **don't have to / needn't**：没有做的必要，不是禁止。
- **可能性语境的 may not**：可能不发生；保留「不发生」的可能，不等于排除「发生」的可能。
- **许可语境的 may not**：不获许可。
- **can't**：依语境表示没有能力、没有许可或不可能。
- **建议语境的 shouldn't**：不应该做。

  title="情态否定的作用范围"

      label: '没有必要',

    },
    {

表达根据证据得出的「不可能」用 **can't**；不要把义务语境的 **mustn't** 直接移作这一读法。may not 与 can't 的推断读法，否定范围不同，不能互换。

过去无必要还需区分是否断言已经做了：

- **needn't have done 的回顾读法**：表示已经做了，但本无必要。
- **didn't need to do**：仅陈述当时没有必要，本身不确定动作是否发生。I **didn't need to go, but I went anyway**.（我本不必去，但还是去了。）

## 常见辨析

### must 与 have to

must 表义务时，使用中有突出说话人要求或自我要求的倾向；have to 有突出情境必要的倾向。这个语用差异不是互斥的词法条件：公共规定可以用 must，自我要求也可以用 have to。

按所需形式选择：

- **直接叙述过去的义务**：用 had to。
- **将来的具体必要**：可用 will have to。must 也可借上下文涉及将来，并非一见 tomorrow 就必须替换。
- **转述原来的要求**：must 可以保留原形，不能将「没有普通过去词形」误解为「任何过去语境都不得出现」。

### should、ought to 与 shall

- **建议、义务和期待**：should 与 ought to 都可使用。ought to 的使用频率较低，在部分语境中更正式；不能规定它一律表示更强的道德义务。
- **第一人称的提议和征询**：用 **Shall I ...? / Shall we ...?**。
- **单纯将来表达**：第一人称也可以用 will，不必执行「第一人称 shall，其余 will」。
- **合同等法律文体**：shall 可表义务。
- **对事实的评价**：should 可表惊讶或遗憾，不是建议，也不必与事实相反。这一用法在英式英语和较正式表达中较常见。

### 半助动词与相关表达

**半助动词**（Semi-auxiliary Verb）的分类范围因语法体系而异。以下结构具有情态或时间意义，内部仍按各自构造变化：

- **be able to + 原形**：表示能够，并提供 can 没有的形式。不能写 will can；但 can 本身可指将来。
- **be going to + 原形**：表示打算，或依据当前迹象作预测。计划不必局限于近期。
- **be about to + 原形**：把事件呈现为从当前参照点看即将发生。若要直接说明 3 年后的计划，不采用这一临近读法。
- **be to + 原形**：表示正式安排或指令；过去叙事还可用来预示后来发生的事。命运感来自叙事语境，不是所有 be to 的固定义。详见 [动词时态](/docs/note/english/grammar/verbs/verb-tenses)。
- **had better + 原形**：针对具体情境提出劝告，带有不照做可能产生不利后果的意味。

had better 的形式固定：

- had 不随主语变成 has；此结构用于当前或将来的劝告，不能仅凭 had 当作过去时。
- 缩写 'd 在这里是 had，不是 would。
- 否定用 **had better not do**。
- 表一般建议可用 should；表达个人偏好用 would rather。三者不能仅根据中文「更好」互换。

### 过去习惯与习惯于

- **used to + 原形**：描述过去的习惯或状态，并与现在形成对照。
- **would + 原形的过去习惯读法**：在已建立的过去背景中描述反复动作。描述过去持续状态「曾住在这里」时，用 used to live，不以这一习惯读法的 would live 直接替换。
- **be used to + 名词或 -ing 结构**：表示习惯于；to 是介词。
- **be used + to 不定式**：use 的被动加目的不定式。
