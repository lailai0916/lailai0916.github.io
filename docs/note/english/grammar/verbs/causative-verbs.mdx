## 简介

**使役结构**（Causative Construction）表达促使、允许或安排某人做某事，或使某物处于某状态。这些动词用法称为 **使役动词**（Causative Verb）。

基本结构为 **主语 + 动词 + 宾语 + 宾语补足语**。补语可以说明宾语的动作、状态、身份或方向：

补语可以说明宾语的动作或状态：

同一个动词可以有不同用法：make a cake 表示做蛋糕，不是上述使役结构。

## 核心结构

### 形式选择

do 表示动词原形，done 表示过去分词。先确定支配动词及其义项，选择它许可的补语构式：

- **make**：
  - **make + 宾语 + do**：表示促使或迫使，make 不必表示强迫。
  - **词项受限的过去分词补语**：make oneself **heard/understood** 表示让别人听到或理解自己，不能推广成 make + 任意宾语 + 任意过去分词。
- **let**：
  - **let + 宾语 + do**：表示允许或让，let 不自带委婉语气。
  - **裸不定式内部也可被动**：不能把不定式中的被动等同于主句 let 的被动。
- **have/get**：
  - **不定式补语**：have + 宾语 + do；get + 宾语 + to do。
  - **过去分词补语**：have/get + 宾语 + done。
  - **-ing 补语**：have/get + 宾语 + doing。

选定构式后，再判断宾语是补语所述动作的执行者、承受者，还是某种状态的主体。承受动作不仅对应 have/get + done，还可能由许可被动不定式的构式表达。

make him **do** 中的 do 是裸不定式，can **do** 也选择原形不定式。两者的上层结构不同：前者是带宾语的补足结构，后者属于情态动词链。

### 主语与补语

补语不是动词时，按它说明的内容分析：

- **形容词补语**：说明状态。
- **名词补语**：说明身份。
- **方向或位置补语**：说明宾语所要到达的方向或位置。

## 语态与意义

### make 与 let

转换或转述时，按原动词分支处理：

- **make + 宾语 + 原形不定式**：作对应被动转换时，用 **be made to do**，保留动作，补上 to。
- **let 表示允许**：用 **be allowed to do** 转述，不写 be let to do。
- **let go 等固定表达**：保留该表达自身的用法。He **was let go**. 可表示「他被放走了」或「他被解雇了」。
- **have someone do、get someone to do**：不能套用 be made to do 的转换规则。要表达被要求做某事，按原意选择 He **was asked/told to do** ... 等结构。

<EnglishExamples
  title="make 与 let 的被动转述"
  items={[
    {

      translation: '他们让我们等。',

    {
      sentence: 'We were made to wait.',
      label: 'make 被动',
      translation: '我们被要求等。',
      analysis: ['原形不定式在对应被动句中补上 to。'],
    },
    {
      sentence: 'They let him leave.',
      label: 'let 主动',
      translation: '他们允许他离开。',
    },
    {
      sentence: 'He was allowed to leave.',
      label: '允许的被动转述',
      translation: '他获准离开。',
      analysis: ['用 be allowed to do 转述，不写 be let to do。'],
    },

/>

### have/get something done

按事件来源与语境区分读法：

  title="have/get something done 的读法"

      label: '促成任务完成',

      analysis: ['重点是完成结果，执行者由语境判断。'],
    },
    {
      sentence: 'He had his wallet stolen.',
      label: '遭遇事件',
      translation: '他的钱包被偷了。',
      analysis: ['不表示主语安排了偷窃。'],
    },

/>

have/get 的差别不按收费划分：

- **意义侧重**：have 在安排任务的语境中突出安排，get 在克服困难或达成目标的语境中突出促成。
- **服务场景**：have 与 get 都可用于付费服务，意义可以接近；have 不要求付费，get 也不要求免费或劝说。
- **剪发场景的默认读法**：中文都可说「我剪了头发」，英语须按动作关系选结构。

## 相关动词模式

### 宾语与不定式

表达下列意义时，用 **动词 + 宾语 + to do**：

- **促成、使能够**：cause、enable。
- **强制、命令**：force、compel、order。
- **请求、告知**：ask、tell。
- **说服、鼓励**：persuade、encourage。
- **允许**：allow、permit。

否定范围须区分主句与补语：

- **否定带 to 不定式的动作**：中性语序用 **not to do**。强调否定时也可用 to not do，不定式仍带 to。
- **否定主句谓语**：否定的是上层动词，不等于否定补语中的动作。

### 状态与过程补语

使役意义不统一要求 to do；其他动词须按自身补语形式选用：

- **drive + 宾语 + 形容词**：说明宾语的状态。
- **leave + 宾语 + doing**：说明宾语持续进行的活动。

<EnglishExamples
  title="状态与过程补语"

    {

      translation: '噪声让我发狂。',
    },
    {
      sentence: 'She left me waiting outside.',
      label: '-ing 补语',
      translation: '她让我一直在外面等。',

  ]}

## 感官结构

see、hear、watch、notice、feel 等感知动词也可接宾语和非限定补语。这里表达感知，不是促使。

按宾语与事件的关系、观察角度选择形式：

- **把事件作为整体感知**：用 **see + 宾语 + do**。
- **感知正在展开的片段**：用 **see + 宾语 + doing**。
- **宾语承受被感知的动作**：用 **see + 宾语 + done**。

<EnglishExamples
  title="感知补语的观察角度"
  items={[
    {
      label: '整体事件',
      sentence: 'I saw him cross the road.',
      translation: '我看见他过了马路。',
      analysis: ['整体视角不要求肉眼观察到每一个瞬间，也可呈现重复的完整事件。'],
    },
    {
      label: '进行片段',
      sentence: 'I saw him crossing the road.',
      translation: '我看见他正在过马路。',
    },
    {
      label: '被动关系',
      sentence: 'I saw him arrested.',
      translation: '我看见他被捕。',
    },
  ]}
/>

find 不应直接套用 see 的裸不定式模式：

<EnglishExamples
  title="find 的补语"
  items={[
    {
      sentence: 'We found him working.',
      label: '-ing 补语',
      translation: '我们发现他正在工作。',
    },
    {
      sentence: 'We found him to be reliable.',
      label: '带 to 不定式',
      translation: '我们发现他可靠。',
    },
  ]}
/>

以 see 的对应被动结构为例，按原补语形式分支；不能据此假定所有感知动词都能套用同一种被动结构：

- **原形补语**：对应被动结构改为 to do。
- **-ing 补语**：对应被动结构保留 -ing。

<EnglishExamples
  title="感知补语的被动转换"
  items={[
    {
      sentence: 'Someone saw him enter.',
      label: '原形补语主动',
      translation: '有人看见他进去了。',
    },
    {
      sentence: 'He was seen to enter.',
      label: '原形补语被动',
      analysis: ['原形补语改为 to do。'],
    },
    {
      sentence: 'Someone saw him entering.',
      label: '-ing 补语主动',
      translation: '有人看见他正在进去。',
    },
    {
      sentence: 'He was seen entering.',
      label: '-ing 补语被动',
      analysis: ['对应被动结构保留 -ing。'],
    },
    {
      sentence: 'He was seen running away.',
      label: '保留过程视角',

    },
  ]}
/>

把 -ing 统一改成 to do 会改变观察角度。详见 [非谓语动词](/docs/note/english/grammar/verbs/non-finite-verbs)。
