## 简介

传统学习语法用 **时态** 统称动词的时间和体的组合。建立体系时，应区分三个问题：

|    层面    |             核心问题             |            例子            |
| :--------: | :------------------------------: | :------------------------: |
| 时间与时态 |        从什么视点定位事件        | 现在、过去、将来、过去将来 |
|     体     | 怎样观察事件的内部结构与时间关系 | 一般、进行、完成、完成进行 |
|    情态    |     对事件表达什么判断或态度     |  可能、必然、意愿、假设等  |

**时态**（Tense）和 **体**（Aspect）在严格语法描述中不是同一个概念。英语有现在、过去的形态对立，没有与过去式同类的专属将来词尾；will 还属于情态系统。不同语法体系对完成结构的分类也略有差异。

学习阶段仍可保留 **4 × 4 = 16** 的时态表：它把常用的时间视角与体组合放在同一张地图上。矩阵是检索工具，不能据此认为英语只有这些表达时间的方式，也不能把四行都当成同一种形态变化。

## 构造矩阵

### 十六格形式

表中 do 表示动词原形，did 表示过去式，doing 表示 -ing 形式，done 表示过去分词。一般现在和一般过去的 be 需要单列其变化。

| <span style={{ whiteSpace: 'nowrap' }}>时间视角</span> |        一般        |      进行       |      完成       |       完成进行        |
| :----------------------------------------------------: | :----------------: | :-------------: | :-------------: | :-------------------: |
|                          现在                          | do/does；am/is/are | am/is/are doing |  have/has done  |  have/has been doing  |
|                          过去                          |   did；was/were    | was/were doing  |    had done     |    had been doing     |
|                          将来                          |      will do       |  will be doing  | will have done  | will have been doing  |
|                        过去将来                        |      would do      | would be doing  | would have done | would have been doing |

将来和过去将来两行选用 will/would 作为代表形式。be going to、现在进行表安排、一般现在表时刻表等同样能表达将来。过去将来中的 would 也不能与所有「would + 动词」结构画等号。

### 动词词形

**过去式**（Past Form）和 **过去分词**（Past Participle）是不同的形式；**过去时态** 则是分句的时间语法，两者不能混称。

| 原形  | 现在第三人称单数 |  过去式  | 过去分词 | -ing 形式 |
| :---: | :--------------: | :------: | :------: | :-------: |
|  eat  |       eats       |   ate    |  eaten   |  eating   |
| write |      writes      |  wrote   | written  |  writing  |
|  go   |       goes       |   went   |   gone   |   going   |
| have  |       has        |   had    |   had    |  having   |
|  do   |       does       |   did    |   done   |   doing   |
|  be   |        is        | was/were |   been   |   being   |
|  hit  |       hits       |   hit    |   hit    |  hitting  |
|  die  |       dies       |   died   |   died   |   dying   |
| read  |      reads       |   read   |   read   |  reading  |

be 的其他现在式有 am/are，具体与主语配合；read 的原形通常读 /riːd/，过去式和过去分词通常读 /red/。不能仅看一个词的拼写，就确定它是哪一种形式。

规则变化也有拼写条件：

|              情况              |                          常见变化                           |                            示例与边界                             |
| :----------------------------: | :---------------------------------------------------------: | :---------------------------------------------------------------: |
|            一般情况            | 第三人称加 -s；规则过去式、过去分词加 -ed；-ing 形式加 -ing |                    look → looks/looked/looking                    |
|  -s、-sh、-ch、-x、-z 等结尾   |                      第三人称常加 -es                       |          watch → watches；go → goes、do → does 也加 -es           |
|       辅音字母 + y 结尾        |      第三人称变 -ies，规则过去形式变 -ied，-ing 保留 y      |   study → studies/studied/studying；play → plays/played/playing   |
|        不发音的 e 结尾         |              规则过去形式加 -d，-ing 通常去 e               |            live → lived/living；see → seeing 则保留 e             |
|            -ie 结尾            |                    加 -ing 时变为 -ying                     |                     die → dying、lie → lying                      |
| 末尾是重读短元音加单个辅音字母 |                加 -ed/-ing 时通常双写该辅音                 | stop → stopped/stopping；begin → beginning；open → opening 不双写 |

双写还有词尾字母与地区拼写限制，不能仅凭「最后三个字母是辅元辅」判断。w、x、y 通常不按此规则双写；某些 -c 结尾动词先加 k，例如 panic → panicked/panicking。travel 的英式常见 travelled/travelling，美式常见 traveled/traveling。

不规则形式可以分组记忆，但不能把相似拼写当作保证：hit–hit–hit 三形相同；bring–brought–brought 和 feel–felt–felt 的后两形相同；begin–began–begun、give–gave–given、speak–spoke–spoken 则三形不同。具体词形应查词典或不规则动词表，不从某一个类推例子推定全部动词。

### 模块关系

- 进行体由 **be + doing** 构造。
- 完成体由 **have + done** 构造。
- 完成进行体由 **have + been + doing** 构造，been 是 be 的过去分词。
- 将来行在前面加 will，后接原形；过去视点常将 will 改成 would。

例如 will have been working 的顺序来自 will 要求 have 用原形、have 要求 be 用过去分词 been、进行 be 要求 work 用 -ing。这是形式约束，不是逐词翻译出的中文顺序。详见 [助动词 & 情态动词](/docs/note/english/grammar/verbs/auxiliary-modal-verbs)。

## 时间参照

### 说话、参照与事件

可用三个标签帮助分析：

- **S（Speech Time）**：说话时间，通常是当前说这句话的时刻。
- **R（Reference Time）**：有关参照时间，可以由主句、时间状语或上下文给出。
- **E（Event Time）**：动作或状态占据的时间。

它们是分析工具，并非每个句子都能压缩成三个精确的数学点。状态、反复活动和进行过程往往占据区间，完成体也可能包含持续到参照时间的情状。

|                  例句                  |             参照方式              |
| :------------------------------------: | :-------------------------------: |
|         I **am working** now.          |    R 接近 S，工作过程在 R 展开    |
|       I **was working** at nine.       | R 是过去的九点，工作过程在 R 展开 |
|    I **had left** when she called.     |   R 是过去她来电时，离开先于 R    |
| I **will have left** by nine tomorrow. |   R 在将来，离开不晚于该截止点    |

这里的「现在」不必是无长度瞬间。I live here.（我住在这里。）描述跨越现在的一段状态；The Earth goes around the Sun.（地球绕太阳转。）表达一般规律。

### 过去将来

过去将来从 **过去的视点** 设置其后的参照时间。设过去视点为 P，所设定的将来参照时间 R 晚于 P，但 R 与现在 S 的先后关系并不固定。一般式通常把事件定位在 P 之后；进行和完成等形式则进一步说明事件与 R 的关系。

假设现在是周五：

- On Monday, he said he **would leave on Tuesday**.（周一他说周二离开。）Tuesday 在过去视点之后，却已早于现在。
- On Monday, he said he **would leave next Saturday**.（周一他说下周六离开。）离开可以仍晚于现在。

这两句都是过去将来。不能把它的定义写成「过去视点 < 现在 < 将来事件」。完成结构中的事件还可能早于 P 开始：On Monday he said that by Friday he **would have lived there for ten years**.（周一他说，到周五他就在那里住满 10 年了。）居住的起点早于周一，完成所参照的周五则晚于周一。

## 体的对照

### 一般、进行与完成

一般（Simple）、进行（Continuous/Progressive）、完成（Perfect）和完成进行（Perfect Continuous/Progressive）是矩阵的四列名称。

|    体    |                  基本观察方式                  |             不应推出的结论             |
| :------: | :--------------------------------------------: | :------------------------------------: |
|   一般   | 不用进行或完成形式，整体陈述状态、习惯、事件等 |    不等于动作短暂，也不等于永远成立    |
|   进行   |             从过程内部观察有关阶段             | 不保证事件最终完成，也不只限于说话瞬间 |
|   完成   |     把先前事件或延续情状与参照时间联系起来     |   不等于动作结束，也不总突出可见结果   |
| 完成进行 |       把延续到参照时间附近的过程呈现出来       |    不保证仍在继续，也不保证刚好停止    |

比较同一组动词：

- I **work** here.（我在这里工作。）陈述工作关系或常态。
- I **am working** here this week.（我这周在这里工作。）突出当前阶段的临时活动。
- I **have worked** here since 2020.（我从 2020 年起就在这里工作。）可表示一直持续至今，工作没有结束。
- I **have been working** here all morning.（我整个上午一直在这里工作。）突出截至现在的过程，可能仍在做，也可能刚停下。

完成进行不是「进行 + 已结束」；完成也不是中文「做完」的固定对应。

### 动词词义的限制

进行体与动词在当前语境中的意义有关。

- I **know** the answer. 通常不用 I am knowing the answer. 因为 know 在这里描述认知状态。
- I **think** you are right.（我认为你是对的。）与 I **am thinking about** your question.（我正在思考你的问题。）采用不同词义。
- She **is being** rude.（她此刻表现得很无礼。）把表现当作暂时行为。

带终点的动作与无明确终点的活动也会影响解读：I **have written three pages**. 关注完成数量；I **have been writing**. 关注写作过程，不能据此确定写完多少。

## 十六格例句

下面每格都给出典型语境。中文翻译帮助理解，但不能代替英语形式与参照关系。

### 现在视角

|     名称     |                                      例句                                      |          核心解读          |
| :----------: | :----------------------------------------------------------------------------: | :------------------------: |
|   一般现在   |                I **study English every day**.（我每天学英语。）                |          日常习惯          |
|   现在进行   |              I **am studying English now**.（我现在正在学英语。）              |   过程在当前参照时间展开   |
|   现在完成   |       I **have studied English since 2020**.（我从 2020 年起学习英语。）       | 持续到现在的经历或学习状态 |
| 现在完成进行 | I **have been studying English for two hours**.（我已经连续学英语 2 小时了。） |     截至现在的学习过程     |

**一般现在** 也用于客观关系、时刻表及某些将来从句：Water boils at 100°C **at standard atmospheric pressure**.（标准大气压下水在 100°C 沸腾。）The train **leaves** at eight.（列车八点出发。）

I **eat carrots**.（我吃胡萝卜。）可以表达食物类别上的习惯；I **eat a carrot every day**.（我每天吃一根胡萝卜。）也成立，单数数量与反复动作并不矛盾。名词的单复数与动词的时态应分开判断。

**现在进行** 可以描述当前阶段，也能表达已有安排：I **am learning Spanish** these days.（我最近在学西班牙语。）We **are meeting** tomorrow.（我们明天见面。）与 always 连用还可能带评价色彩：He **is always complaining**.（他老是在抱怨。）但不必所有 always + 进行体都表示不满。

**现在完成** 常见读法有：

- 先前事件与目前情况有关：I **have lost my keys**.（我把钥匙弄丢了。）通常暗示目前仍有找不到钥匙的问题。
- 经历：I **have been to Paris twice**.（我去过巴黎两次。）说话人截至现在的经历。
- 持续：She **has known him for years**.（她认识他很多年了。）know 通常用完成一般式，不用完成进行式。
- 截至现在的比较范围：This is the best film I **have ever seen**.（这是我看过的最好的电影。）

表示截至现在的首次经历，常用 This is the first time I **have visited** London.（这是我第一次到伦敦。）把参照点移到过去，可用 It was the first time I **had visited** London. 形式依靠参照点选择，不是 first time 自带唯一固定时态。

**现在完成进行** 还可以解释当前迹象：You look tired. **Have you been running**?（你看起来很累，刚才一直在跑步吗？）说话时可以已经停下。She **has been feeling unwell lately**.（她最近一直感觉身体不适。）也可描述阶段性身体感受，不能把所有状态意义的词一律排除出进行体。某些动词用两种完成形式差别很小：I've lived / I've been living here for ten years. 后者更突出持续过程或暂时性，但不是绝对对立。

### 过去视角

|     名称     |                                          例句                                          |         核心解读         |
| :----------: | :------------------------------------------------------------------------------------: | :----------------------: |
|   一般过去   |                  I **studied English yesterday**.（我昨天学了英语。）                  | 事件位于已过去的时间范围 |
|   过去进行   |        I **was studying English at nine last night**.（昨晚九点我正在学英语。）        |   过去参照时刻中的过程   |
|   过去完成   |      I **had finished the lesson before she arrived**.（她到之前我已学完这课。）       |   完成先于过去参照事件   |
| 过去完成进行 | I **had been studying for two hours when she arrived**.（她到时我已连续学了 2 小时。） | 截至过去参照点的持续过程 |

**一般过去** 不必是一次动作，也能描述过去习惯和状态：When I was a child, I **played football** every day.（小时候我每天踢足球。） 过去习惯并不必须加 used to；used to 常另带与现在对比的意味。

**过去进行** 常提供叙事背景：I **was reading** when the phone **rang**.（我正读书时电话响了。）也能表达过去的临时状态或当时已有的将来安排：We **were leaving** the next day.（我们当时准备第二天离开。）when/while 只是连接事件，不自动决定时态。过去进行也能描述一段时间：It **was raining all day yesterday**.（昨天整天都在下雨。）这句强调持续过程；It **rained all day yesterday**. 也成立，采用整体事件视角。

**过去完成** 需要有关的过去参照点，可以来自上下文，而不必与另一个过去时同处一句：By then, everyone **had left**.（到那时所有人都已走了。）若 after/before 或叙述顺序已使先后清楚，一般过去有时也足够：After he **graduated**, he found a job. 不是凡「过去的过去」都必须使用过去完成。

**过去完成进行** 可解释过去的迹象：He **was** tired because he **had been running**.（他那时很累，因为此前一直在跑。）与现在完成进行一样，不能仅凭形式断言过程在参照点后一定继续或一定结束。

### 将来视角

|     名称     |                                           例句                                           |           核心解读           |
| :----------: | :--------------------------------------------------------------------------------------: | :--------------------------: |
|   一般将来   |                  I **will study English tomorrow**.（我明天会学英语。）                  | 对将来作陈述、预测或表达意愿 |
|   将来进行   |            I **will be studying at nine tomorrow**.（明天九点我会正在学习。）            |     从将来时刻内部看过程     |
|   将来完成   |         I **will have finished the lesson by Friday**.（到周五我会已学完这课。）         |    相对于将来截止点已完成    |
| 将来完成进行 | By noon, I **will have been studying for three hours**.（到中午我就连续学了 3 小时了。） |   截至将来参照点的持续过程   |

**将来进行** 也常把某活动呈现为正常进程或预定安排：I'll **be working all day** tomorrow.（明天我整天都要工作。）它不需要将来只持续一个瞬间。

will 不要求说话人百分之百确定：I think it **will probably rain** tomorrow.（我想明天可能会下雨。）将来进行也可用 I **will probably be working** tomorrow evening.（我明晚可能会在工作。）进行体突出过程视角，并不自动比一般形式更确定。

**将来完成** 中，by 表「不晚于」：by Friday 不表示必须恰好在周五完成。将来完成也能用于持续状态：By June, she **will have known him for ten years**.（到六月她就认识他 10 年了。）know 不因此结束。

**将来完成进行** 强调截至将来某时已经持续的过程，通常需要明确或可恢复的参照时间。使用频率低于一般将来，并不因此成为不合语法的「罕见例外」。

### 过去将来视角

|       名称       |                                                     例句                                                     |             核心解读             |
| :--------------: | :----------------------------------------------------------------------------------------------------------: | :------------------------------: |
|   一般过去将来   |                     She said she **would study that evening**.（她说她那天晚上会学习。）                     |   相对于说话这一过去事件的将来   |
|   过去将来进行   |                   She said she **would be studying at nine**.（她说九点时她会正在学习。）                    |    从过去预测将来参照点的过程    |
|   过去将来完成   |                  She said she **would have finished by Friday**.（她说到周五她会已完成。）                   |    从过去预测将来截止点前完成    |
| 过去将来完成进行 | She said that by noon she **would have been studying for three hours**.（她说到中午她就已连续学了 3 小时。） | 从过去预测截至以后某时的持续过程 |

过去将来也可用 **was/were going to do** 表达先前的打算或预测：He said he **was going to leave** the next day.（他说他准备第二天离开。）I **was going to call**, but I forgot.（我本打算打电话，但忘了。）后句因 but I forgot 明确说明未实现；was going to 本身并不保证计划落空。

这里的 said 建立过去视点，that evening、at nine、by Friday、by noon 给出其后的有关时间。实际是否按计划发生，要看后文，would 本身不保证兑现。

**would 的形式与过去将来不是一一对应**：

- When we were children, we **would play** outside.（小时候我们常在外面玩。）过去习惯。
- If I were you, I **would accept**.（若我是你，我会接受。）假设结果。
- If I had known, I **would have helped**.（若我当时知道，我本会帮忙。）过去反事实结果。

- **Would you pass me the salt?**（请把盐递给我好吗？）礼貌请求，不表示过去时间。

其中假设结果应结合 [动词语气](/docs/note/english/grammar/verbs/verb-moods) 分析，礼貌和习惯用法可对照 [助动词 & 情态动词](/docs/note/english/grammar/verbs/auxiliary-modal-verbs)。不能仅因出现 would have done 就标为「过去预测将来完成」。

## 选择步骤

1. **确定参照时间**：是当前视点、过去视点，还是从某一视点设置的以后时间；
2. **确定观察方式**：整体陈述，观察内部过程，联系截至参照点的先前或持续情状，还是突出持续过程；
3. **检查词义与结构**：状态意义是否自然接受进行体，will/would 是否表示时间，时间状语及主从句关系是否一致。

例如，Last night she told me that by Friday she would have finished the report. 中，told 建立过去视点，Friday 是其后的截止点，完成形式把完成报告定位在该截止点之前；它并不直接告诉读者目前是否已经到周五。

## 易混对照

### 现在完成与一般过去

|                                 现在完成                                 |                                  一般过去                                  |
| :----------------------------------------------------------------------: | :------------------------------------------------------------------------: |
|              I **have seen** that film.（我看过那部电影。）              |                  I **saw** it yesterday.（我昨天看的。）                   |
| I **have lived** here for ten years.（我在这里住了 10 年，通常仍住着。） | I **lived** there for ten years.（我在那里住过 10 年，作为过去阶段叙述。） |
|               **Have** you **eaten** yet?（你吃过了吗？）                |         **Did** you **eat** before you left?（离开前你吃过了吗？）         |

标准用法中，明确封闭且不包含现在的过去时间状语，如 yesterday、in 2010，通常与一般过去搭配，不能写 I have seen him yesterday. today、this week 是否包含当前时间和叙述范围，要结合语境判断。

美式英语较常用一般过去与 just、already、yet 搭配，因此 Did you eat yet? 不应简单判为错误。考试中需结合题目语境及所采用的语言规范。

**been 与 gone** 的对照也不能替代时间分析：

- She **has been to London**.（她去过伦敦。）通常表达已完成的造访经历，常理解为已离开那里。
- She **has gone to London**.（她已经去伦敦了。）通常把出发后尚未返回当前参照地点作为有关情况。
- She **went to London last week and is still there**.（她上周去了伦敦，现在还在那里。）一般过去仅定位过去事件，不保证人已回来。

因此，不能从 went 自动推出「已经返回」，也不能脱离说话视点，把 have gone 规定成绝对不能当面说的句式。

### 将来表达

|      形式      |           常见用途           |                      示例                       |
| :------------: | :--------------------------: | :---------------------------------------------: |
|    will do     |  预测、承诺、当场决定、意愿  |     I'll answer the phone.（我来接电话。）      |
| be going to do | 既有打算；基于当前迹象的预测 |    Look at those clouds. It's going to rain.    |
|    现在进行    |       已安排的将来活动       |       We're meeting the teacher tomorrow.       |
|    一般现在    |         时刻表、日程         |        The exam starts at nine tomorrow.        |
| be about to do |           即将发生           |          The train is about to leave.           |
|    be to do    |       正式安排、指令等       | The president is to visit the school next week. |

较正式或传统的第一人称将来还可见 **shall do**：We **shall return**.（我们会回来的。）现代常用英语通常也可用 will；shall 在征询、承诺和规则中的其他情态意义，另见 [助动词 & 情态动词](/docs/note/english/grammar/verbs/auxiliary-modal-verbs)。

be going to 的将来用法不能仅按「正走向某地」逐词理解；be to do 也不是可自由删掉 going 得到的同义表达。You **are to finish** this today.（你应在今天完成。）常带指令意味，与 I **am going to finish** this today.（我打算今天完成。）不同。

这些用途有交叉，不是每种情境都有唯一合法形式。will 不只表示临时决定，be going to 也不要求每次都已有详细计划。

### 时间状语与主从句

时间状语提供语境约束，而不是机械匹配答案的口令。常见表达可以成组记录：

- 频率或习惯：always、usually、often、every day；可用于一般陈述，也可能与带评价的进行体搭配。
- 当前或阶段：now、at the moment、at present、these days；具体形式仍受动词词义和观察方式限制。
- 封闭的过去：yesterday、two days ago、last week、in 2010；通常定位到过去。
- 将来：tomorrow、next week、soon；可与 will、be going to 或表示将来的现在形式配合。
- 截至目前或近期：so far、up to now、already、yet、just、recently、lately、in/over the past few years；常与现在完成有关，但分布并不相同。

|     表达      |            可以出现的结构            |                   解释                   |
| :-----------: | :----------------------------------: | :--------------------------------------: |
| for two years | lived / have lived / will have lived |     for 表持续长度，不独占某一种时态     |
|  since 2020   |       have worked / had worked       |  完成结构的参照时间可以现在，也可以过去  |
|      now      |       am reading / understand        |   状态意义的 understand 通常不用进行体   |
| when / while  |         一般、进行等多种形式         |            连接词不直接决定体            |
|    always     |          work / am working           | 习惯陈述与带评价的重复行为可采用不同形式 |

so far/up to now 通常把范围延伸到现在：We **have received** ten applications **so far**.（到目前为止，我们收到 10 份申请。）in/over the past few years 通常也包含截至现在的时间范围；不能把它缩写成任意的 in + 时间，因为 in 2010 通常是封闭的过去范围。recently 则既可见于 I **have seen** him recently，也可见于 I **saw** him recently，取决于叙述视点与语言变体。

since 引出的从句常用一般过去：I **have lived** here since I **was** a child.（我从小就住在这里。）不能把完成形式机械传播到从句。

在表将来的时间或条件状语从句中，通常用现在形式：

- I'll call you **when I arrive**.（我到了就给你打电话。）
- If it **rains** tomorrow, we'll stay home.（明天下雨的话，我们待在家里。）

这条规则不能推广到所有含 when/if 的从句：I don't know **when he will arrive**.（我不知道他什么时候到。）中的 when 分句是间接疑问内容，不是时间状语。

间接引语中的过去主句常引发时态后移：She said, 「I am tired.」 → She said she **was** tired. 但后移不等于情况现在已不成立；若内容仍适用或说话人保留当前视角，也可能不后移：The teacher said that water **boils** at 100°C at standard atmospheric pressure.

## 自测

1. 现在是周五，He said on Monday that he would leave on Tuesday. 是否因为周二已经过去就不能用 would？
2. I have known her for ten years. 是否表示现在已经不认识她？
3. I have been running. 是否能单独证明说话时还在跑？
4. I `___` him yesterday. 应选 saw 还是 have seen？
5. I'll call you when he arrives. 和 I don't know when he will arrive. 为什么不同？

<summary>答案与解析</summary>

1. 可以用。would 从周一这一过去视点出发，不要求离开晚于现在；
2. 不是。完成体可表示持续至今的状态，know 的状态通常仍然成立；
3. 不能。完成进行可表示持续至今，也可表示刚停止而留下当前迹象；
4. 通常选 saw。yesterday 是封闭的过去时间范围；
5. 前句 when 引导表将来的时间状语从句，通常用现在形式；后句是间接疑问，will 可以标明所询问的将来事件。
