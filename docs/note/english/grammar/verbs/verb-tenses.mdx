## 简介

传统学习语法用 **时态** 统称动词的时间和体的组合。分析时分开判断：

- **时间与时态**：从现在、过去，还是某一视点之后的时间定位事件。
- **体**：整体陈述事件，观察内部过程，还是联系截至参照时间的事件或持续情状。
- **情态**：表达可能、必要、意愿、假设等判断或态度。

**时态**（Tense）和 **体**（Aspect）在严格语法描述中不是同一个概念。英语有现在、过去的形态对立，没有与过去式同类的专属将来词尾；will 还属于情态系统。不同语法体系对完成结构的分类也略有差异。

学习阶段仍可保留 **4 × 4 = 16** 的时态表：它把常用的时间视角与体组合放在同一张地图上。矩阵是检索工具，不能据此认为英语只有这些表达时间的方式，也不能把四行都当成同一种形态变化。

## 构造矩阵

### 十六格形式

- **一般现在格的 do/does**：通用的现在式占位记号，具体动词按主语的人称和数选用词形。
- **动词链中的 do**：代表原形，如 will do 中 will 要求后一动词用原形。
- **did、doing、done**：分别代表过去式、-ing 形式和过去分词；具体词汇按相应词形替换。

| <span style={{ whiteSpace: 'nowrap' }}>时间视角</span> |   一般   |      进行       |      完成       |       完成进行        |
| :----------------------------------------------------: | :------: | :-------------: | :-------------: | :-------------------: |
|                          现在                          | do/does  | am/is/are doing |  have/has done  |  have/has been doing  |
|                          过去                          |   did    | was/were doing  |    had done     |    had been doing     |
|                          将来                          | will do  |  will be doing  | will have done  | will have been doing  |
|                        过去将来                        | would do | would be doing  | would have done | would have been doing |

将来和过去将来两行选用 will/would 作为代表形式。be going to、现在进行表安排、一般现在表时刻表等同样能表达将来。过去将来中的 would 也不能与所有「would + 动词」结构画等号。

### 动词词形

**过去式**（Past Form）和 **过去分词**（Past Participle）是不同的形式；**过去时态** 则是分句的时间语法，两者不能混称。

| 原形  | 现在第三人称单数 |  过去式  | 过去分词 | -ing 形式 |
| :---: | :--------------: | :------: | :------: | :-------: |
|  eat  |       eats       |   ate    |  eaten   |  eating   |
| write |      writes      |  wrote   | written  |  writing  |
|  go   |       goes       |   went   |   gone   |   going   |
| have  |       has        |   had    |   had    |  having   |
|  do   |       does       |   did    |   done   |   doing   |
|  be   |        is        | was/were |   been   |   being   |
|  hit  |       hits       |   hit    |   hit    |  hitting  |
|  die  |       dies       |   died   |   died   |   dying   |
| read  |      reads       |   read   |   read   |  reading  |

be 在现在还用 am/are，与主语配合；read 的原形读 /riːd/，过去式和过去分词读 /red/。拼写相同不表示词形功能或读音相同。

不规则过去形式按词汇记忆：

- **三形相同**：hit–hit–hit。
- **过去式与过去分词相同**：bring–brought–brought、feel–felt–felt。
- **三形不同**：begin–began–begun、give–gave–given、speak–spoke–spoken。

这些组是记忆索引，不是从一个单词生成同组全部词的规则。

### 词形拼写

先区分需要的是第三人称单数、规则过去式/过去分词，还是 -ing。词典指定的不规则形式和拼写变体优先于下列词尾分支；例如 go 的过去式用 went，不能套用 -ed，format 则采用 formatted/formatting。

#### 第三人称单数

构造普通动词的一般现在第三人称单数形式时，按以下顺序判断，命中后停止：

1. **词汇指定形式**：have → has、do → does、go → goes；quiz 先双写 z，形成 quizzes。-o 词尾按具体词处理，不能从 goes 推出 radio 要加 -es，radio → radios；
2. **辅音字母 + y**：把 y 改为 -ies，如 study → studies；元音字母 + y 不进入这一分支，如 play → plays、buy → buys；
3. **-s、-sh、-x、-z 结尾**：加 -es，如 pass → passes、wash → washes、fix → fixes、buzz → buzzes；
4. **-ch 结尾**：末音是咝音时加 -es，如 watch → watches（/tʃ/）；其余非咝音加 -s，如 stomach → stomachs（/k/）；
5. **其余规则形式**：加 -s，如 look → looks、read → reads。

#### 规则 -ed 形式

以下仅构造规则过去式和过去分词，不替代上面的不规则词形：

1. **以 e 结尾**：加 -d，如 live → lived、agree → agreed、die → died；
2. **辅音字母 + y**：把 y 改为 -ied，如 study → studied；元音字母 + y 保留 y，如 play → played；
3. **其余词尾**：按下节判断是否加 k 或双写，再加 -ed，如 panic → panicked、stop → stopped、open → opened。

#### -ing 形式

按以下顺序判断：

1. **-ie 结尾**：改成 -ying，如 die → dying、lie → lying、tie → tying；
2. **保留 e 的拼写分支**：-ee、-oe 保留 e，如 see → seeing、agree → agreeing、hoe → hoeing、canoe → canoeing；be → being、dye → dyeing、singe → singeing 也保留 e。dyeing（染色）与 dying（死亡）、singeing（燎焦）与 singing（唱歌）不能混写；
3. **地区或词典允许的变体**：ageing/aging、eyeing/eying 按词典和采用的拼写规范选择，不强行统一成「末尾 e 必删」；
4. **其余不发音的 e 结尾**：去 e 加 -ing，如 live → living、write → writing；
5. **其余词尾**：按下节处理辅音，再加 -ing，如 stop → stopping、begin → beginning、open → opening。y 在这里不改成 i：study → studying、play → playing。

#### 词尾辅音

构造规则 -ed 形式或 -ing 形式，且尚未进入前面的 e/y 等分支时，按顺序处理：

1. **词汇拼写优先**：format → formatted/formatting；focus 允许 focused/focusing 和 focussed/focussing。采用词典列出的形式，不仅凭重音反推拼写；
2. **-ic 结尾**：加 k 后再接词尾，如 panic → panicked/panicking、mimic → mimicked/mimicking。不能扩大成所有 -c 都加 k：arc → arced/arcing、sync → synced/syncing；其他备选拼写按词典；
3. **地区拼写分支**：travel、cancel、label 选用英式双 l 写法时，采用 travelled/travelling、cancelled/cancelling、labelled/labelling；选用美式常用单 l 写法时，采用 traveled/traveling、canceled/canceling、labeled/labeling；
4. **词尾 w、x、y**：保留该字母，不按下面的单辅音双写，如 snow → snowed/snowing、fix → fixed/fixing、play → played/playing；
5. **末尾音节重读，且以单个元音字母和单个辅音字母收尾**：双写末辅音，再加词尾，如 stop → stopped/stopping、prefer → preferred/preferring、control → controlled/controlling；begin 的 -ing 形式是 beginning，过去式仍按不规则词汇用 began；
6. **不满足以上条件**：直接接词尾，如 open → opened/opening、visit → visited/visiting、rain → rained/raining。

重音、元音拼写和词汇形式都参与判断；qu 中的 u 不独立表示元音，如 equip → equipped/equipping。遇到未掌握的动词，先核词典的词形栏，不能只取最后三个字母执行「辅元辅就双写」。

### 词尾读音

先完成词形选择和拼写，再根据词干的实际末音选择屈折词尾的读音。最后一个字母与最后一个音不是同一输入。

#### 规则三单词尾

规则 -s/-es 词尾按以下顺序判断：

1. **末音为咝音** /s/、/z/、/ʃ/、/ʒ/、/tʃ/、/dʒ/：读 /ɪz/，如 passes、washes、watches；
2. **末音为其他清辅音**：读 /s/，如 stops、works、laughs；
3. **末音为元音或其他浊辅音**：读 /z/，如 plays、reads、runs。

词尾读音不能决定整个词的读音。does /dʌz/、says /sez/ 等还涉及词干元音变化，has、is 等词汇指定形式也按完整词条确认。名词复数的对应规则见 [名词](/docs/note/english/grammar/parts-of-speech/nouns)。

#### 规则 -ed 词尾

以下用于按规则形成的 -ed 过去式和过去分词，按加词尾前的词干末音判断：

1. **末音为 /t/ 或 /d/**：读 /ɪd/，增加一个音节，如 wanted、needed；
2. **末音为其他清辅音**：读 /t/，如 worked、washed、laughed；
3. **末音为元音或其他浊辅音**：读 /d/，如 played、called、loved。

- **拼写不决定是否增加音节**：love 的 e 不发音，loved 的 -ed 读 /d/；wait 的末音为 /t/，waited 的 -ed 读 /ɪd/。
- **形容词词项另行确认**：a learned professor 中 learned 是形容词，读 /ˈlɜːnɪd/；不能仅因拼写含 -ed 就套用动词词尾规则。

### 模块关系

- 进行体由 **be + doing** 构造。
- 完成体由 **have + done** 构造。
- 完成进行体由 **have + been + doing** 构造，been 是 be 的过去分词。
- 矩阵的将来行在前面加 will，后接原形；过去将来这一代表行在同一位置使用 would。

例如选择 will、完成 have、进行 be 和 work 后，依次确定后一动词的词形：

1. will 要求 have 用原形；
2. 完成 have 要求 be 用过去分词 been；
3. 进行 be 要求 work 用 -ing 形式 working。

结果为 will have been working。详见 [助动词与情态动词](/docs/note/english/grammar/verbs/auxiliary-modal-verbs)。

## 时间参照

### 说话、参照与事件

可用三个标签帮助分析：

- **S（Speech Time）**：当前被分析话语的说话时间。
- **R（Reference Time）**：有关参照时间，可以由主句、时间状语或上下文给出。
- **E（Event Time）**：动作或状态占据的时间。

它们是分析工具，并非每个句子都能压缩成三个精确的数学点。状态、反复活动和进行过程往往占据区间，完成体也可能包含持续到参照时间的情状。

- I **am working** now.：R 接近 S，工作过程在 R 展开。
- I **was working** at nine.：R 是过去的九点，工作过程在 R 展开。
- I **had left** when she called.：R 是过去她来电时，离开先于 R。
- I **will have left** by nine tomorrow.：R 是明天九点，离开不晚于该截止点。

这里的「现在」不必是无长度瞬间。I live here.（我住在这里。）描述跨越现在的一段状态；The Earth goes around the Sun.（地球绕太阳转。）表达一般规律。

### 过去将来

过去将来从 **过去的视点** 设置其后的参照时间：

1. 先确定过去视点 P；
2. 设置晚于 P 的参照时间 R；R 可以早于、接近或晚于现在 S；
3. 一般式把事件定位在 P 之后；进行、完成等形式进一步说明事件与 R 的关系，不能把所有事件的起点也限定在 P 之后。

假设现在是周五：

- On Monday, he said he **would leave on Tuesday**.（周一他说周二离开。）Tuesday 在过去视点之后，却已早于现在。
- On Monday, he said he **would leave next Saturday**.（周一他说下周六离开。）离开可以仍晚于现在。

这两句都是过去将来，不要求「过去视点 < 现在 < 将来事件」。完成结构还允许事件在 P 之前开始：On Monday he said that by Friday he **would have lived there for ten years**.（周一他说，到周五他就在那里住满 10 年了。）居住的起点早于周一，参照点周五则晚于周一。

## 体的对照

### 一般、进行与完成

一般（Simple）、进行（Continuous/Progressive）、完成（Perfect）和完成进行（Perfect Continuous/Progressive）是矩阵的四列名称。

- **一般**：不采用进行或完成形式，整体陈述状态、习惯或事件；既可描述短暂动作，也可描述长期状态。
- **进行**：从事件内部观察有关阶段，不断言事件最终完成，也不限于说话瞬间。
- **完成**：把先前事件或延续情状与参照时间联系起来；事件是否结束、是否存在可见结果，由具体词义和语境决定。
- **完成进行**：突出延续到参照时间附近的过程；该过程可以仍在继续，也可以刚刚停止。

比较同一组动词：

- I **work** here.（我在这里工作。）陈述工作关系或常态。
- I **am working** here this week.（我这周在这里工作。）突出当前阶段的临时活动。
- I **have worked** here since 2020.（我从 2020 年起就在这里工作。）可表示一直持续至今，工作没有结束。
- I **have been working** here all morning.（我整个上午一直在这里工作。）突出截至现在的过程，可能仍在做，也可能刚停下。

完成进行不是「进行 + 已结束」；完成也不是中文「做完」的固定对应。

### 动词词义的限制

进行体与动词在当前语境中的意义有关。

- **稳定的认知状态**：标准书面语用 I **know** the answer. 陈述已掌握的答案，不用 I am knowing the answer.
- I **think** you are right.（我认为你是对的。）与 I **am thinking about** your question.（我正在思考你的问题。）采用不同词义。
- She **is being** rude.（她此刻表现得很无礼。）把表现当作暂时行为。

带终点的动作与无明确终点的活动也会影响解读：I **have written three pages**. 关注完成数量；I **have been writing**. 关注写作过程，不能据此确定写完多少。

## 十六格例句

下面每格都给出典型语境。中文翻译帮助理解，但不能代替英语形式与参照关系。

### 现在视角

- **一般现在**：I **study English every day**.（我每天学英语。）陈述日常习惯。
- **现在进行**：I **am studying English now**.（我现在正在学英语。）从当前参照时间内部观察过程。
- **现在完成**：I **have studied English since 2020**.（我从 2020 年起学习英语。）把截至现在的学习经历或持续状态与当前联系起来。
- **现在完成进行**：I **have been studying English for two hours**.（我已经连续学英语 2 小时了。）突出截至现在的学习过程。

一般现在还可用于以下语境：

- **客观关系**：Water boils at 100°C **at standard atmospheric pressure**.（标准大气压下水在 100°C 沸腾。）
- **时刻表或日程**：The train **leaves** at eight.（列车八点出发。）
- **将来时间、条件状语从句**：按后文的从句分支处理，不把主句的 will 复制进状语从句。

I **eat carrots**.（我吃胡萝卜。）可以表达食物类别上的习惯；I **eat a carrot every day**.（我每天吃一根胡萝卜。）也成立，单数数量与反复动作并不矛盾。名词的单复数与动词的时态应分开判断。

现在进行的其他用法按所表达的意义区分：

- **当前阶段的活动**：I **am learning Spanish** these days.（我最近在学西班牙语。）不要求此刻正坐在书桌前学习。
- **已有安排的将来活动**：We **are meeting** tomorrow.（我们明天见面。）
- **带评价的重复行为**：He **is always complaining**.（他老是在抱怨。）评价色彩来自 always、动词词义和语境；进行体本身不等于不满。

现在完成按事件与当前的联系区分读法：

- **解释当前处境**：I can't get in. I **have lost my keys**.（我进不去，钥匙弄丢了。）把此前丢失与当前无法进入的处境联系起来。
- 经历：I **have been to Paris twice**.（我去过巴黎两次。）说话人截至现在的经历。
- **持续状态**：She **has known him for years**.（她认识他很多年了。）在这里用完成一般式表达相识延续至今，不因 have known 就理解为已不认识。
- 截至现在的比较范围：This is the best film I **have ever seen**.（这是我看过的最好的电影。）

在下列「This/It is/was the first time + 经历分句」构式中，完成形式与参照点对应：

- **截至现在的首次经历**：This is the first time I **have visited** London.（这是我第一次到伦敦。）
- **截至过去参照点的首次经历**：It was the first time I **had visited** London.

现在完成进行还需结合事件类型解释：

- **过程留下当前迹象**：You look tired. **Have you been running**?（你看起来很累，刚才一直在跑步吗？）说话时可以已经停下。
- **阶段性身体感受**：She **has been feeling unwell lately**.（她最近一直感觉身体不适。）feel 在此接受进行体，不能把所有「状态」释义都当作禁用条件。
- **两种完成形式都成立**：I've lived / I've been living here for ten years. 两句都可描述居住延续至今；后者突出持续过程，也可能带暂时性意味，不能由它推出必将搬走。

### 过去视角

- **一般过去**：I **studied English yesterday**.（我昨天学了英语。）事件位于已过去的时间范围。
- **过去进行**：I **was studying English at nine last night**.（昨晚九点我正在学英语。）从过去九点内部观察过程。
- **过去完成**：I **had finished the lesson before she arrived**.（她到之前我已学完这课。）完成先于过去的到达事件。
- **过去完成进行**：I **had been studying for two hours when she arrived**.（她到时我已连续学了 2 小时。）突出截至过去参照点的过程。

选择过去形式时，区分以下语境：

- **过去习惯或状态**：一般过去也能使用。When I was a child, I **played football** every day.（小时候我每天踢足球。）used to 不是表达过去习惯的必需成分，选用它还可带出与现在的对比。
- **叙事背景中的过程**：I **was reading** when the phone **rang**.（我正读书时电话响了。）when/while 连接事件，不直接指定体。
- **过去已有的将来安排**：We **were leaving** the next day.（我们当时准备第二天离开。）
- **持续一段时间的活动**：It **was raining all day yesterday**.（昨天整天都在下雨。）突出过程；It **rained all day yesterday**. 则把整天下雨作为整体陈述，两种形式都成立。
- **先于过去参照点**：By then, everyone **had left**.（到那时所有人都已走了。）参照点可以从上文恢复，不要求同句再放一个一般过去。
- **先后已由 after/before 或叙述顺序表达**：After he **graduated**, he found a job. 可以用一般过去；若另需突出先于过去视点的关系，再采用过去完成，不能见到两个过去事件就强制改成 had done。

**过去完成进行** 可解释过去的迹象：He **was** tired because he **had been running**.（他那时很累，因为此前一直在跑。）与现在完成进行一样，不能仅凭形式断言过程在参照点后一定继续或一定结束。

### 将来视角

- **一般将来**：I **will study English tomorrow**.（我明天会学英语。）对将来作陈述、预测或表达意愿。
- **将来进行**：I **will be studying at nine tomorrow**.（明天九点我会正在学习。）从将来九点内部观察过程。
- **将来完成**：I **will have finished the lesson by Friday**.（到周五我会已学完这课。）把完成定位于将来截止点之前。
- **将来完成进行**：By noon, I **will have been studying for three hours**.（到中午我就连续学了 3 小时了。）突出截至将来参照点的过程。

将来进行也可把活动呈现为正常进程或预定安排：I'll **be working all day** tomorrow.（明天我整天都要工作。）参照范围可以是一整天，不限于一个瞬间。

will 不要求说话人百分之百确定：I think it **will probably rain** tomorrow.（我想明天可能会下雨。）将来进行也可用 I **will probably be working** tomorrow evening.（我明晚可能会在工作。）进行体突出过程视角，并不自动比一般形式更确定。

**将来完成** 中，by 表「不晚于」：by Friday 不表示必须恰好在周五完成。将来完成也能用于持续状态：By June, she **will have known him for ten years**.（到六月她就认识他 10 年了。）know 不因此结束。

**将来完成进行** 强调截至将来某时已经持续的过程；参照时间由时间状语明说，或从上下文恢复。它在日常表达中比一般将来少见，但形式和时间关系仍按同一构造规则分析。

### 过去将来视角

- **一般过去将来**：She said she **would study that evening**.（她说她那天晚上会学习。）从 said 建立的过去视点看当天晚上的学习。
- **过去将来进行**：She said she **would be studying at nine**.（她说九点时她会正在学习。）从过去预测后续参照点的过程。
- **过去将来完成**：She said she **would have finished by Friday**.（她说到周五她会已完成。）从过去预测后续截止点前的完成。
- **过去将来完成进行**：She said that by noon she **would have been studying for three hours**.（她说到中午她就已连续学了 3 小时。）从过去预测截至后续参照点的持续过程。

过去将来也可用 **was/were going to do** 表达先前的打算或预测：

- **计划内容**：He said he **was going to leave** the next day.（他说他准备第二天离开。）形式本身不保证计划实现或落空。
- **语境说明未实现**：I **was going to call**, but I forgot.（我本打算打电话，但忘了。）未实现由 but I forgot 明确给出。

这里的 said 建立过去视点，that evening、at nine、by Friday、by noon 给出其后的有关时间。实际是否按计划发生，要看后文，would 本身不保证兑现。

**would 的形式与过去将来不是一一对应**：

- When we were children, we **would play** outside.（小时候我们常在外面玩。）过去习惯。
- If I were you, I **would accept**.（若我是你，我会接受。）假设结果。
- If I had known, I **would have helped**.（若我当时知道，我本会帮忙。）过去反事实结果。
- **Would you pass me the salt?**（请把盐递给我好吗？）礼貌请求，不表示过去时间。

其中假设结果应结合 [动词语气](/docs/note/english/grammar/verbs/verb-moods) 分析，礼貌和习惯用法可对照 [助动词与情态动词](/docs/note/english/grammar/verbs/auxiliary-modal-verbs)。不能仅因出现 would have done 就标为「过去预测将来完成」。

## 选择步骤

1. **确定参照时间**：是当前视点、过去视点，还是从某一视点设置的以后时间；
2. **确定观察方式**：整体陈述，观察内部过程，联系截至参照点的先前或持续情状，还是突出持续过程；
3. **检查词义与结构**：状态意义是否自然接受进行体，will/would 是否表示时间，时间状语及主从句关系是否一致。

例如，Last night she told me that by Friday she would have finished the report. 中，told 建立过去视点，Friday 是其后的截止点，完成形式把完成报告定位在该截止点之前；它并不直接告诉读者目前是否已经到周五。

## 易混对照

### 现在完成与一般过去

|                                     现在完成                                     |                                  一般过去                                  |
| :------------------------------------------------------------------------------: | :------------------------------------------------------------------------: |
|                  I **have seen** that film.（我看过那部电影。）                  |                  I **saw** it yesterday.（我昨天看的。）                   |
| I **have lived** here for ten years.（我在这里住了 10 年，描述持续至今的状态。） | I **lived** there for ten years.（我在那里住过 10 年，作为过去阶段叙述。） |
|                   **Have** you **eaten** yet?（你吃过了吗？）                    |         **Did** you **eat** before you left?（离开前你吃过了吗？）         |

按所陈述的时间范围选择：

- **事件直接定位于已结束的过去范围**：yesterday、in 2010 等直接修饰该事件时，采用一般过去。I **saw him yesterday**. 成立，I have seen him yesterday. 不符合这一用法。
- **时间范围包含现在**：若 today、this week 表示截至当前的经历或进展，可用现在完成；若叙述的是这段时间内已结束的一次过去事件，也可用一般过去。
- **英美用法分支**：美式英语中，一般过去可与 just、already、yet 搭配，如 Did you eat yet?；不能把按某一英式练习模板选出的现在完成，当作所有语言变体的唯一形式。

**been 与 gone** 的对照也不能替代时间分析：

- **经历义 have been to**：She **has been to London**.（她去过伦敦。）把造访作为已经完成的经历陈述，不必表示她已回到说话人身边。
- **当前去向义 have gone to**：She **has gone to London**.（她已经去伦敦了。）从有关参照地点看她已出发、尚未返回；具体所在位置由语境确定。
- She **went to London last week and is still there**.（她上周去了伦敦，现在还在那里。）一般过去仅定位过去事件，不保证人已回来。

因此，不能从 went 自动推出「已经返回」，也不能脱离说话视点，把 have gone 规定成绝对不能当面说的句式。

### 将来表达

- **will do**：表达预测、承诺、意愿或当场决定，如 I'll answer the phone.（我来接电话。）不把 will 限定成仅能表示临时决定。
- **be going to do**：表达既有打算，或依据当前迹象作预测：Look at those clouds. It's going to rain.（看那些云，快下雨了。）不要求每项打算都已有详细计划。
- **现在进行**：把已有安排作为将来活动呈现：We're meeting the teacher tomorrow.（我们明天要见老师。）
- **一般现在**：按时刻表、日程陈述将来：The exam starts at nine tomorrow.（考试明天九点开始。）
- **be about to do**：表达即将发生：The train is about to leave.（列车马上就要开了。）
- **be to do**：表达正式安排或指令：The president is to visit the school next week.（总统将于下周访问这所学校。）You **are to finish** this today.（你应在今天完成。）

在较正式或传统的第一人称将来表达中，还可选 **shall do**：We **shall return**.（我们会回来的。）日常表达也可选 will；shall 在征询、承诺和规则中的情态意义见 [助动词与情态动词](/docs/note/english/grammar/verbs/auxiliary-modal-verbs)。

be going to 的将来用法不按「正走向某地」逐词理解；be to do 也不是删掉 going 得到的同义表达。I **am going to finish** this today.（我打算今天完成。）陈述自己的打算，不等同于向别人下达 are to finish 的指令。

这些用途有交叉，不是每种情境都有唯一合法形式。will 不只表示临时决定，be going to 也不要求每次都已有详细计划。

### 时间状语与主从句

时间状语提供语境约束，而不是机械匹配答案的口令。常见表达可以成组记录：

- 频率或习惯：always、usually、often、every day；可用于一般陈述，也可能与带评价的进行体搭配。
- 当前或阶段：now、at the moment、at present、these days；具体形式仍受动词词义和观察方式限制。
- 封闭的过去：yesterday、two days ago、last week、in 2010；直接给出过去范围。
- 将来：tomorrow、next week、soon；可与 will、be going to 或表示将来的现在形式配合。
- 截至目前或近期：so far、up to now、already、yet、just、recently、lately、in/over the past few years；具体时间范围按下列分支判断。

常见状语按功能处理：

- **for + 时长**：给出持续长度，可配 lived、have lived、will have lived，不独占某种时态。
- **since + 起点**：完成结构的参照点可以在现在或过去，如 have worked / had worked since 2020。
- **now**：过程读法可用 am reading，认知状态可用 understand；不能仅凭 now 就造出 am understanding。
- **when/while**：连接事件，可配一般、进行等形式，按各事件的参照关系选择。
- **always**：可配一般形式 work，也可配带评价的重复过程 am always working；区别在于观察方式和语境。

时间范围与从句形式分别检查：

- **截至当前的统计**：so far/up to now 把范围延伸到现在：We **have received** ten applications **so far**.（到目前为止，我们收到 10 份申请。）in/over the past few years 也可设置截至现在的范围，不能缩成任意的 in + 时间；in 2010 则直接给出过去年份。
- **近期事件**：按截至现在的经历叙述，可用 I **have seen** him recently. 按过去事件叙述，可用 I **saw** him recently. 具体选择还需结合英美用法。
- **since 后的起点事件**：若起点位于过去，从句可用一般过去：I **have lived** here since I **was** a child.（我从小就住在这里。）主句的完成形式不会自动传播到从句。

when/if 从句先判功能，再判 will 是否表示纯将来：

1. **将来的时间或开放条件状语**：用现在形式定位有关事件，如 I'll call you **when I arrive**.（我到了就给你打电话。）If it **rains** tomorrow, we'll stay home.（明天下雨的话，我们待在家里。）需突出先完成时可用现在完成：Call me **when you have finished**.（完成后给我打电话。）；
2. **will 表意愿或配合**：不按纯将来时态删去 will，如 If you **will wait** here, I'll ask her.（若你愿意在这里等，我去问问她。）；
3. **间接疑问内容**：允许按所询问事件的时间使用 will，如 I don't know **when he will arrive**.（我不知道他什么时候到。）这里不是时间状语。

间接引语另按叙述视点选择：

- **沿用过去的报告视点**：She said, 「I am tired.」 → She said she **was** tired. 这是时态后移，不断言她现在已经不累。
- **保留当前仍适用的内容视点**：The teacher said that water **boils** at 100°C at standard atmospheric pressure. 从句可以不后移，不能只因主句 said 就强制改成 boiled。
