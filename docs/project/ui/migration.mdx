## 替换依赖

本页适用于仍使用旧包 `@lailai/ui` 的应用。新项目直接按照 [快速开始](/docs/project/ui/getting-started) 安装 `@lailai0916/ui`，无需执行迁移。

移除旧依赖后，安装 npm 发布版本：

```bash
npm uninstall @lailai/ui
npm install --save-exact @lailai0916/ui@0.2.0
```

工作区项目需在对应工作区执行依赖变更。将导入和样式改为：

```tsx
import { Button, TextField } from '@lailai0916/ui';
import '@lailai0916/ui/theme.css';
import '@lailai0916/ui/styles.css';
```

删除旧包导入，宿主样式放在组件库 CSS 之后。保留自己的基础排版和 `box-sizing`，因为包不提供全局重置。

## 按钮属性

| 旧接口               | 新接口                       |
| -------------------- | ---------------------------- |
| `variant="quiet"`    | `variant="ghost"`            |
| `size="small"`       | `size="sm"`                  |
| `size="medium"`      | `size="md"`                  |
| `size="large"`       | `size="lg"`                  |
| 依赖旧包默认主要按钮 | 显式设置 `variant="primary"` |

0.2 系列的 `Button` 默认是 `secondary`、`md`；`IconButton` 仅提供 `sm`、`md`。图标、整行宽度与选中态分别使用 `leftIcon`、`fullWidth`、`active`。

## 主题变量

常用映射如下；其他变量应对照完整主题清单，不要只做前缀替换后假定它存在。

| 旧变量                                                          | 新变量                                       |
| --------------------------------------------------------------- | -------------------------------------------- |
| `--lui-color-canvas`                                            | `--lk-background-color`                      |
| `--lui-color-surface`                                           | `--lk-card-background-color`                 |
| `--lui-color-surface-muted`                                     | `--lk-color-emphasis-100`                    |
| `--lui-color-surface-raised`                                    | `--lk-background-raised`                     |
| `--lui-color-label`                                             | `--lk-font-color-base`                       |
| `--lui-color-label-secondary`                                   | `--lk-font-color-secondary`                  |
| `--lui-color-label-tertiary`                                    | `--lk-font-color-tertiary`                   |
| `--lui-color-separator`                                         | `--lk-color-emphasis-300`                    |
| `--lui-color-separator-strong`                                  | `--lk-color-emphasis-400`                    |
| `--lui-color-accent`、`--lui-color-accent-fill`                 | `--lk-color-primary`                         |
| `--lui-color-accent-hover`、`--lui-color-accent-fill-hover`     | `--lk-color-primary-dark`                    |
| `--lui-color-accent-pressed`、`--lui-color-accent-fill-pressed` | `--lk-color-primary-darker`                  |
| `--lui-color-accent-soft`                                       | `--lk-color-primary-soft`                    |
| `--lui-color-accent-label`                                      | `--lk-color-primary-label`                   |
| `--lui-color-focus`                                             | `--lk-color-primary`                         |
| `--lui-font-sans`                                               | `--lk-font-family`                           |
| `--lui-radius-panel`、`--lui-radius-feature`                    | `--lk-radius-md`、`--lk-radius-lg`           |
| `--lui-motion-control`、`--lui-motion-surface`                  | `--lk-transition`、`--lk-transition-surface` |

产品专有变量仍由应用维护，共用配色与控件样式集中在组件库。`ThemeProvider` 默认存储键保持 `lailai.theme`；已有框架主题管理的项目继续沿用宿主机制。

## 样式接口

旧的全局 `.lui-*` 类替换为 CSS Modules。必须从宿主调整内部元素时，使用公开标记：

| 旧选择器                  | 新选择器                    |
| ------------------------- | --------------------------- |
| `.lui-button`             | `[data-lk='button']`        |
| `.lui-avatar`             | `[data-lk='avatar']`        |
| `.lui-brand`              | `[data-lk='brand']`         |
| `.lui-brand__logo`        | `[data-lk='brand-logo']`    |
| `.lui-field__control`     | `[data-lk='field-control']` |
| `.lui-panel`              | `[data-lk='panel']`         |
| `.lui-theme-picker__menu` | `[data-lk='theme-menu']`    |

## 验证

1. 搜索旧包名、旧变量与旧选择器，确认源代码和锁文件均已替换。
2. 运行项目检查与生产构建，确认不存在类型错误或缺失导出。
3. 检查按钮默认层级、表单焦点、禁用态、窄屏布局和键盘导航。
4. 检查主题切换、刷新恢复和应用原有的强调色设置。
5. 使用已发布的 npm 版本生成最终锁文件，部署后再次验证主要页面。
