## 简介

**laikit UI** 是 lailai 的共享 React 组件库，npm 包名为 `@lailai0916/ui`，源码仓库为 `lailai0916/ui`。设计遵循统一、简约、现代，供 [lailai's Home](https://lailai.one)、[lailai's Tools](https://tools.lailai.one) 和 [lailai's Academy](https://academy.lailai.one) 等项目复用。

这组文档对应 **0.2 系列** API。组件库提供可复用的界面与交互，网站负责路由、业务数据、页面组织和用户文案。Docusaurus 的文章组件、Tools 的具体工具、Academy 的学习业务仍由各自项目维护。

## 使用边界

- 应用需要 React 与 React DOM，支持 React 18.3.1 或 19；包提供 ESM 与 TypeScript 声明。
- JavaScript 可由打包器移除未使用模块；共享样式文件包含整套组件样式。
- 抽取组件库减少的是重复维护的源码，不能直接等同于浏览器下载体积的减少。
- 图表接收应用传入的数据；`GitHub` 卡片会请求公开仓库信息，Iconify 图标可能发起网络请求。
- 组件样式使用 CSS Modules，主题通过 `--lk-*` 变量定制。优先使用公开属性与变量，避免依赖生成的类名。
