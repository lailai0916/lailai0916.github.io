## 身份与标记

| 组件        | 必要属性          | 可选属性                                                        |
| ----------- | ----------------- | --------------------------------------------------------------- |
| `Avatar`    | `name`、`alt`     | `src`、`size`，默认尺寸 36 px                                   |
| `Brand`     | `logoSrc`、`name` | `logoAlt`，默认空字符串                                         |
| `Badge`     | 无                | `children`、`icon`、`count`、`active`、`hoverable`、`className` |
| `Icon`      | `icon`            | `width`、`height`、`className`、`style`、`onLoad`、SVG 属性     |
| `IconBlock` | 无                | `icon`、`variant`、`size`、`iconSize`、`className`、`children`  |

`Avatar` 在没有图片时显示姓名首字母；`alt` 应描述头像用途。`Brand` 由应用提供标志地址与名称。`IconBlock.variant` 为 `accent` 或 `muted`。

`Badge.hoverable` 只提供悬停外观，不会把徽标变成按钮；需要点击操作时使用按钮或链接。图标名使用 Iconify 标识，例如 `lucide:book-open`，图标数据可能通过网络加载。

`Icon` 在服务端渲染、加载中或加载失败时保留同尺寸的空 SVG，文字与控件不会因图标出现而改变位置。默认尺寸为 `1em × 1em`；仅设置 `width` 或 `height` 时，另一边使用相同尺寸。非正方形图标应显式设置两边尺寸，或通过 CSS 固定宽高，不使用 `auto`。

  <Icon icon="flag:cn-4x3" width={20} height={15} />
</Cluster>

```tsx
<Icon icon="lucide:book-open" width={20} />;
<Icon icon="flag:cn-4x3" width={20} height={15} />;
```

## 窗口

`TrafficLights` 显示装饰性的窗口圆点；`WindowBar` 提供标题栏，可传 `children`、`className`。需要标签切换与折叠时使用 `WindowPanel`：

```tsx
import { WindowPanel } from '@lailai0916/ui';

export function ResultWindow() {
  return (
    <WindowPanel
      collapseLabel="收起结果"
      expandLabel="展开结果"
      expandTo="last"
      tabs={[
        { label: '结果', content: <p>转换成功。</p> },
        { label: '原始数据', content: <pre>{'{"ok":true}'}</pre> },
      ]}
    />
  );
}
```

每个标签含 `label`、`content`；`bare` 可移除默认正文内边距。`toolbar(activeIndex, open)` 可以提供附加工具。`expandTo` 为 `first` 或 `last`，决定重新展开时选中哪一页。

## 文章与仓库

| 组件         | 主要属性                                              | 用途                        |
| ------------ | ----------------------------------------------------- | --------------------------- |
| `MDTitle`    | `title`、`description`、`className`                   | 接受 React 内容的文章标题区 |
| `Quote`      | `children`、`author`、`source`、`className`           | 引用正文及明确的署名来源    |
| `GitHub`     | `repo`、`className`                                   | 公开 GitHub 仓库卡片        |
| `EmptyState` | `title`、`description`；可选 `icon`、`action`         | 有说明与后续操作的空状态    |
| `Paginator`  | `ariaLabel`；可选 `prevItem`、`nextItem`、`className` | 前后项导航                  |

`Quote` 的作者与来源应真实；`GitHub.repo` 使用 `owner/repo` 格式，例如 `lailai0916/ui`。GitHub API 失败或限流时，卡片显示本地化错误，不应传入访问令牌。

`Paginator` 每个导航项包含 `title`、`permalink`、`label`。组件只渲染给定链接，排序、页数和当前页由应用决定。

```tsx
import { Paginator } from '@lailai0916/ui';

export function GuideNavigation() {
  return (
    <Paginator
      ariaLabel="文档导航"
      prevItem={{ title: '数据展示', permalink: '/docs/project/ui/data-display', label: '上一篇' }}
      nextItem={{ title: '主题定制', permalink: '/docs/project/ui/theming', label: '下一篇' }}
    />
  );
}
```

## 操作提示

`Hint` 用短文本解释按钮、链接或输入框的用途。默认悬停 500 毫秒后出现，键盘聚焦时立即出现；可将鼠标移到提示上阅读，按 Esc 关闭。提示自动避让视口边缘，并支持深浅色和减少动态效果。

export function ActionHintPreview() {
  return (
    <Stack>
      <Hint label="复制当前结果到剪贴板">
        <Button>悬停或用 Tab 聚焦</Button>
      </Hint>
      <Hint label="按标题或关键词查找内容">
        <Input aria-label="搜索示例" placeholder="输入关键词" />
      </Hint>
    </Stack>
  );
}

<ActionHintPreview />

```tsx
import { Hint, Input } from '@lailai0916/ui';

<Hint label="按标题或关键词查找内容" side="bottom" delay={500}>
  <Input aria-label="搜索" aria-describedby="search-description" />
</Hint>;
```

`label` 是提示文字；`children` 必须是一个元素。自定义触发组件需把 ref、事件和无障碍属性传给同一个 DOM 元素。`Hint` 不增加触发器外层容器，保留原有外观、点击行为与 `aria-describedby`，并移除原生 `title`，避免同时出现两个提示框。

`side` 支持 `top`、`bottom`、`left`、`right`，默认 `bottom`；`delay` 是悬停等待的毫秒数；`disabled` 仅关闭提示，不禁用控件。`className` 与原生 `div` 属性作用于提示内容，稳定样式入口是 `[data-lk="hint"]`。原生对话框内的提示保留在对话框的顶层中。

`IconButton` 自动显示操作提示，内容默认取 `title ?? label`，可用 `hint={false}` 或 `title=""` 关闭。`Button`、`ButtonLink` 在传入非空 `title` 时使用 `Hint`；语言和主题按钮也复用它。字段的标签、错误和必读说明继续通过 `label`、`description`、`error` 常驻展示。

## 数据提示

`Tooltip` 是图表使用的提示内容层，接受 `leftPct`、原生 `div` 属性和 `children`，可组合 `Tooltip.Label` 与 `Tooltip.Value`。它不包含悬停触发器、门户或自动避让；显示时机、定位容器和交互均由调用方控制。

```tsx
import { Tooltip } from '@lailai0916/ui';

export function ChartHint({ visible }: { visible: boolean }) {
  return (
    <div style={{ position: 'relative' }}>
      {visible && (
        <Tooltip leftPct={50}>
          <Tooltip.Label>星期一</Tooltip.Label>
          <Tooltip.Value>12 次访问</Tooltip.Value>
        </Tooltip>
      )}
    </div>
  );
}
```

`Hint` 用于操作说明，`Tooltip` 用于日期、数值、状态等数据展示。需要包含可点击链接或按钮的卡片应采用单独的弹层或对话框交互。

完整图表优先使用 `Chart` 或 `Donut`，它们已组织图形与提示层。

`Badge.variant` 默认为 `neutral`，可选择 `primary`、`success`、`warning`、`danger` 表达业务状态。默认徽标外观保持不变。
