## 简介

lailai.skill 是持续维护的个人模型，让 AI Agent 尽可能按照 lailai 的方式交流、思考和产出。它面向日常聊天、中文写作、算法竞赛代码、设计审查和辅助判断，不代表本人作出承诺或授权。

- `profile/` 保存个人信息、性格、思维习惯、偏好与边界。
- `references/` 保存写作、Markdown、LaTeX、代码与设计风格。
- `observations.md` 记录尚未沉淀为规则的观察。
- `examples/`、`tests/` 与 `tools/` 提供示例、行为测试和机械检查。
- `evolution/` 记录评估标准与长期维护过程。

新观察不直接等于长期规则。经验证的习惯才会进入个人模型，并同步调整示例与测试。

## 使用

按仓库的 [安装说明](https://github.com/lailai0916/lailai-skill/blob/main/README.zh-Hans.md#快速开始) 配置共享 Skill 入口，再向 Agent 描述任务，例如「按 lailai 的风格润色这段文字」。

Agent 从 [SKILL.md](https://github.com/lailai0916/lailai-skill/blob/main/SKILL.md) 开始，按任务读取所需内容。维护已有项目时，项目内部规则在其范围内优先，个人 Skill 补充跨项目风格。
