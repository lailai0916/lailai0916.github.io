## 使用

点击仓库页的 **Use this template** 新建仓库，然后完成占位内容检查：

```bash
rg -n 'TODO|<owner>|<repo>|One paragraph|Replace with' .
rg -n 'lailai-template|lailai0916/lailai-template' . --glob '!README*'
```

随后将中英文 README 重写为严格镜像，替换徽章路径，补完 `AGENTS.md`，删除无用模板，
并设置 GitHub About 的 description、homepage 与准确 topics。这些步骤均为初始化完成条件。
