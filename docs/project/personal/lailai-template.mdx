## 使用

点击仓库页的 **Use this template** 新建仓库，完整读取
[初始化指南](https://github.com/lailai0916/lailai-template/blob/main/SETUP.md)，按其中的标准完成配置与验收。

验收后清理新项目继承的初始化文档，并保留上游规范入口；模板源仓库永久保留指南。
已有项目维护 README 或仓库元数据时，也查阅同一来源。本站项目页仅说明用途与入口。
