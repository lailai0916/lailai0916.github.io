## 简介

lailai-template 是开箱即用的 GitHub 仓库模板，也是通用仓库标准的维护入口。

仓库提供双语 README 示例、协作表单、Git 配置、Prettier 配置与 Agent 项目地图。[SETUP.md](https://github.com/lailai0916/lailai-template/blob/main/SETUP.md) 统一说明仓库命名、README 排版、GitHub About、工程配置与验收要求。

## 使用

在仓库页点击 [Use this template]，完整读取初始化指南，再按实际项目替换内容、配置工程并完成验收。阅读完指南不等于完成初始化。

验收后清理新项目继承的初始化文档，保留上游规范入口和项目自身的配置、工具与测试。模板源仓库永久保留指南，不执行这一步清理。

已有项目维护 README 或仓库元数据时，同样查阅上游指南，结合项目现状采用适用要求，不直接覆盖已有配置。

## 校验

通用检查器维护在模板仓库，可通过 `--root` 指定其他项目。启用 `--github` 时，还会只读核对 GitHub 元数据；未执行该检查时，不将远端状态标记为已验证。

持续集成可引用模板的固定版本，同时保留项目自身的测试和构建检查。具体命令与适用范围见 [校验说明](https://github.com/lailai0916/lailai-template/blob/main/SETUP.md#validation)，不向下游复制检查脚本。
