## 简介

laiism-skill 是用于整理、讨论与发展 laiism 思想体系的 Agent Skill。它关注世界观、价值立场、论证与实践，不模拟完整人格，也不接管日常写作、代码或仓库规范。名称 `laiism` 始终小写。

它支持解释已有材料、检验前提与反例、讨论适用范围，以及起草供审阅的新建议。讨论思想不等于接受思想，草案也不代表已经确立的主张。

## 思想材料

[positions.json](https://github.com/lailai0916/laiism-skill/blob/main/positions.json) 是思想正文与依据的统一来源。每项材料有稳定的标识、正文、来源和两类确认状态：

- **个人立场**：是否已有本人确认记录。
- **正式主张**：是否已由本人明确确立为 laiism 教义。

确认个人立场不等于确立教义。历史模型摘要不视为本人逐字原话，待确认观察也不当作已知信仰。材料整理、修改与确认方法见 [维护说明](https://github.com/lailai0916/laiism-skill/blob/main/references/method.md)。

## 使用

按仓库的 [安装说明](https://github.com/lailai0916/laiism-skill/blob/main/README.zh-Hans.md#快速开始) 配置共享 Skill 入口，Agent 先读 [SKILL.md](https://github.com/lailai0916/laiism-skill/blob/main/SKILL.md)，再读取相关思想条目。

例如，可以要求「解释这条已记录立场的前提，并提出一个反例」，或「根据现有材料起草一份建议，区分已有主张与新增内容」。

该 Skill 可独立使用，不依赖个人网站或其他个人 Skill。网站不复制思想正文，具体条目的内容、来源与状态以仓库为准。
