## 项目仓库

<GitHub repo="lailai0916/laiism-skill" />

## 简介

laiism.skill 是用于整理、讨论与发展 laiism 思想体系的 Agent Skill，关注世界观、价值立场、论证与实践。

它支持解释已有观点、分析推理过程、检验反例、讨论适用范围，以及结合现有材料起草新主张。

## 思想材料

[思想材料](https://github.com/lailai0916/laiism-skill/blob/main/positions.json) 按条目记录观点正文、来源和确认状态，可区分已确认的个人立场与正式主张。

## 使用

按仓库的 [安装说明](https://github.com/lailai0916/laiism-skill/blob/main/README.zh-Hans.md#快速开始) 完成安装后，让 Agent 使用 `laiism-skill`。

例如，可以要求「解释这条立场的前提，并提出一个反例」，或「根据现有材料起草一份新的讨论草稿」。
