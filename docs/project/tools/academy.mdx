summary: lailai's Academy 是一个面向长期学习目标的个人学习工作台。页面把目标拆成每日任务，提供 Words、Poems 和 Review 三个模块，并用本地 AI 规划预览生成下一步安排。任务进度保存在浏览器的 localStorage 中，界面默认使用英语，也可切换为简体中文。项目采用 Vite、React 和 TypeScript 构建，通过 GitHub Actions 发布到 GitHub Pages；当前规划器仍是本地预览，未来再接入服务端 API。
